## 1. 唯一干预与可支持主张

每个账号对使用同一模型产生的完整、未填充记录对logit块K，N=nm，n,m∈{2,…,8}：

    mu(K) = sum(K)/N
    G(K) = logsumexp(K) - log(N)
    H(K) = G_half(K) = 0.5*mu(K) + 0.5*G(K)

固定tau=1、系数1/2；不训练系数、不扫描、不按域切换。H不是旧S/G两个模型的输出集成。只新训H；S与G为旧冻结结果对照，F不参与新运行。目的为检验这一个完整评分替换能否改善重复开发valid上的自然账号排序。

H在同K上满足mu≤H≤G，局部导数q=0.5u+0.5softmax(K)；偏离均匀的局部份额减半，不保证整网梯度、身份证据覆盖或性能。它可以伤害稀疏真证据、放大强负无关logit，且对元素任意重排不变，不能识别双边覆盖或来源捷径。当前集中并非G新域结果的已证根因。H仍是已知聚合构件的固定混合，不能仅凭胜S声称独立算法创新；论文主张与本次开发结果分别判读。

5. 从相同配对fixture恢复作H的current+history更新。
6. 再从相同配对fixture恢复，运行H实际完整角色数capture后，重复第5次H配对更新。

当前/配对fixture允许设置合法阶段时钟及Adam计数，必须明示并保存实际构造；不声称省略步骤已发生，初始化/参数/Adam/RNG/输入在对应成对更新前须完全相同。历史T为同一手写非恒定完整表，用各自G/H投影，D活跃；这只隔离受控资格干预，不是正式共享A或共享Memory。第2—6次用非零encoder LR。最大训练形状28×8=224记录、标题/描述各256 token且内容不同，不得用退化重复内容掩盖作用。

原生必须展示H-G在当前及配对两路径的目标、关键head/encoder裁剪前后梯度及真实参数更新差别，两支贡献按CPU解析/完整图证据衔接；同fixture输入来源可在CPU阶段调至非退化后冻结，GPU不为寻例追加调用。若未取得差异证据则资格失败，不看总梯度非零就通过。

第6次capture用48 fit/6 cache/40 blind，每账号2记录的最小合法手写组；完整走score_fn/pooling_fn、残差和保存，再比较下一更新后model全部参数/Adam/模式/RNG/Memory与第5次逐元素相同。H实际保存恢复完整/推理两类状态并真实评分，身份冲突拒绝；G的未变恢复资格继承，不额外重核。一次原生记录最大形状更新、评分/全表、残差、加载/保存恢复的时间与峰值；不为更好计时重跑。原生失败无自动重试；6次或600秒先到即停，失败不清账。

### 时间投影

原生同步CUDA后测t_A/t_B为H最大形状无历史/配对更新，v为H自然评分和出生全表前向的最大值，h为已得K/T后完整D0/D1投影，L为加载/初始化/身份核验；s_full/r_full/s_infer/r_infer含保存恢复身份/IO，均用本次H实际有限正测量，同类取最大。公式：

    T_train = 288*(t_A+t_B)
    T_eval = 1446*v + 36*h
    T_IO = L + 2*(s_full+r_full+s_infer+r_infer)
    T_projected = 1.25*(T_train+T_eval+T_IO+1800秒) <= 28800秒

1446前向=528个A诊断群+600个B诊断/残差群+312个两端点三次52群评分+6个A出生全表；36为6轮×6缓存残差。1800秒明确预留给许可合表扫描/token检查、两次校准、固定完整指标/重采样、旧结果读取、独立保存结果分析和小IO，不冒称已测。若实现多出前向/大IO，需计入投影并接受受影响实现审查，不能隐藏或砍诊断挤预算。

以已保存旧原生G时间作建议量级，机械代入同公式为18624.059300秒约5.173350小时；来源为reports/documentation/20261015/balanced_pooling_repair/qualification/gpu/attempt01/result/result.json的measurements。此不是新H实测/资格或预计完成承诺。GPU通过后用H本次实测重算，投影过8小时即停报，不自动扩大额度。

### 磁盘与生命周期

每端点最多一份临时完整Adam状态，完成恢复并留身份后释放；保留A/B两推理权重及两Memory到结果收尾，B沿已恢复的A对象继续。新原生实际大小W_full/W_infer代入：

    W_projected = ceil[1.1*(W_full+2*W_infer+2GiB)] <= 10GiB
