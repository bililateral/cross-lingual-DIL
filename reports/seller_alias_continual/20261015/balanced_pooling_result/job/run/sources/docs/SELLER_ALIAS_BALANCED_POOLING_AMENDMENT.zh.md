## 2. 有限求解：只增加固定终点的Q验收

保留原FP64 log-domain Sinkhorn、零势、双中心化、完整行列更新、规范平移、可行化算法和4096上限。设`p_error`为原始P双侧最大残差，`q_error`为Q双侧最大残差，`checked_gap=max(dual-primal,0)+eps_fp`，`safe`为原全部非有限、负质量、Q非负和显著负gap检查通过。

```text
O = safe AND q_error <= 1e-12 AND checked_gap <= 5e-9
         AND p_error <= 1e-10
T = safe AND q_error <= 1e-12 AND checked_gap <= 5e-9
         AND p_error > 1e-10
         AND actual_iteration == SOLVER.maximum_iterations == 4096
accept = O OR T
```

O/T互斥，第4096次满足O的块仍算普通接受。第1—4095次及所有旧成功路径继续原计算／冻结已收敛块；`maximum_iterations=1`等故障测试不能因局部循环结束触发T。T只接收同一次实际计算的Q和`mu+primal`；不另跑隐藏求解、沿用旧计划、填常量、改P日志或把P替换成Q。不通过即失败，不跳块、退回S/G、裁剪／缩放logit、加warm-start、增加迭代或换求解算法。

| 保留要求 | 数值及含义 |
|---|---|
| Q可行性 | 非负，两侧最大绝对残差≤1e-12 |
| gap | 原显著负gap拒绝；`checked_gap≤5e-9`；原`eps_fp=256·eps64·(1+max|W|+max|a|+max|b|)`不改 |
| 独立内部值 | FP64绝对误差≤1e-8 |
| 包络梯度／计划 | 相对独立最优计划的全块L1误差≤2e-4，包含FP32转换 |
| 对外FP32值 | 误差≤`1e-8+1e-7·max(1,abs(F_ref))` |
| 实际VJP | 使用返回的Q，`upstream[:,None,None] * Q.to(input.dtype)`；不是对有限迭代程序精确求导 |

**变的是P≤1e-10不再是第4096次所有成功的必要条件；没有放宽上述输出误差。** 精确可行Q和精确算术下，对偶上界不要求中间P先可行，且`F*-J(Q)=KL(Q||P*)≤D-J(Q)`。近可行Q会有边际残差与势的乘积项及浮点误差；原eps_fp不是严格区间证书。独立资格仍必要，不能把实数不等式解释为任意浮点输入或整段训练轨迹的统一精度保证。

新求解版本固定为`log_sinkhorn_terminal_q_v1`；原`log_sinkhorn_round_v1`继续标识旧结果。原数值阈值和tau保持，policy与`SOLVER`严格一致。三臂新保存身份均来自本次新来源；旧模型／Memory／回执不改名重贴为新版本。

新启动器从本次包装开始记录唯一开始时间／绝对截止时刻；读取gate／policy、加载、资格核对、正式读入、求解、训练、诊断、保存恢复、评价、bootstrap和作业内收尾均计入。shell的TERM等待和最多5秒KILL宽限必须包含在67971秒内：按同一截止时刻计算剩余timeout，先扣终止宽限及已耗包装时间，不在剩余额度后额外加5秒。预算为0或不一致则在正式读取前拒绝。保留原磁盘写前reserve、显存／RSS门，不增通用计费服务。
