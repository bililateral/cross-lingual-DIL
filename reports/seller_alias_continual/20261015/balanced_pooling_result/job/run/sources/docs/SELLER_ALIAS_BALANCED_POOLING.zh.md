## 1. 问题、三臂与主张边界

检验以记录匹配的熵正则最优值替代均值后，整套学习系统能否改善自然账号的未见群排序。主要问题为学习B后旧域A的MAP收益，同时报告B能力、首阶段获得能力及概率质量的代价。完整S必须保留其A0／A1监督、历史监督和出生目标保持。

令某账号对的跨记录logit块为有限实数矩阵K∈R^(n×m)，n,m∈{2,…,8}；U_ij=1/(nm)，r_i=1/n，c_j=1/m，tau=1固定。三臂只改变下述评分函数，并将其贯穿自己的完整路径：

| 臂 | 每个账号对的评分 | 直接比较及能支持的解释 |
|---|---|---|
| S | S(K)=mean(K) | 保留现有完整S实际计算路径，是主要内部对照 |
| G | G(K)=tau·[logsumexp(K/tau)−log(nm)] | G−S检验不加双边际的普通非线性择优是否有用 |
| F | F(K)=max_{P≥0,P1=r,Pᵀ1=c} {〈P,K〉−tau·ΣP_ij log(P_ij/U_ij)} | F−S检验完整候选系统；F−G检验固定其余设置后双边际约束的条件性系统增量 |

G、F均含完整熵项／归一化，不用仅〈P,K〉替代F，不另加可学习温度、边际、门控、正则或教师。tau=1并非尺度不变；本轮不对K作改变目标的缩放、截断或标准化。

同一K上S≤F≤G≤max(K)，所以H只能表述为：相对G限制集中择优，并希望相对S的交互奖励更有利于真同控账号。双边际不保证可靠身份覆盖，单个高分、模板、噪声以及A1共同来源仍可获奖励；F也不直接保证降低异控分数。各臂学习后的K不同，不能把同K不等式当成训练结果。OT构件已有先例，本轮属于任务适配／机制比较，效果与论文贡献分别判断。

## 3. F的有限求解、误差和失败语义

### 3.1 固定求解器与返回值

只实现本轮2—8条记录块所需的FP64对数域Sinkhorn，不引入外部OT库、通用求解平台、多求解器选择或跨调用warm start。所有训练、教师投影、诊断、校准、预测和恢复后评分调用同一个函数及同一配置。

先作精确等价的加性消去：`mu=mean(K)`，`W_ij=K_ij−rowmean_i(K)−colmean_j(K)+mu`。均匀边际下`F(K)=mu+F(W)`且最优P相同；这不是改变tau或将logit重新归一化。显式包络反向直接返回原K的计划权重，不对一个不完整的中心化图另外求导。

从a=b=0开始，`log P_ij=log U_ij+W_ij/tau+a_i+b_j`。一次迭代严格指一次完整行更新及一次完整列更新：

    a_i = log r_i − logsumexp_j(log U_ij + W_ij/tau + b_j)
    b_j = log c_j − logsumexp_i(log U_ij + W_ij/tau + a_i)

每个完整迭代后检查；上限4096个完整迭代／块。可对同形状块作确定性批处理，不跨块改变结果；收敛块冻结，未通过的块继续。用a减其均值、b加同一均值的规范化防势漂移，log P不变。不能仅以“已迭代20次”或loss稳定返回成功。

为同时约束可行性、值和包络近似，只在这个小块函数内部做一次可行化与一个标量对偶差检查：P先将超出r的行向下缩放，再将超出c的列向下缩放，得到P''；用剩余行／列质量的外积除以剩余总质量补齐，得Q。剩余总质量为零时直接用P''，不得除零。该局部操作采用[Altschuler等原论文Algorithm 2](https://proceedings.neurips.cc/paper/2017/file/491442df5f88c6aa018e86dac21d3606-Paper.pdf)的可行化结构；它解决本轮有限计划非可行的具体缺口，不建立独立认证系统。零质量熵项按`0 log 0=0`，不得加任意epsilon改变目标。

用可行化前的log势计算上界，用可行化后的Q计算下界：

    primal = <Q,W> − tau·Σ Q_ij log(Q_ij/U_ij)
    dual   = tau·[Σ exp(log P_ij) − 1 − <r,a> − <c,b>]
    gap    = dual − primal
    eps_fp = 256·eps64·(1 + ||W||∞ + ||a||∞ + ||b||∞)
    gap_checked = max(gap,0) + eps_fp

eps64=2^-52。eps_fp是明确的工程浮点保护量，不冒称区间算术证明。gap为负时只有绝对值≤eps_fp才可按舍入零处理；更负则失败，不用`abs(gap)`掩盖方向错误。可行化的行列剩余质量也只允许eps_fp以内的舍入负值置零，更负则失败，之后仍须复核Q的全部边际。Q非负检查、行／列质量复核、全部有限检查都必须通过。

| 量 | 固定接受条件 | 用途与界限 |
|---|---|---|
| 原P双边际残差 | 两侧逐项最大绝对误差≤1e-10 | 保证求解先接近约束；单独不构成精度依据 |
| 可行化Q | 非负；两侧逐项最大绝对误差≤1e-12 | 数值上落实可行性，不能只检列边际 |
| 受保护对偶差 | gap≥−eps_fp且gap_checked≤5e-9 | 同时检查目标值和计划质量；不能只报边际PASS |
| 独立参考的内部FP64值误差 | 绝对误差≤1e-8 | 资格样例逐项确认上述工程阈值实际有效 |
| 独立参考的原K梯度误差 | 全块L1误差≤2e-4 | 比较Q与独立P*，包括FP32反向转换 |
| 对外FP32分数误差 | ≤`1e-8+1e-7·max(1,abs(F_ref))` | 单列转换误差，不要求FP32达到1e-8绝对精度 |

在精确可行与精确算术下，`F(W)−primal=tau·KL(Q||P*)≤gap`，Pinsker给`||Q−P*||1≤sqrt(2gap/tau)`；5e-9对应1e-4的理论计划误差量级。实际浮点仍须通过独立值／梯度参考，不把有限残差、eps_fp或该实数不等式写成机器级严格证书，也不把2e-4局部梯度误差解释为整段训练轨迹误差界。

返回值为`mu+primal`，包含熵项；自定义包络反向为`upstream·Q`，不反传有限Sinkhorn／可行化迭代，不将Q断开后仅凭其存在声称精确梯度。它是理论最优值梯度的受控近似，一般不等于有限停止程序自身的精确导数。S和G分别用原均值导数与log-mean-exp的softmax导数。

### 3.2 不收敛和可复现范围

任何块非有限、非法形状、不能按上述舍入规则处理的负质量或显著负gap立即失败；边际／值条件未达时继续迭代，到4096次仍未通过则失败。失败均停止受影响资格／正式作业，不退回均值/G、不沿用上一个计划、不跳块、不把未收敛当近似成功、不调整tau或放宽阈值。有限实数输入不保证在本预算内收敛。该实现无法按阈值与资源要求资格通过时，先报告具体反例和代价，再决定是否修订合同。

正常只在现有更新／诊断／端点记录中累计调用数、最大迭代数、最大原边际／Q边际误差、最大gap_checked、失败数和数值配置身份，不逐块存储P。故障只留本次允许群的UID、账号对索引、形状、阶段／角色及数值摘要；正式K片段不自动外发。资格手写完整矩阵及输出可留。无新的长期计划缓存、教师计划或摘要Memory。

1. 数值参考不用同一Sinkhorn重跑当独立证明。2×2用`mu+tau·logcosh((a+d−b−c)/(4tau))`及解析P；2×m／转置用列约束消元后的一维单调二分独立参考，m=2…8：令d_j=(K_1j−K_2j)/tau，解`mean_j sigmoid(d_j−c)=1/2`，c的初始夹区为[min d,max d]，缩到宽≤1e-13（d全同直接取该值），再以`P_1j=sigmoid(d_j−c)/m`、`P_2j=1/m−P_1j`算值及梯度；8×8置换对称块用解析解。全部n,m=2…8另用一个固定非对称手写矩阵族检查边际、转置、行列置换、加性消去、S≤F≤G及FP32转换，不增加随机搜索／超参数网格。
2. 明确包含零／常数、纯行列加性、2×2覆盖／单行／孤立高分、非方阵，以及外审指出的20次截断风险形状。独立参考值／P达到§3阈值；参考中心差分步长1e-5只核对平滑手写点，不以近top5换序的总损失差分证明求解精度。故意将最大迭代压为1等故障参数只用于确认非收敛必失败，不能混入正式policy。
3. 轻量模型的单图参考与实际512分块VJP相互核对；S原值／梯度／更新保持原路径，G/F在已知非退化样例有对应差异。此处用每账号两条记录的手写群，F由2×2闭式组成直接autograd参考；这些特殊块的实际Q须达到相对解析P*的L1误差≤1e-7，再对目标、proxy／head／encoder梯度及参数更新逐项用atol=2e-6、rtol=2e-5核对。一般矩形块仍按§3的独立值／计划界核验，不从特殊2×2外推整个求解器达到1e-7，也不放宽整网容差掩盖接线错误。

    W_projected = ceil[1.1·(W_full + 6·W_infer + 2GiB)] ≤ 16GiB。

2GiB覆盖六份Memory、盲分数、逐群指标／计数、诊断／统计、日志、冻结来源、资格小证据和编排旁文件；10%为序列化余量。旧W_full=3,904,607,789、W_infer=1,304,377,675机械代入为15,266,193,236字节，约14.217750GiB，仅作建议16GiB的依据。原生临时大型文件先按范围释放，不与正式叠加；若临时写入／原子替换产生第二完整副本，必须先计入实际峰值，不能沿用单份公式。资格10GiB、正式16GiB是不同生命周期，不能同时占满后说各未超限。

每次大文件写入前检查当前占用与保守reserve，持续监控进程RSS、CUDA reserved及本workspace实际输出，不跟随输入软链接遍历数据。每阶段先查实际属主、路径、同作业PID／监听及他人资源；正式单GPU0无其他计算作业、空闲显存≥30GiB、主机可用内存≥72GiB、盘可用≥16GiB且覆盖当次reserve、单CPU有余量才启动。资格核对其10GiB范围。禁止停他人作业或为凑空间自行删旧证据／模型。

未来本合同获准且审查／资格／投影均满足时，只有资源不足才沿用或创建一个一次性监听；先核对同作业不存在重复进程，条件满足仅启动一次，确认正式实际更新后自删Linux监听源码并保留冻结源及回执。监听不得越过数据／审查前提，也不重启失败作业。
