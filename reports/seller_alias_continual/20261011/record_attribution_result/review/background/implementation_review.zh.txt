三、实际目标与梯度路径

3.1 合同中的差异确实进入运算

令 T 为群内所有不同记录的对称分数表；A0 是原账号归属，A1 是按同控连通分量进行的一次记录重分配。q_A(T) 是对应账号袋之间所有跨袋记录分数的均值。令 B_A = BCE(q_A,y) + rank(q_A,y) + 0.5 hard(q_A,y)，D0 = mean[(q_A0(T) − q_A0(T_teacher))²]。

当前群：
  R0：B_A0
  S ：(B_A0 + B_A1) / 2
历史群：
  R0：0.1 B_A0 + 0.5 D0
  S ：0.1 (B_A0 + B_A1) / 2 + 0.5 D0

step28_record_replay.py:130–156 的分支实际只为 R0 建立 A0 列表；R0 不调用带重分配 seed 的 assignment。S 保留原 A0／A1 监督平均，历史蒸馏仍只用 D0。R0 的训练 mse1 字段为 None。公共诊断随后在 eval 中计算 D1 是观测，不是把 A1 监督重新加回 R0 训练。[E3]

LOGIT0.1 沿新 run.update 的专门分支进入原账号模型：首阶段调用 parent.update，后续调用 step28_er_weight.update，历史监督 0.1、历史 logit 保持 0.5，真实历史分支保留计算图。这里 0.5 hard 与 0.5 teacher 是不同项，不能混同。[E4]

3.2 VJP 不是只算表上的损失

实际路径是 run.execute → train → train_stage → update → record.update → backward_group。record_vectors 对标题／描述分别真实编码，FP32 归一化后拼接；pair_table 包含全部 off-diagonal 记录对。account_logits 用账号归属矩阵做袋间均值。backward_group 先建立一次有梯度的 encoder 输出 z；在不保留全部 head 图的情况下得到表值，求 dJ/dT；以叶子记录向量逐块重算 head 并反传，累计 head 参数梯度和 dJ/dz；最后 z.backward(leaf.grad) 将表 VJP 送回真实 encoder。当前与历史各自完成反传后，统一裁剪一次，optimizer.step() 一次。[E3]

因此，源代码没有把 proxy 表当成最终可训练参数，也没有在两群之间提前 Adam。删除 leaf 到 z 的最后一次 VJP 会断开 encoder；删除块内 backward 会丢失 head／记录向量梯度；把两群分别 step 会改变实际 Adam 次数及更新值。下面的全参数梯度／更新比较和原生探针有能力区分这些改动，而不是只比较一个损失浮点值。

3.3 独立参考与反例的强度

包内新测试 38–77 行采用未分块、完整保留图的 head 计算，并用 literal_scores 显式遍历跨袋记录均值，与正式分块 VJP 比较损失、全部参数梯度及一次 Adam 后参数。它重用既有 assignment 和 B 定义，因此不应称从标签生成到所有损失组件都完全独立；其独立性集中于池化计算方式、完整 autograd 与 VJP／分块更新路径。既有 C/S 数学和 A0/A1 区分证据可在未变部分复用。[E3、E9]

新测试 79–103 行会让 R0 任何 A1 请求直接抛错，并检验历史 S−R0 的表梯度等于 0.05·∇(B_A1−B_A0)。固定手写表的差异非零；把关键重分配监督替换成零差异必须失败。这是有区分力的反例，不是“任意两份相同实现相等”。[E9]

本轮另以 NumPy 显式建立 378×1540 的跨袋均值矩阵，并独立写出 BCE、逐查询 rank、已知 top5 hard 的值与解析梯度；使用包内不变手写群构造器，仅输入固定合成分数／teacher。当前 S−R0 的梯度恒等式最大误差为 1.735×10⁻¹⁸，历史为 6.069×10⁻¹⁹；两种情形各做 8 个方向、两臂合计 16 次有限差分检查，最大误差分别为 1.415×10⁻¹⁰ 与 1.974×10⁻¹¹。遗漏重分配监督造成的最大表梯度差分别为 0.01087849、0.001087849，明确非零。此核对是数学反例，不是 Torch／BGE autograd 实测。[E11]

将直接提供的 ORIGINAL_CS_record_replay.py 与本轮文件按 AST 定义逐一比较，只有 objective 改变；record_vectors、assignment、pair_table、account_logits、backward_group、update、reference、score 和 Memory 等定义相同。新 objective 的 C/S 分支保留原计算式，只加入 R0 选择。共同诊断源码与旧原生回执绑定的文件逐字节相同。故复用已有不变运算审查合理；本轮仍重新读了实际调用、R0 分支、首阶段编排和新资格程序，并未用旧“审过”代替这些增量审查。[E2、E3、E6]

四、起点、teacher、供给、数值和公平性

4.1 两个未训练架构，九条独立训练路径

train 在“顺序×臂”内重新加载模型、建立 optimizer、把 memory 置空，再实际执行三阶段。记录架构 R0/S 从同一未训练参数／optimizer／RNG 起点开始；LOGIT 是另一种头和账号汇总架构。实际保存两份未训练盲起点：record 和 LOGIT0.1。共享的是同一架构的未训练起点，不是 R0/S 的首阶段训练结果。[E5]

R0 与 S 的首阶段分别发生 288 次更新。checkpoint 在各自当前模型下为自己的新保留群生成 teacher；后续路径从自己的 Memory 延续，旧幸存 teacher 保持出生时分数，不借另一臂的首阶段或 teacher。finalize 为兼容旧统计函数使用的 stage1 命名键置于各臂独立字典中；这不构成物理训练状态共享。[E5、E7]

4.2 当前／历史供给和实际日程

每阶段当前 48 拟合群，按固定顺序和种子做 6 轮，一轮每群一次。12 校准群只用于该阶段的正斜率映射；60 valid 群在训练期间只供隔离盲评分。历史由最多 6 群 Algorithm R 保留和均匀有放回抽取提供；首阶段没有历史，每个后续更新一次 memory.draw。每个域的 48 群按稳定 UID 输入一次保留器，不能把六轮当六次入库机会。teacher、正文、标签、索引、RNG、计数、校准辅助状态都在序列化 Memory 上受 1 MiB 限制；淘汰群不从旧归档重新取回。[E4、E5]

每阶段编码器日程重启：29 步预热后线性下降，第 288 步为零；head 学习率保持 0.001，完整 Adam 跨阶段延续。所有臂各 2,592 次更新、4,320 个梯度群呈现，合计分别 7,776／12,960。六群历史缓存中每群每阶段期望抽到 48 次，而当前每群出现 6 次，潜在重复拟合风险确实存在且由既定诊断覆盖；这不是本轮已经观察到过拟合。[E4–E6]

新正式入口在模型训练前调用 configure_numerics；共享的显式数值设置、BF16 encoder 前向、FP32 参数／梯度／Adam、梯度检查点、微批与头分块均有代码落点。LOGIT 保留它自己的历史 seed 推导；不要求两种不同表示架构有相同 dropout 张量，就不能据此宣称随机性逐元素跨架构相同。[E3–E5、E8]

4.3 可以支持什么归因

R0−LOGIT0.1 比较记录表示、袋间评分与历史分数表示等组成的系统结构变化。它不能单独回答记录池化、head 维度或 teacher 表示中哪个因素产生收益。S−R0 同时加入当前和历史重分配监督，并通过不同首阶段学习结果改变后续 teacher 与轨迹；它是既定重分配监督策略的整体增量，不能超额解释成“仅历史重组”“仅当前增强”或固定 teacher 下的直接效应。S−LOGIT 是总系统比较。[E1、E3–E5]

两臂即使共享未训练起点，首学能力也可能不同。因此 F_first 或 F 变小不能单独证明最终旧域更强；必须把首学绝对水平、O、N、新学习 G 和逐域轨迹一起看。相同更新数与数据呈现给出了本合同的配对边界；它不等于相同 wall time、FLOPs 或模型参数量。不把新增算力匹配臂自动列为当前前提。

五、162 次诊断、完整恢复与一次开标签

5.1 调用并非停留在文档

train_stage 在每个实际 step%48==0 后调用 diagnostics.capture；9 条路径×3 阶段×6 轮＝162 次。首阶段 capture 读取 fit48 和盲 valid60；后续再读取存活 cache6。fit/cache 只用学习器已经允许持有的标签；valid 只存盲 logit，标签在后续统一开放。诊断结果不驱动选轮、early stopping、缓存选择、teacher 刷新或超参数改变。[E5、E6]

neutral 上下文保存 Python、NumPy、Torch CPU/CUDA RNG，逐模块保存 training 标志，进入 eval/inference，退出后逐模块恢复，包括混合 train/eval 子模块。capture 检查 Adam 计数和 Memory 字节不变。记录额外 D0、D1、交叉项和差异的运算在该中性上下文内进行，没有 backward／step。[E6]

运行时 capture 没有每轮复制全部参数和 Adam 重新比较；不能把该检查表述得更强。合理证据是：实际路径中没有参数更新操作、无训练态 buffer 更新，包内 TinyEncoder 完整 capture 测试比较模型／梯度／Adam／RNG／子模块模式／Memory，再实际做下一次更新并比较；新原生程序将补充真实 BGE 的最大形状前向部件及下一更新逐字节一致性。此组合与用户批准的证据边界相符。[E6、E8、E9]

5.2 阶段保存与恢复

checkpoint 对当前域 12 校准群和全部 60 valid 群盲评分，拟合仅当前域的一个正斜率映射，生成自己的新 teacher，序列化并反序列化 Memory。随后保存完整模型／Adam／元数据，恢复并核验 digest、元数据、RNG，再对全部 12+60 群重算并比较。推理模型另存并按 state digest 恢复；raw、stage-cal、first-cal 及映射保存。临时完整 checkpoint 验证后按既定规则删除，只保留一份当前临时全状态的峰值预算。[E5]

这证明阶段边界所需完整状态在保存恢复路径上得到检查；没有必要把本轮扩成任意进程崩溃、任意文件故障的通用恢复工程。正式未运行，当前也没有 27 份实际项目 checkpoint 可供声称通过。

5.3 盲门与访问顺序

blind_gate 检查 27 个点、两份未训练分数、九条初始化状态、更新／Adam 日程、每轮 group_uid 序列、各臂自身 Memory 的出生来源与幸存 teacher 字节，并重建 Algorithm R 和 288 次历史抽样。还检查三种输出的映射关系、162 诊断的 epoch／阶段／缓存出生域／valid 对齐、epoch6 分数与阶段终点一致等。[E5、E6]

execute 顺序为：来源与资源前提 → train 一次解析 → 全部训练／保存／恢复 → blind_gate → before_valid 记录和预算检查 → valid 一次解析 → 保存统计与诊断评价 → 完整访问账和完成记录。parse_once 在真正 loader 前记一次尝试，失败不隐去、没有自动重试。成功结尾预期 train=1、valid=1、heldout=0、owners=0。[E5]

5.4 CPU 与原生覆盖必须分层

包内全九路径调度测试对昂贵 train_stage／checkpoint 等使用替身，验证独立路径、teacher 来源编排、逻辑点和门控，不能把它写成 CPU 实跑 7,776 更新。另一个测试为各臂真实 TinyEncoder 执行首阶段 288 更新、6 次 capture 和阶段保存恢复；另有三臂后续 Memory／完整 capture／下一更新中性测试。原生程序验证的是 N224/token256 的真实 BGE 更新与中性前向部件；它没有调用 162 次完整 capture，也没有执行正式三阶段全循环。实现和说明均公开了这个范围，未发现用替身冒充正式循环的证据。[E8、E9]

六、保存指标、实际域配对与归因判读

6.1 保存的证据足以回答已限定的问题

collect 对 27 点×raw／stage-cal／first-cal 保存 81 套 60×22 群指标矩阵与混淆计数，再保存两种未训练架构的 raw 矩阵和计数。group_uid、实际域、顺序、臂、阶段、来源及逻辑点映射均可追踪。finalize 从这些已保存矩阵重读，提供逐点／逐域绝对值、群宏、合并混淆计数、两种未训练起点、各顺序结果与三组预定比较。[E7]

22 个指标具体为：AP、梯形 PR-AUC、ROC-AUC、Recall@FPR≤1%；Brier、log_loss、固定 0.5 的 precision／recall／F1／specificity／balanced accuracy／MCC；MAP、MRR、Recall@1/3/5/10、NDCG@1/3/5/10。前一组 AP 是账号对分类 AP，MAP 是逐查询候选排名的平均 AP，两者不能互换。群宏 F1 与合并混淆计数所得 F1 分列，不把其中一项代替另一项。[E7]

主输出角色 primary 对 14 个排序／曲线指标取 raw，对 8 个概率／固定阈值指标取 stage-cal；另外保留全部 raw、stage-cal、first-cal。正斜率映射需保持严格次序和并列。校准是每个阶段模型各自使用当前域 12 校准群拟合；对概率指标比较的是模型加该阶段映射的系统，不能把映射漂移全部归因于 encoder 遗忘。first-cal 只冻结自身首阶段两个参数，不借旧域校准数据重新拟合。[E4、E7]

记 R(o,t,j) 为顺序 o 学完第 t 阶段，在第 j 个到达域上的指标。O 为最终前两旧域平均，N 为第二／第三域刚学完时平均，Z 为最终最新域，A2 为第二域刚学完的能力；还保存 F_first、两旧域平均遗忘 F、新学习增益 G、最终三域平均 final_all。所有量都按既定三个顺序等权。对 Brier／log_loss 的遗忘和增益方向做相应反号，避免把“损失变小”写成遗忘恶化。特别是本轮 R0/S 首阶段不同，必须保留首学水平与最终绝对值。[E7]

6.2 配对单位是实际域中的整群

既有统计函数先建立形状 (3 顺序, 3 实际域, 20 群, 22 指标) 的加权字段，按实际 A/B/C 映射到各顺序的到达位置。PCG64(20260930) 生成一次 (5000,3,20) bootstrap 索引，跨方法、顺序、阶段、端点共享。差值先在相同群相减，再用该索引汇总；同一群在多个顺序出现不会变成新增独立样本。95% 区间使用线性分位数。[E7]

本轮独立检查执行了实际 collect／finalize 的未修改函数体，输入全部为手写群和分数。由于完整入口导入需要本环境没有的 Torch／psutil，只通过 AST 抽取纯函数，注入其原纯函数依赖；没有因此执行或声称执行完整 train／execute／blind_gate。独立参考直接按实际域逐项索引，核对 3 比较×4 角色×O/N×22 指标×6 个标量（均值、三个顺序、两个区间端点），共 3,168 个标量，最大差 3.504×10⁻¹⁶。刻意倒转比较臂的群对应时，bootstrap 值最大变化 0.11356075，说明这个输入有能力暴露错误配对，而非用完全相同群掩盖错误。[E11]

此检查没有为 22 个已审指标重新建立另一套定义。它重点验证本轮保存、重读、角色选择和 O/N 归因组合；其余既有指标的定义继续沿用直接源码与既有审查证据。不能把该项 PASS 说成重新独立验证了所有历史统计研究。

6.3 O 与 N 分别判断，保留代价

map_interpretation 对 O 和 N 分别使用“下界>0”“上界<0”“其他”三分规则。跨零、恰好触零都返回“方向未确定”；没有等效、非劣效或事后容忍度分支。finalize 没有把多组开发区间合并成一个 overall passed；程序的统计完成状态也不是科学成功状态。[E7、E11]

因此，O 正向而 N 负向表示保持收益和新学习代价并存；O 正向而 N 跨零，不能写成“提升旧域且没有新域损害”。O/N 均跨零也不能证明两方法等效。逐域、Z、A2、F/G、概率和固定阈值取舍必须随结果披露。区间条件于固定 s0、固定已复用开发数据和三个循环顺序，不覆盖重新训练总体或任意真实域迁移；不把辅助多区间当总体多重检验通过，不追改历史五项／23 项。

6.4 过拟合诊断的可解释范围

诊断保存每轮 fit48／cache0或6／盲 valid60 的 MAP、R@5、log_loss；开放 valid 后按相应实际域评价，并保留缓存出生域、D0／D1／交叉项等轨迹。第 1 到第 6 轮的比较把训练改善、留出恶化和 gap 扩大并列；log_loss 反号后与排序方向一致。cache 不存在时返回 N/A，不把它填成零损失。[E6]

本轮用非恒定手写 6×48×3 和 6×20×3 曲线独立重算相应区间，最大差为 0；已检查明确过拟合迹象与空缓存情形。该程序可标记“有相应迹象”，不能将未满足三条件写成“无过拟合”，也不能单独区分有限样本波动、目标冲突、域变化和记忆化根因。log_loss 延续已审的概率裁剪定义（1e−15），不是无界 logit BCE；不在本轮静默替换定义或阈值。[E6、E7、E11]

七、新原生资格：实际将检查什么，尚不能声称什么

7.1 程序确有三臂真实更新，不是只打印配置

新 verifier 的 native 为三个臂分别加载 BGE、显式设定数值行为，检查梯度检查点／BF16，构造当前和历史手写最大群：28 账号×8 记录＝N224，标题／描述共 448 条文本，每条 tokenizer 长度确为 256，不允许截断。每臂先在 eval 下生成一个手写 teacher，随后真正做一次首阶段更新，触发首个 Adam 状态分配，并检查一个真实 BGE query 权重和两层 head 权重发生变化。[E8]

之后显式把 Adam step 设为 288，保留刚才一次真实更新生成的矩。这是手写延续夹具，不是完成 288 次训练的声称。程序保存完整模型／Adam／梯度／RNG／各模块模式，实际做一次当前+历史配对更新到 step289，并检查 BGE 与两层 head 有有限非零梯度且参数改变。[E8]

恢复完整起点后插入两个最大形状群的中性评分和保存，检查全部模型／梯度／Adam 摘要、RNG、混合模块模式不变，再做同一次真实配对更新。equal_state 对模型、Adam、梯度张量按 uint8 逐字节比较，另比较后续 RNG 与损失行；参数／梯度／Adam 两个矩必须保持 FP32。每臂是一次首更新加两次配对更新，即全部计划 9 次真实更新、15 个梯度群呈现。[E8]

7.2 LOGIT 对照是独立旧调用／种子路径

LOGIT 的 baseline 使用 old_numerics 的历史显式设置，并在 verifier 中直接写出旧 step28_er_weight.update 调用和两条 seed 推导；插入诊断后的 repeat 使用本轮 run.update。它检查两个有效设置字典一致，且全状态／梯度／后续 RNG／损失相同。R0/S 则从相同完整起点比较插入前后。这比只检查配置字符串、fresh Adam 或几个 probe 数值更有区分力。[E8]

仍须按真实覆盖范围报告：这不是完整阶段学习、完整 capture 或正式数据测量；它是 CPU 已测调度／capture 之外的真实 encoder/head、首个 Adam 分配、手写后续 Adam 状态以及最大形状前向部件核验。当前未执行，不能提前填入 equality_counts、峰值或 PASS。

7.3 历史 R1 没有被隔离

背景 R1 中旧／新 C 和 S 的 27/27 输出一致，而 LOGIT 为 0/27；初始化等已对齐，但差异已在 step1 梯度范数出现，早于首个 step48 诊断，因此“全部由第一次诊断引起”不能成立。旧入口显式设置与当时五臂入口缺少配置调用／有效值记录有关联证据，却没有建立唯一数值根因。[E10]

既有数值补核实际为小形状 C/S、fresh Adam，不能补写为本轮 LOGIT 最大形状延续核验，也不能隔离历史 R1。当前显式配置与本轮新原生旧调用对照解决的是今后的可核查运行条件；不修饰旧结果，不重开已关闭历史全部实验。

8.2 原生程序采用的公式

每臂纯前向采用 max(最大群评分秒数, teacher 源秒数)。训练项为各臂 4,320×配对更新秒数/2，再加 9×max(0, 首分配秒数−配对秒数/2)。时间上再加 3,600 秒杂项预留与 18,144 群的小数组写盘代理，整体乘 1.25。存储为 1.1×[9×三臂参数字节之和 + 3×最大臂参数字节 + 2 GiB]，对应 27 个推理模型、至多一份当前完整模型／Adam 和杂项余量。[E8]

3,600 秒覆盖加载、哈希、CPU 指标／bootstrap、校准及其余保存恢复等未逐项实测开销。小数组写盘代理不是全模型 checkpoint 吞吐测试。25%／10% 余量和旧最大形状换算是计划假设，不是数学运行时上界；没有发现遗漏一个整套训练或诊断循环的数量级缺口。新原生采样、正式预算检查和 watchdog 的实际资源停止行为仍是必要既定前提。若新投影超界，按现有 gate 停，不偷偷减少诊断、缩短日程、增加容量或自动重试。[E5、E8]

8.3 RD-P1：规划数字可复算性瑕疵（低影响、非阻断）

具体位置：new/implementation.zh.txt:33；计算路径：step28_record_attribution_verify.py:160–169；开放输入：background/FIVE_ARM_native.json 的 LOGIT0.1 和 record 测量。按照声明的机械换算，将旧 record 条目（旧 C_plus 实测）同时代入 R0/S，而非称为新的两臂实测。

十、建议与 OUT_OF_SCOPE_OVERDESIGN 的具体边界

合理但不新增前提：
（1）最终结果摘要把两组主要比较的 O/N MAP 方向放在同一表中，旁列实际训练／评分／产物成本；不只摘正向一列。现有统计与 runtime 字段足够。
（2）报告 F_first/F 时同时给出首学绝对值；把 stage-cal 与 first-cal 的差异按校准系统解释；过拟合用“有／未见相应迹象”，不当作排除证明。
（3）新原生实测后直接替换规划摘要中的旧测量估计，并保留首分配、paired、source、eval 和投影分项。校正文案 RD-P1，不改冻结包。

下列主张本轮不成立为自动阻断：
（1）“没有新研究创新性或单因素唯一机制保证，不能运行。”本轮是既定诊断实验；S−R0 的联合干预边界已明示。
（2）“必须加多 seed、另开 test、增加真实数据或六个全排列。”这些可以是后续独立研究选择，不是当前授权。
（3）“必须把参数量／GPU 小时严格配平，再设更多结构和 teacher 对照。”当前允许的是同数据与更新呈现的系统比较，代价单列。
