# 记录模型与重组监督：三臂归因实验合同

2026-10-09。用户在三臂归因建议后明确回复：“那就按照你说的继续吧，有细节需要澄清的就问我”。随后针对本合同具体范围确认“同意上述预算与读取范围（推荐）”及“按归因诊断分别判读（推荐）”。本轮为 LOGIT0.1、去掉重组监督的记录模型 R0、原 S，s0、ABC/BCA/CAB，共 7,776 次更新；新增预算、train／valid 各一次及归因判读均已确认。完成受影响实现、必要核验和网页外审／主审后执行正式实验；五臂旧许可和本次数值修复免审均不转移到本研究。

## 1. 要回答的问题

原 C/S 相对 LOGIT 的差异同时包含记录表示／配对结构和重组监督，不能据旧比较判断哪一部分起作用；C−S 没有建立原主问题所需的主要旧域增量，C_plus 是已关闭的固定配置负结果。本轮拆开前两个因素，为下一步方法设计提供证据，不将消融本身包装成创新算法，也不承诺本轮解决整体研究问题。

研究对象仍为：有限历史训练信息下，依次学习新卖家群体，并保持对旧分布未见卖家的候选排序／基础识别。继续使用已选 BAAI/bge-large-zh-v1.5（revision 79e7739b6ab944e86d6171e44d24c997fc1e0116）；“历史目标”是该路径过去保存的数值评分，不是另一个预训练模型。

固定两个主要比较：R0−LOGIT0.1 回答整套记录表示及评分结构相对旧账号汇总系统的效果；S−R0 回答加入同控重组监督的增量。S−LOGIT0.1 是预先列出的系统总差异。后者不能证明更复杂的方法更有效，前者也不是只改变一个池化算子的严格单因素实验：头维度、函数族、历史目标表示、计算量及跨架构 dropout 路径都有区别。不增加计算量匹配对照、纯 SEQ、C、C_plus 或 S_strong。

## 2. 三臂实际计算

继承[原 C/S 合同](SELLER_ALIAS_RECORD_REPLAY_PILOT.zh.md)和[LOGIT0.1 合同](SELLER_ALIAS_LOGIT_LOW.zh.md)中本节明确采用的输入、优化器、损失、记忆和评价定义。B 为 BCE＋query-rank＋0.5 known-top5-hard。A0 是记录仍属于原账号；A1 是仅在同控连通分量内打乱完整记录、按原账号条数重新分配。B0=B(A0)，Bbar=(B(A0)+B(A1))/2。D0 是当前模型与本路径保存的历史评分在原分组下的 378 项 raw logit 均方误差。

| 臂 | 当前群监督 | 历史群监督与评分保持 | 结构 |
|---|---|---|---|
| LOGIT0.1 | B0 | 0.1 B0＋0.5 D0 | 原账号均值／标准差表示及原配对头 |
| R0 | B0 | 0.1 B0＋0.5 D0 | 原 C/S 的记录表示、记录对头与账号汇总；训练不构造 A1 |
| S | Bbar | 0.1 Bbar＋0.5 D0 | 与 R0 完全相同的记录结构，沿用原 S 的重组监督 |

首阶段没有历史项。后两阶段每步当前与历史各一群，梯度累加后一次 clip=1、一次 AdamW；不按监督视图数额外增加优化器更新。R0 不计算两份相同 B0 再平均，不把 A1 的日志存在当成增强生效。S 的两视图共享同一次 live encoder 表示与记录对表，监督平均而非相加翻倍。记录表 VJP 继续从损失经 dJ/dK、分块头、dJ/dZ 回传 live BGE；标题／描述分别归一化后拼接除以 √2，2,048 维记录表示，头 4,096→128→1；LOGIT 维持原 4,096 维账号表示、8,192→128→1 头。

R0/S 使用相同完整记录表 Memory 格式、同样六群和 1MiB 上限，仅 D0 进入历史保持目标。保留完整表是为了使 S−R0 只切换重组监督，并复用既有记忆实现；不是声称 R0 需要使用所有表项，也不据本轮宣布该记忆表示最节省。两臂各自在自己的阶段末产生新留存群的历史目标，存活旧目标不刷新，淘汰群不从档案恢复；不能共用已分化模型的目标。LOGIT 仍保存原 378 项账号分数。

## 3. 起点、供给和实际工作量

三臂均从同一已选 BGE 预训练归档重新开始三阶段，不复用旧训练权重。R0/S 头结构和初始化逐位相同，但首阶段监督不同，必须分别完成首阶段，不共享已训练的 S 首阶段模型／Adam／Memory。三个顺序的未训练同架构起点相同；跨架构只要求同 BGE、既定 seed 和各自固定头，不伪称完整参数或 dropout 张量逐位配对。

沿用 initialization=20260909、current schedule=20260918、memory=20260930，s0 及 ABC/BCA/CAB；保留各自现有命名 dropout 流，R0/S 不以臂名改变随机流。当前群顺序、历史群抽样和模型无关 Algorithm R 成员在三臂配对。每阶段每域 48 fit 群、六轮、288 更新，Adam 连续到 288／576／864；阶段学习率重按原日程。

总计 3臂×3顺序×3阶段×288＝7,776 物理更新，12,960 次梯度群呈现，27 个物理／逻辑阶段状态，162 个实际 epoch 诊断点，不存在 shared 首阶段别名。另按两个未训练架构各保存一份 60 群 raw 盲预测，R0/S 共同引用相同记录起点；这是起点观察，不多训练路径、不选初始化。每个阶段保留本路径当前 12 校准群的映射、首域固定映射、全 60 valid 的 raw／stage-cal／first-cal 分数。

所有实际执行入口在载模前调用公共 configure_numerics 并保存生效值：deterministic=True、warn_only=False、CUDA matmul TF32=False、cuDNN TF32=False、cuDNN benchmark=False，Python 启动前 CUBLAS_WORKSPACE_CONFIG=:4096:8。原生核验与正式运行都记录；不靠模块导入的副作用。不以本轮新结果修补历史 LOGIT R1 或声称已隔离其根因。

## 4. 数据和三种权限

固定数据为 reports/seller_alias_continual/20260910/expression_generation/20260910_150500/data，每域 48 fit／12 calibration／20 development-valid。模型输入仍仅屏蔽后的标题和描述，全部 2—8 条记录／账号、28 账号／群、最大 224 记录，256 token 上限、microbatch 4、BF16 encoder 和 FP32 参数／头／梯度／Adam；不截断、不将 UID、域或控制者作为模型特征。

- 技术读取：本轮新 train 标签解析尝试一次，由离线调度器按阶段供给，学习器只取得当前 fit 和自身存活记忆，校准器只取得当前域 12 群。valid 文本仅用于无标签前向；全部训练及盲门通过后 valid 标签解析尝试一次。失败也记账。test、owners、Audit、private_custody 为零；不读取旧 Memory 正文来恢复训练，不生成新数据或留出。
- 结果开放：7,776 更新、27 次完整阶段恢复、162 份六轮诊断、两个未训练盲起点及全部来源／预算／分数检查完成后，统一开放一次 valid 结果。先完整保存指标与计数，再比较。不看中途 valid 指标，不选最好 epoch，不提前停止取有利模型。可查看训练损失、fit／缓存诊断和资源，但不据其更改实验。
- 根据结果选择：本轮没有可自适应调整的候选、系数、种子或轮数。三组比较完整报告后结束，只形成后续研究建议；任何下一轮训练另行明确范围。反复使用的开发 valid 与已用基础 test 不会变为独立确认集。

## 5. 过拟合诊断和阶段完整性

实际训练循环每 48 次更新调用保留的通用诊断：A0／eval／无 autograd，当前 48 fit、当前存活缓存（首阶段为零，后续六群）和全 60 valid。fit／缓存保存 MAP、Recall@5 和原评价器的截断概率 log_loss；valid 只盲存 raw 预测，完整结束后统一评价。cache 按实际出生域与对应 valid 比较，缺失域为 N/A；固定 epoch1→6 及全部六点，不把遗忘、欠拟合、校准变化与过拟合混称。

复用通用诊断现有的记录表 D0/D1 残差输出，R0 的 D1 只在无梯度、状态中性的诊断中计算，绝不进入 R0 训练目标。保留它不授予新增比较或选模型权限；不将残差称为梯度夹角或泛化机制证明。诊断须保持参数、已有梯度、Adam、所有子模块模式、Python／NumPy／Torch 随机状态、Memory 成员／目标／抽样状态不变，且不改变下一次实际更新。

每阶段完整保存并恢复 model／Adam／RNG／Memory，在 12 校准群与 60 valid 群逐位核对分数；保留 27 份推理状态和必要科研证据。没有共享首阶段，因此只需一个当前临时完整检查点，恢复核对后即删除该临时文件。阶段权重待后续诊断／复核／审查及恢复依赖消失后，按既有用户要求先留记录再清理；不能只因负结果删除。

## 6. 结果判读

本轮作为归因诊断，不新增一个“总通过”门，也不把五臂原 23 项改为更容易通过的新验收。两个主要比较各以 O MAP（最终两个旧域平均）和 N MAP（后两阶段刚学完的新域平均）并列为主要观察；分别给实际差值、三顺序结果和配对条件 95% 区间。固定 S−LOGIT0.1 为第三个系统比较。旧合同的五项／23 项及历史 false 永远保留，不因本研究改写。

继续完整报告原 22 指标、三个保存角色与 primary、O/N/Z/F_first/F/G/final_all/A2、全部阶段／实际域结果和分类计数；保留 raw 与校准的不同结论。沿用实际域整群配对 PCG64(20260930) 的 5,000 次 bootstrap，各方法／阶段／顺序共用群抽样。区间是给定模型与反复开发数据的条件区间，不覆盖训练种子、生成、选择不确定性；多个辅助区间不称多项独立显著性证据或总体多重检验通过。

| 观察 | 允许的解释及下一步建议 |
|---|---|
| 某端点差的区间全正／全负 | 该固定条件下有正向／负向证据，明确比较和端点 |
| 区间跨零或触零 | 方向未确定；不说等效、无作用或无损失，不据此自动选择更复杂方法 |
| 旧域正向、新域负向 | 存在旧／新取舍；不能说不牺牲新学习 |
| 旧域正向、新域跨零 | 旧域收益有证据，新域代价未确定；不能说已证实非劣效 |
| 两个主要端点均正向 | 两端点在本固定条件下均有正向证据，仍须检查逐域差异及成本；不等于研究问题全部解决 |

R0 有收益而 S−R0 未建立收益时，优先围绕较简结构整理后续研究，但不将跨零当等效。S−R0 有收益时，区分首阶段学习、后续新域学习与保持；本实验同时改变当前和历史监督的重组，不能进一步归因于其中一支。首域起点较低导致 F 看起来较好时必须并列报告绝对表现，不能直接声称改善持续学习。两比较都缺乏稳定收益时保留旧正结果与新差异，重新审视路线。生成器的账号固定风格与重组样本分布差异仅为待证假说，不能事后直接判为根因。

## 9. 失败与收尾
