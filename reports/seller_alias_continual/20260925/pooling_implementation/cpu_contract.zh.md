## 1. 研究问题与依据

研究问题：在固定中文BGE、同控监督、候选池和每次训练更新数的条件下，让模型学习账号内各商品文本的汇总权重，能否相对D改善未参与训练的卖家马甲候选排序？

D已经联合训练BGE和对称账号对评分头，目标已经包含BCE和排序损失。其第6轮拟合／校准／valid的MAP分别约为0.675598／0.499491／0.491119；valid的Recall@5为0.626786。固定均值和总体标准差给每件商品相同权重，未学习哪些商品文本更有助于当前关系判断。上述差距支持继续检验泛化和账号表示，**不能证明均匀汇总就是原因，也不能证明增加注意力一定改善**。[原结果](SELLER_ALIAS_CHINESE_RESULT.zh.md)。

拟议方法采用可学习、对商品排列不敏感的集合汇总。注意力集合汇总有既有研究基础；本文的均匀残差、双通道矩表示和账号同控用途是本项目拟议配置，不能将原论文结果当成本项目效果证据。[Ilse等，ICML 2018](https://proceedings.mlr.press/v80/ilse18a.html)。

本轮只比较D与一个加权汇总配置，解释的是完整汇总配置的增量，包括新增参数及其优化；不单独证明注意力机制、参数容量或某类文本线索的因果贡献。输入商品数仅为2—8，新参数可能过拟合或不能带来提升，阴性结果同样保留。

## 2. 对照与唯一干预

| 项目 | D对照 | 加权汇总候选 |
|---|---|---|
| 编码器 | 固定提交的BGE-large-zh-v1.5，联合训练 | 相同 |
| 商品输入 | 全部商品的屏蔽标题、描述分别编码 | 相同，标题与描述按商品配对 |
| 账号汇总 | 两通道各自均值、总体标准差 | 同维度的加权均值、加权总体标准差 |
| 账号维度／评分头 | 4096维；对称特征8192→128→1 logit | 相同 |
| 训练损失 | BCE＋权重1、温度1的原排序损失 | 相同 |
| 每次训练 | 6轮×144拟合群＝864更新 | 相同 |

每条标题和描述的CLS向量先作L2归一化。设账号有n件商品，配对向量为t_i、d_i，各1024维；候选新增一个所有账号共享的汇总模块：

```text
h_i = tanh(W [t_i; d_i] + b)       # W: 64×2048，b: 64
s_i = w^T h_i                    # w: 64，无输出偏置
a_i = exp(s_i) / sum_j exp(s_j)  # 只在本账号商品内归一化
p_i = 0.5 / n + 0.5 * a_i
mu_t = sum_i p_i * t_i
std_t = sqrt(sum_i p_i * (t_i - mu_t)^2 + 1e-8)
mu_d、std_d 同理
u = L2_normalize([mu_t; std_t; mu_d; std_d])
```

两通道使用同一组商品权重；不得分别打乱标题和描述。0.5是本草案固定的均匀成分与学习成分混合比例，保证每件商品权重至少0.5/n，**与旧持续学习中的两个历史约束系数无关**；本轮不搜索它。评分仅由本账号文本决定，不输入账号ID、商品ID、域ID、商品类别标签、owners或生成器潜变量；ID只作对齐和并列排序。

新增参数为131,200个。W按固定局部随机流Xavier初始化，b和w初始化为0；此时数学上恢复均匀权重。编码器和评分头的共同初态须与同种子D一致；模块初始化不得改变后续共同随机流。有限精度下加权矩与原均值实现的等价误差须用独立手算和真实向量说明，不能声称未经核查的逐位相同。

沿用D的encoder AdamW学习率2e-5、weight_decay=.01；head学习率.001、weight_decay=0。新汇总模块学习率.001、weight_decay=.01；其参数必须显式加入优化器。betas=(.9,.999)、eps=1e-8、foreach=False、全模型clip_norm=1。所有表示汇总和评分头用FP32；GPU编码器用BF16，微批4、非重入激活检查点并保留随机状态，最长256 token且禁止截断。

## 4. 对应用户要求的验收判据

**主要指标为MAP，重点检查Recall@5。** MAP衡量全部相关马甲在27候选中的排序；Recall@5检查人工查看前5个候选时覆盖相关账号的比例。K=5是本轮研究工作点，不冒称已确定真实人工复核预算；同时完整报告K=1/3/5/10。

将MAP绝对差0.01作为本轮最小观察提升，并要求配对95%区间下界大于0。0.01相当于1个MAP百分点，约为原D valid MAP的2%；这是本轮研究推进标准，没有已知业务成本依据。区间要求排除0，**不等于已经证明总体增益至少0.01**。所有“不下降”均指冻结评价中的观察值护栏；完整报告其配对区间，不冒称已证明总体严格非劣效。

用户要求的“基础识别”落实为**同群378个账号对是否同控的区分能力与概率预测质量**：AP、ROC-AUC不得降低；Brier、log_loss不得升高。它们和查询级MAP／Recall@5分别验收，不用排序提升抵消二分类退化。未设允许退化幅度，也不将原D未通过的0.1%／50%自动判定绝对门追认为新门。固定0及训练内校准阈值的全部分类结果、逐域差异照常报告，不能声称四项保护即保证所有操作点或每个域都不变差。

| 阶段 | 事前固定的通过条件，全部须满足 |
|---|---|
| valid开发 | 三配对平均ΔMAP≥0.01，且整群配对条件95%区间下界>0；三个配对各自ΔMAP均>0；三配对平均与预定s0分别满足：ΔRecall@5≥0、ΔAP≥0、ΔROC-AUC≥0、ΔBrier≤0、Δlog_loss≤0 |
| 独立test | 只比较预定s0候选第6轮与原D第6轮；ΔMAP≥0.01且整群配对条件95%区间下界>0；同时ΔRecall@5≥0、ΔAP≥0、ΔROC-AUC≥0、ΔBrier≤0、Δlog_loss≤0 |

valid通过后才能申请test阶段。送测对象固定为s0候选，不根据valid挑种子、择模型、合并预测或重训最终模型。只有test也通过、结果本地主审及适用外审完成，才按用户要求开始设计持续学习。若任一阶段未达到相应条件，保留结果、说明失败位置，重新讨论下一步，不自动继续搜索或补测。

本草案明确选择5000次域内整群配对bootstrap、双侧95%百分位区间、线性分位数插值；valid种子20260925，test种子20260926。valid先对同一群的三个配对差取平均，再按每域20个群有放回抽样；test对固定模型差按每域40群抽样。三域等权，不把28个查询、378个账号对或3×60个种子群观测当成独立样本。报告各域结果、各配对结果和全部预定指标差值；辅助指标区间不作多重比较校正，不用于替代MAP通过条件。

区间条件于固定训练种子、模型、生成数据和校准阈值，不包含重新生成数据、重训随机性或开发选择不确定性。三个训练种子只提供有限稳健性检查。test的独立性来自未用于模型开发的留出群体，仍来自同一合成机制；它不证明真实市场、全库检索、没有相关候选时的能力或新域外推。
