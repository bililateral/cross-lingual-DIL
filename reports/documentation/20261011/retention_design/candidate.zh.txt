C历史保持改进：账号内抽样排序波动候选的完整推导与静态筛查
日期：2026-10-11
状态：已完成本轮静态研究；当前不推荐该候选进入实现或训练。不是已运行的实验负结果，未经本轮网页外审。

一、问题、范围与本轮结论

用户本轮要求：“那就继续研究，先形成一个具体、完整的 C 历史保持机制改进方案，以完整 S 为对照。把运算、更新作用、近邻差异和最小验证讲清楚；如果找不到有依据的机制就如实汇报，有需要澄清的细节就问我。”

目标仍是有限历史信息下，同时学习新群体并保持旧分布未见卖家的候选排序／基础识别。完整S保持为主要内部对照；S已有收益不计为C新增贡献，不预定C必须胜出。本稿承接同目录proposal.zh.txt的第一轮筛查，不覆盖其中已经发生的阅读、判断或历史实验事实。

本轮把一条相对有依据的候选推到可审查的计算与更新定义：利用原账号内部的记录子集，保持“同控候选相对异控候选的平均优势及其波动”。其动机是减少对跨账号混合视图和旧分数逐点复现的依赖。静态分析确认这种波动包含原账号总分未表达的信息，并能通过现有反传路径影响模型；但也找到严格反例：一个受保护比较的平均优势和方差不变时，其子集排序可以从全部正确变成三分之一错误。由这些量构造的保持项在这个比较上完全没有纠正信号。

反例没有证明这类正则化必定降低真实性能，也没有推翻正确的一侧概率界；它推翻的是把“保住均值／方差或它们导出的界”直接称为“保住旧排序可靠性”的较强论证。合理代理目标可以存在反例，不以“必须先证明真实泛化”作为所有候选的入场条件。这里结合直接近邻及尚未补上的任务收益链，判断本候选目前只建立了可计算的统计量与常规正则化适配，未达到用户要求的实质机制贡献。本轮不推荐训练，不把修改常数、再叠加一项约束作为自动下一步。此裁决仅针对这里完整定义的候选及其直接改写，不是证明所有C改进都不可能。

本轮只读获准文档、实现、既有审查与公开论文，进行数学推导和手算；没有连接Linux、读取Memory载荷或新标签、运行科研代码／数值实验、恢复权重、修改训练实现或上传新包。以下公式描述候选应怎样运行，不表示它已经实现或接通。

二、完整S、原C及需要解释的增量

以k表示当前模型的完整无向记录对分数表，t表示该历史群首次存活入缓存时、来源域阶段末eval模型生成的固定表。这里的“教师”只是过去同一种中文BGE模型留下的分数，不是另一种模型或仍可调用的额外网络。

A0为原账号分组；A1为既有同控内重组。B为现行BCE＋query-rank＋0.5×top5-hard，Bbar为A0与A1监督的平均，D0／D1为对应账号分数的均方误差。对同一状态的一次当前群＋历史群更新：

J_S = Bbar(current) + 0.1 Bbar(history) + 0.5 D0。
J_C = Bbar(current) + 0.1 Bbar(history) + 0.25 D0 + 0.25 D1。

S和C原来存的都是完整记录对表；不同之处是如何使用它。S的标签监督也包含A1，不能说细粒度方向完全无人训练。本轮候选以J_S为完整底座，不抽走S的重组监督、不减弱0.5 D0、不冻结BGE，也不恢复C_plus或五臂入口。

第一轮已证明：原分组均值之外确有细粒度方向；跨控制者重组的平均分又可由原分组分数和记录数完全恢复。非零D1不是新信息价值、梯度冲突或泛化收益的证明。原C／C_plus的负结果及三臂归因均保留，不能把下面的假设追认成历史失败根因。

三、候选选择的变化与它能支持的假设

候选只考察每个原账号内部，均匀、不放回地抽取两条完整记录；标题与描述作为一个整体，账号、标签及其他账号记录不变。每账号原本有2—8条记录，抽两条是当前任务允许的最少条数；这是一个明确的设计选择，不代表已经证明两条是最优粒度。原本两条的账号没有此项随机性。

选择账号内抽样的静态理由来自实际生成器：每个账号的偏好、样式在逐商品生成之前确定，记录随后在该账号条件下生成。账号内抽样保留该层条件；把不同账号商品混成一个账号则可能混合原本不同的账号样式。该理由支持抽样扰动更贴近账号内部变化，不证明跨账号重组必然有害，也不证明账号内部变化就是未见控制者变化。

可能的收益链只能写成待检验假设：旧模型在少量缓存账号上学到的、对商品抽样稳定的同控排序规律，包含能迁移到同域新身份的关系线索；后续学习破坏了其中一部分，而完整S未完全防住；只限制有用排序波动的恶化可能比复现全部重组旧分数少限制新学习。这三步尚未得到本项目证据支持，不能把“稳定”直接等同于“正确、可泛化”。缓存中的稳定模板或偶然相关也会满足稳定条件。

四、运算：精确计算有限记录抽样下的均值与方差

以下均以固定的一张k为条件。账号i有n_i条记录，b_i=2，w_i是抽样均值权重：抽中的位置取1/b_i，其余取0。不同原账号独立抽样；同一查询与不同候选比较时，必须共享同一个查询子集。

记e_i=1/n_i的全1向量，P_i=I−11^T/n_i，则：

E[w_i]=e_i；Cov(w_i)=Σ_i=α_i P_i；
α_i=(n_i−b_i)/(b_i n_i(n_i−1))。

这由不放回抽样的单点／双点入选概率b_i/n_i和b_i(b_i−1)/(n_i(n_i−1))直接得到。n_i=b_i时Σ_i=0。

对一个查询q、合法训练二值标签给出的同控候选p、异控候选n，令A=K_qp、H=K_qn为两块记录分数矩阵：

M = w_q^T A w_p − w_q^T H w_n；
μ = e_q^T A e_p − e_q^T H e_n；
a = A e_p − H e_n；
v = a^T Σ_q a
    + (A^T e_q)^T Σ_p (A^T e_q)
    + (H^T e_q)^T Σ_n (H^T e_q)
    + tr(Σ_q A Σ_p A^T)
    + tr(Σ_q H Σ_n H^T)。

μ=E[M]，v=Var(M)，没有Monte Carlo估计误差。将w_i=e_i+δ_i代入M，得到三个线性项、两个双线性项；各δ_i独立且均值为零，除同一查询的两项必须先合并外，各交叉期望为零，即得上式。这里只计算固定有限表上的抽样分布，不估计模型参数不确定性或真实市场错误概率。

μ就是A0下同控分数减异控分数，S的D0已直接约束它；新的候选信息来自v。两块分数各自的方差不能直接相加，因为共享查询产生协方差。等价地，可用行／列均值及双中心矩阵P_q A P_p的平方Frobenius范数计算v；不应构造记录对维度的稠密协方差大矩阵。

每群比较集合T包含全部(q,p,n)：16个查询各有1×26个比较，12个查询各有2×25个比较，共1016个。集合来自已有二值训练标签，不读取owners，不新增身份输入，不从valid选择困难比较。所有比较按1016个平均，筛掉某些教师目标时也不另按剩余数重新放大。

五、把候选写成完整目标，并检查实际更新作用

以下固定一种具体形式用于反对性审查，不列权重搜索菜单，也不把它列为待启动合同。

对t按第四节求μ_t、v_t。仅在μ_t>0时建立目标：
κ_t = μ_t / sqrt(1+v_t)，d_t=1+μ_t^2+v_t；
r(k;t) = κ_t sqrt(1+v(k)) − μ(k)；
R(k;t) = (1/1016) Σ_(q,p,n in T) 1[μ_t>0] [r(k;t)]_+^2 / d_t；
J_trial = J_S + 0.25 R(k_history;t_history)。

方差前的1是固定的1平方logit尺度，避免零方差／零分数的除零和退化漏洞；它是本候选明确选择的尺度，并非有理论保证的最佳常数。0.25也仅使本审查对象完整，不能以它与旧C额外项同系数宣称约束强度或梯度相同。教师均值非正时该比较没有R，继续由完整S训练；没有合格比较时R=0。正部平方在r=0处导数为0，来源表及其筛选、κ_t、d_t全部停止梯度。

μ>0时，一侧Chebyshev／Cantelli界给出P(M≤0)≤v/(v+μ²)。因加入1，μ²/(μ²+v+1)也是P(M>0)的一个更保守下界。R=0的受保护比较满足μ/sqrt(1+v)≥κ_t>0，因此不降低这一特定下界；它不保证实际正确比例不降低。界的这一步可由E[(M−μ−c)^2]=v+c²及事件M≤0时平方至少(μ+c)²、取c=v/μ手算推导，不依赖新增数据。

设压平后的k满足μ=a_bar^T k、v=k^T V k，其中V为固定抽样规则导出的半正定算子。对r>0且μ_t>0的比较：

∂R_triplet/∂k = (2r/d_t) [κ_t V k/sqrt(1+v) − a_bar]。

总梯度还需除1016、乘0.25。第一部分会改变记录贡献的离散程度，第二部分推动同控与异控的均值差；不是只生成日志。k=t时R及其梯度为0；但实际历史分支沿用S的训练Dropout，t来自eval，不能推断真实初次重放的R一定为0。

若实现，R必须接入step28_record_replay.py的objective所消费的proxy表；backward_group先得到完整dJ/dk，再通过每512对的真实评分头VJP把梯度传到记录表示，并通过保留的编码器图回传。不能在R计算前detach当前表，也不能只在observe中计算它。仍然先累加当前／历史群梯度，统一clip_grad_norm=1，然后一次既有AdamW更新，编码器和评分头都可训练。分项梯度非零不保证净更新方向或性能改善，裁剪、Adam状态和其他损失都会共同影响更新。

六、生命周期、信息与资源

首域没有历史群，候选和完整S的实际目标一致。若以后比较，可在新合同中约定每个顺序共享一次真实首域训练及完整model／Adam／RNG／Memory状态；不能把已删除的旧权重当作可用共同起点。

后续每步仍抽一个当前完整群、一个存活历史完整群。当前监督不加R；历史监督、A0蒸馏及A1标签监督保留。历史源表仍在来源域结束、该群首次被Algorithm R保留时产生；幸存源表不刷新，淘汰群的表和任何派生目标随之删除。最终无后续阶段时不额外建立无用源表。不得复用其他历史运行的Memory作为本次学习器的免费先验。

保存恢复仍需模型、优化器、全部随机状态、进度、原始群／标签／槽位、保留与抽取状态及固定源表；新候选的公式身份必须固定。推理沿用完整原账号的记录对评分和均值汇总，不需要Memory、域标签或额外教师。统计目标只依赖分数，不需要把旧表征迁移到新坐标系。

最多6群、全部历史载荷≤1,048,576字节不变。现有源表是FP32上三角，N≤224时最多24,976数，即99,904字节／群，六张最多599,424字节；这只是分数载荷，不是包含文本、标签、索引、随机状态后的总大小保证。

本定义不新增长期统计缓存：每次从当步合法源表派生目标，用完释放。若实现者缓存μ_t／v_t等，必须计入历史预算，不准放进模型buffer后漏计。单群四个长度1016的FP64派生向量就是32,512字节，另有掩码／索引及中间量；每步同时物化的历史派生表示也应保守纳入内存核对，不能以“临时”称为免费。总历史限制必须在新实现中按适用口径实际核验，超限不得自行删样本或改精度来维持比较。

每次仍可复用S已产生的同一张记录表；R不要求额外BGE前向，但会新增源表／学生表的中心化、平方和、1016个比较及反传。按账号块预计算均值和中心化平方范数，可避免枚举最多28^3种三账号子集组合，也避免构造稠密V。纸面主要工作量为O(N²+1016×最大账号记录数)的表运算；不是零计算，也不是墙钟、显存或数值精度已验证。没有本轮资源测量和运行预算。

七、手算支持与反例

1. 原账号总分以外确有信息。
令q有3条记录，p、n各2条，因此p、n的子集固定。K_qn全0，K_qp每行两列相同。当三行都是1时，完整分差为1，抽两条后的分差恒1，v=0。当三行为2.2、2.2、−1.4时，完整分差仍为1，但三种等概率子集的分差为2.2、0.4、0.4，v=0.72。因此v不是A0分数的函数。此例证明信息不重复，不证明该信息能迁移或一定能由实际BGE更新独立控制。

2. 必须使用共享查询协方差。
仍用3、2、2条记录，K_qp和K_qn两块都逐行为−1、0、1。每块的子集均值为−0.5、0、0.5，方差1/6；共享查询使两块在每种抽样下完全相等，所以M恒0、v=0。忽略协方差会错误得到1/3。公式中的a=0及其他中心项为0，给出正确结果。

3. 本候选保护量完全不变，实际子集排序仍可退化。
采用第1例的教师三行(2.2,2.2,−1.4)，学生三行改为(−0.2,−0.2,3.4)，两者K_qn均为0：

                         教师              学生
完整账号分差μ              1                 1
三种子集分差           2.2,0.4,0.4       −0.2,1.6,1.6
子集分差方差v            0.72              0.72
严格排错比例               0                1/3
D0（相对教师）              0                 0
新增R（相对教师）           0                 0

各数可手算：教师平方偏差和为1.2²+0.6²+0.6²=2.16；学生为1.2²+0.6²+0.6²，同除3得0.72。没有利用并列分数或数值容差。教师、学生的μ／v相同，所以κ、d及候选保持项无法区分。其他账号块可保持不变；该例至少给出一个受保护比较上的严格反例，不声称全部S监督或完整群总目标也相同。S的A1标签监督仍可能响应这种变化，不能把它忽略后宣布两个完整网络训练等价。

普通Cantelli正确率下界都是1/1.72≈0.5814；带固定1的保守下界都是1/2.72≈0.3676。学生实际正确率2/3仍高于这两个界，故反例没有违背概率不等式；恰好说明“下界没下降”可以和“真实正确率下降”同时发生。这是本候选的机制局限，不是舍入、实现接线或调大权重能够解决的问题：例中R为0，任何有限正权重都没有作用。

4. 两条记录情形直接退化。
q、p、n均只有两条时v=v_t=0，新增项变成教师原本正确的分差之单侧平方hinge保持。它没有额外商品组成信息，属于既有排序保护的直接形式。该退化不意味着所有群都没有增量，但必须披露其适用边界。

5. 缓存稳定与未见身份仍是两件事。
假设缓存中某商品词或模板恰好与同控关系相关，旧模型依赖它且子集变化也稳定，则本候选会保护该规律；对新身份若相关性不再成立，没有内部机制识别它。此为逻辑反例场景，不是声称实际合成数据已经出现该捷径。均值／方差来自固定有限记录集，没有增加新身份信息，1016比较和大量子集也不增加独立身份样本数。
