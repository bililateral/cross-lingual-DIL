C历史保持改进方案：账号内联合排序响应的收缩保持
日期：2026-10-11
状态：具体静态候选，供方案审查；没有新增实现、原生核验或实验结果，不是执行合同。
主要内部对照：完整S。旧C局部诊断继续停止，既有授权和CPU证据不转用于本候选。

1. 本次交付与判断

用户最新要求是形成以完整S为对照的具体C历史保持机制改进方案，讲清保留信息、运算、真实更新、近邻和最小验证，不再为了分析旧C单独做诊断。本方案直接给出一个候选及其可推翻比较；不把查清旧C根因作为前置任务。

候选要保留的是：历史账号的不同商品记录，对同一组候选账号产生的“联合相对评分变化”及其允许的收缩范围。完整S继续保护原账号平均评分；新增项允许历史记录间的作用重新分配、允许记录差异减小，只处罚超出历史允许范围的联合变化。

例如，过去某账号的两条商品记录分别把同一竞争账号推高2分、压低2分。新模型若改为推高1分、压低1分，账号平均关系没变，对商品组成的依赖变小，本候选可以不处罚。若不同竞争账号的变化被重新拼成历史上没有的组合，则即使各列均值、方差相同，也可能受到处罚。不能为每个竞争账号独立挑一套有利的混合方式。

本轮形成了可计算的单候选，并推导了一个与现有排序代理损失直接相关的有限性质，因此建议进入静态方案外审。尚不能称为已建立实质方法贡献：基础数学属于已知弱最优传输／凸序；一项相关KDConv论文正文尚未取得；旧分布未见身份收益、实际求解成本和神经网络内的作用尚无新实验证据。若外审发现仅为已有机制的直接等价应用，应据此收窄或停止，不因已经写出公式就投入训练。

2. 保留完整S，以及有依据的设计缺口

完整S沿用已选中文BAAI/bge-large-zh-v1.5（revision 79e7739b6ab944e86d6171e44d24c997fc1e0116）、记录对头、原分组与同控重组两种监督、全部记录、六群历史记忆、优化器和既有数值设置。

令B = BCE + query-rank + 0.5 top5-hard；Bbar = [B(A0)+B(A1)]/2。
后续阶段完整S的目标为：
    J_S = Bbar(current) + 0.1 Bbar(history) + 0.5 D0(history)。
D0是原分组下378个账号对评分相对于该路径历史来源评分的均方误差。首阶段没有history项。来源评分由过去的同一中文模型保存；没有引入另一种预训练教师。

旧C是0.25D0+0.25D1，D1要求当前与历史模型在同一同控重分配下给出接近的账号评分。C_plus保留0.5D0并加0.25D1，固定实验未建立所需增量，已撤下。本候选不恢复D1，也不降低完整S的0.5D0；改变的是新增历史约束允许什么变化。

可以从实际目标直接确认的缺口是：对历史输出作对称等值匹配，会同时处罚“当前更依赖个别记录”和“当前较少依赖个别记录”这两类变化。该对称性在数学上存在，但不能据此宣布它就是历史C失败的根因。新候选考察能否只保持必要的联合变化范围，并给新学习留下收缩空间。

与任务的联系来自两层、必须分开：
（1）生成源码先给账号抽取偏好和表达风格，再生成该账号的多条记录。因此研究同账号内记录组成变化有具体结构依据；本候选不需要把不同账号的表达风格假定为完全可交换。
（2）假设共享BGE与评分头若减少对个别商品组成的脆弱依赖，可能把旧关系的识别方式迁移到旧分布的新账号。第二层是待检验的归纳假设，第一层及缓存上的数学性质均不能证明它。

完整S已经有同控重组监督，不能把本候选说成首次利用记录变化或首次学习排序稳健性。它提出的是额外历史保持策略的特定差异。

3. 信息对象与明确运算

输入仅为当前存活历史群的：原记录归属、已允许的训练二元标签、固定来源完整记录对评分表t，以及当前模型的完整记录对评分表k。每群28账号；账号q有n_q条记录，2<=n_q<=8；其余d=27个账号为候选。K是对称评分表，不要求半正定，不把它当作Gram核。

3.1 从记录对评分得到联合相对响应

对查询账号q的每条记录r、每个候选账号j，先对候选账号全部记录平均：
    A_q(k)[r,j] = (1/n_j) sum_{s in I_j} k[r,s]。
I_j为账号j的原记录集合，不从owners或封存身份推导。令P_q为合法train标签给出的同控正候选集合，大小为1或2：
    V_q(k)[r,j] = A_q(k)[r,j]
                  - (1/|P_q|) sum_{p in P_q} A_q(k)[r,p]。
每一行同时包含对全部27个候选、相对于正候选平均分的响应；减去共同平移不改变候选排序，也使该行的正候选坐标平均为0。

令H_n = I_n - 11^T/n。定义：
    m_q(k) = (1/n_q) 1^T V_q(k)，
    X_q = H_n V_q(k)，Y_q = H_n V_q(t)。
m_q是账号完整记录平均后的相对候选向量，已经由D0约束。X_q、Y_q是各条记录围绕这个平均值的联合变化。它们是n_q乘27的矩阵，不是27个互不相干的方差。

3.2 历史允许的变化集合

定义双随机矩阵集合：
    B_n = { W in R^(n*n) : W>=0，W1=1，W^T1=1 }。
两组约束分别要求每条当前记录接收的权重和为1、每条历史记录供给的总权重也为1。候选允许集合为：
    C(Y_q) = { W Y_q : W in B_(n_q) }。

同一个W必须用于全部27列。此集合包括历史各行的任意重排，以及这些重排的加权平均。它保留历史联合变化范围，同时允许收缩；W=11^T/n时结果为0。只有行和约束的任意注意力混合不等价：它可反复使用某一历史行，并不保持历史经验分布的等权份额。

3.3 唯一候选目标

    R_q(k,t) = min_{W in B_(n_q)} ||X_q-WY_q||_F^2 / (27 n_q)，
    R(k,t) = (1/28) sum_q R_q(k,t)，
    J_new = J_S + 0.25 R(k_history,t_history)。

新项只用于抽中的一个存活历史群，以A0定义账号内的变化；完整S在current/history上的A0/A1监督和D0全部保持。0.25为本稿建议的固定单配置系数，采用平均logit平方单位，不由新valid结果选取。它不表示与旧D1或下述对照具有相等梯度强度，不借用旧0.25的成功证据，也不自动授权系数搜索。

推理仍使用原来的完整记录账号评分，没有投影、历史访问或额外教师调用。此机制是训练期间的保持约束。

4. 实际参数更新与小规模求解

4.1 梯度必须接入现有真实路径

令Z_q*=W_q*Y_q为X_q到闭凸集合C(Y_q)的欧氏投影。即使最优W不唯一，最优Z唯一；平方距离对X可微：
    dR_q/dX_q = 2(X_q-Z_q*)/(27n_q)。
来源t、Y、合法标签索引以及求出的Z*作为固定目标；当前k、V(k)、X不能断开梯度。固定投影目标求此导数是包络／投影距离的正确一阶导数，不需要对求解器迭代求导，也不引入HVP、元学习或外层valid梯度。

拟接线位置是现有step28_record_replay.py的历史objective：由同一live评分表计算新增项，取得dJ/dtable，沿backward_group已有分块VJP传到记录对head及那一次live BGE图。当前群与历史群梯度合并后，沿用全局clip=1和一次AdamW step。不能只保存R日志、只更新W、只更新head，或把当前X也detach后声称实现了机制。

由H_n中心化，新增项对原账号之间每个完整记录块的表梯度总和为0（查询侧求和消去；对称表的反向查询贡献也分别消去）。这说明它在独立评分表坐标中不含直接的A0块均值方向，并非重新分摊D0权重。但在共享神经网络中，参数Jacobian、裁剪和Adam会耦合不同评分，不能声称一次实际更新严格保持账号均分，或保证不妨碍新域学习。

来源表由旧阶段eval模型产生，当前更新沿用S的train/dropout语义。第5节是对两张固定表的性质，不是训练随机过程或最终eval表的保证。

4.2 可落实的数值求解规定（尚未原生验证）

每个q最多64个W变量，目标为凸二次式。拟采用确定性的带away-step条件梯度法，避免把n!个排列全部物化，也不引入可训练额外网络：
  a. 从单位排列I出发，保存其活动排列权重alpha；W始终为活动排列的凸组合。
  b. 计算G = 2(WY-X)Y^T/(27n)。解线性分配得到P，使<G,P>在排列矩阵上最小；并计算全局Frank-Wolfe gap g=<G,W-P>。
  c. g <= eps时返回。eps拟固定为1e-6*(1+||X||_F^2/(27n)+||Y||_F^2/(27n))；这是数值求解精度，不是科学效果门。
  d. 比较FW方向P-W与活动集合中下降最多的away方向W-V；确定并列选择顺序。FW最大步长1；away最大步长alpha_V/(1-alpha_V)，活动集合仅一项时不用away。
  e. 对所选方向D使用精确二次线搜索：gamma=clip(-<WY-X,DY>/||DY||_F^2,0,gamma_max)。零曲率按目标导数和可行端点处理；更新凸组合权重，移除零权重排列。
  f. 用FP64计算小问题、验证有限值与可行性；单q最多1024次迭代。资格阶段若达不到精度／预算即停止修正方案，正式运行若失败则按新合同停止，不静默降精度、截断成假最优或自动扩跑。

线性分配以最小成本排列求解，至多8阶；实现可使用Linux既有可用基础库，不能假设需安装新环境。FW gap给出f(W)-f*的上界；因此可同时报告返回可行解的误差证据。归一化目标差不超过g时，有||Z-Z*||_F^2/(27n)<=g，导数误差可相应上界，不以迭代次数代替精度。

这是完整求解路径设计，尚无速度／收敛实测；1024是失败上限而非声称每次会耗满或必然够用。小问题不调用BGE，仍有CPU传输和同步成本，不能把它记为免费。

5. 它能保证什么：有限缓存上的凸排序损失性质

5.1 精确性质及证明

固定查询账号q及全部候选账号记录。假设m_q(k)=m_q(t)=m且R_q=0，即X=WY。对查询账号均匀无放回选取b条记录，B为其下标集合。自然任务子包取2<=b<=n；数学式对b=1亦成立，但不把单记录账号作为本项目正式数据设定。

Birkhoff分解给出W=sum_pi alpha_pi Pi，alpha>=0、sum alpha=1。于是：
    m + mean_{r in B} X_r
      = sum_pi alpha_pi [m + mean_{r in B} (Pi Y)_r]。
对任意凸函数phi用Jensen，再对均匀B取平均；均匀子集在任意行排列后分布相同，因此：
    E_B phi(m+mean_B X) <= E_B phi(m+mean_B Y)。

本项目已有query-rank为logsumexp(账号候选分)-正候选平均分；按第3节变换后恰等于
    ell(v)=log(sum_j exp(v_j))，
它是凸函数。故在上述条件下，均匀抽取查询记录后的平均query-rank不增。一个共享W同时约束所有b，不需训练时枚举所有子包，也不需逐候选独立校准。

这使用已知凸序／双随机矩阵性质。新内容至多是该关系在本任务记录评分结构上的具体构造和用途，不能将此推导写成首次发现凸序、弱最优传输或Jensen定理。

5.2 软约束、非精确求解时的边界

令返回的W可行，E=X-WY，m_s、m_t可不同，r=||E||_F^2/(27n)，c_b=(n-b)/(b(n-1))。由于E列中心化，均匀子集均值的平方范数期望为c_b||E||_F^2/n；logsumexp对L2范数为1-Lipschitz。得到：
    E_B ell(m_s+mean_B X)
      <= E_B ell(m_t+mean_B Y)
         + ||m_s-m_t||_2 + sqrt(27 c_b r)。
该式使用实际可行W，不需要假装已求精确最优。b=n时新增残差项为0，完整账号平均关系主要仍由D0承担。实际训练采用软损失，两个误差项不会自动为0；不能据公式宣称无代价保护。

5.3 明确不支持的外推

它不保证MAP、Recall或任意非凸排序指标；不保证旧分布未见账号；不保证每个子集、不保证两侧账号同时子采样；不保证完整BCE或实际重新选择hard负例后的整个B不增。对所有q施加约束，也不会自动消去这些边界。n=2时只有b=2是合法子包大小，性质对该账号没有额外的小子包保证。

尤其必须正面检验：约束最终是不是仅改善缓存代理量；旧历史响应是否含有有害方向；神经网络是否能实现有利收缩；新增梯度是否损伤新域。后续比较直接针对本候选，不启动旧C独立诊断。

6. 手算区分、实际反例与失败条件

以下为低维手算，不是正式28账号实验、不是网络内原生更新。示例的标量损失按其自身维度归一化；正式实现必须使用27n及28账号平均。

6.1 允许收缩，区别精确分布匹配与一律压零
Y=(-2,2)^T，X=(-1,1)^T，W=[[.75,.25],[.25,.75]]满足全部约束且WY=X，新项为0。精确排列匹配的平均平方误差为1；直接把所有X压0的方差惩罚也非0。本候选既允许重分配，又允许适度收缩，不强迫恢复旧幅度或无限压零。
同均分来源Y=(-4,4)可容纳X=(-3,3)，Y=(-2,2)则不能，说明新增项依赖D0均分以外的来源信息。

6.2 必须共同保持多候选的联合关系
Y两行=(1,1)、(-1,-1)，X两行=(1,-1)、(-1,1)。各列单独看分布、均值、方差均完全相同，但同一个W无法由列相同的Y产生列不同的X。最优Z为0，按2乘2元素平均的残差为1。独立逐列配对会错误地给0。
再以一个正候选分为0、这两列为负候选，来源平均logsumexp为0.5*log[(1+2e)(1+2/e)]，当前为log(1+e+1/e)；后者更大，因为两者指数平方的差为4*sinh(1)^2>0。这是联合结构与排序代理量有关的直接反例，不是用“相关性”三个字代替论证。

6.3 能看见此前均值／方差候选遗漏的变化
历史正负分差(2.2,2.2,-1.4)、当前(-.2,-.2,3.4)，均值均为1、方差相同。中心化后Y=(1.2,1.2,-2.4)，X=(-1.2,-1.2,2.4)。当前最大值2.4超出历史行凸包上界1.2；最优Z=(-.6,-.6,1.2)，可由三行权重(.5,0,.5)、(0,.5,.5)、(.5,.5,0)实现。标量平均平方残差为.72，dR/dX=(-.4,-.4,.8)，非零且三项和为0。
在第3节单正候选的相对负候选坐标中分差符号相反，平方距离和可行关系不变。此例仅证明新项不同于此前被否决的矩保持，不能证明它足以改善未见账号。

6.4 本候选自己的严格排序反例，必须保留
历史分差T=(-3,1,1,5)，当前=(-1/3,-1/3,-1/3,5)。把前三行等权混合、第四行保留的W双随机；均分均为1，新增项为0。均匀选两条查询记录时，历史6对子集中2对分差为负，当前3对为负。一个正、一个负候选的错误排序比例增加，即使平均凸排序代理损失满足第5节性质。
因此不能把“收缩”泛称为所有排序指标更可靠。27候选场景也不因加入其他候选而获得MAP保证。该反例不是应该修掉的测试输入，而是方案主张的实际边界。

6.5 退化情况
若Y=0，本候选退化为对X的平方收缩；若所有拟训练X已经在C(Y)内，新增项没有作用。若历史范围很宽，可能放过有害变化；范围很窄则可能阻碍学习。源表在缓存拟合得好，也不说明该范围对新身份正确。不能据手算可分或损失非零排除这些失败。

7. 最接近的研究以及尚未闭合的创新判断

下面是方法层面的差异，不以模型、中文应用或Memory大小不同冒充创新。

（a）弱／重心最优传输与凸序。
Gozlan与Juillet的On a mixture of Brenier and Strassen Theorems第1.1—1.2节明确给出条件重心传输代价及凸序关系。本候选min_W||X-WY||^2是有限等权、平衡约束下的相关形式。基础优化工具和“可向历史分布的均值组合靠近”并非原创。
https://juillet.perso.math.cnrs.fr/papers/WOT-v2.pdf

（b）Wasserstein Contrastive Representation Distillation（WCoRD）。
已读第3.2节式12—13：其局部项用点对代价的线性OT加熵正则匹配特征分布，另有全局对比项。本候选将平方放在每行历史重心之外：||X_i-sum_j W_ijY_j||^2；区别于sum_ij W_ij||X_i-Y_j||^2。因而历史行可混合、波动可收缩，不仅是排列匹配。不能声称第一次用OT蒸馏，也不能把下文纯匹配对照称为完整WCoRD复现。

8. 历史生命周期、成本与公平性

来源仍是各训练路径在群所属域末、首次存活时保存的完整FP32记录对表；原存活表不刷新，淘汰不取回，末阶段不为无后续用途生成新表。只使用当前实时六群Algorithm R；历史归档不能合并。每条路径的所有持久历史文本、标签、表、索引、计数、RNG等完整序列化状态仍须<=1MiB。

最大224记录的无序无对角表为24,976个FP32，单表99,904字节，六表599,424字节；这只是表载荷，绝不把它当成包含文本及附属状态的总Memory证明。候选不新增持久历史字段，X/Y/求解矩阵由已有输入当步形成、当步释放；若后来缓存它们跨步使用，须计入历史状态并重新判断设计，不可当作“临时变量”藏起。

计算最多28个8阶凸小问题／历史呈现；不增加BGE前向或保留整套历史模型。临时工作内存、CPU单线程开销、GPU等待及同步都纳入未来原生测量，当前没有实测预算或完成时间。已经删除的旧三臂权重不作为可用起点；如进入新实验，从已选预训练重新训练共同首阶段。

各臂使用相同初始化、current顺序、history抽样、记忆成员选择、dropout和A1随机流及相同训练步数。后续各自轨迹生成自己的新增来源表，旧表生命周期一致；这比较完整保持策略的后果，并非全程相同教师数值的单步因果实验。无需恢复旧诊断来补此区别。

9.2 支撑所提机制解释的最小比较为四臂

S：完整S，原配置。
New：完整S + 0.25R，本文唯一候选。
Match：完整S + 0.25R_match。相同X/Y，但每个q只允许一个排列：
    R_match,q = min_{Pi为排列} ||X-PiY||_F^2/(27n)。
它是等权离散分布的精确平方OT匹配，允许换行、不允许缩小来源分布。用于判断收益是否需要“允许收缩”，不叫作整篇WCoRD的复现。
Radius：完整S + 0.25R_radius，其中
    R_radius,q = [max(0,||X||_F-||Y||_F)]^2/(27n)，再按28账号平均。
它保留历史变化的总幅度上界，丢弃联合几何；不是故意换坏教师。所有WY的F范数不超过||Y||_F，因此该幅度集合比本文集合宽。用于判断是否只有普通限幅就够了。

这四臂各自回答一个不能互换的问题：New-S检验增量，New-Match检验允许收缩的必要性，New-Radius检验历史联合范围相对于单一幅度预算的必要性。只做两臂可以比较性能，但无法支撑后两个机制解释。相同系数和单位并不匹配实际梯度强度；结果只能支持固定约束策略间的比较，不能排除所有优化尺度解释。

不重训旧C、C_plus或LOGIT，不加自动系数网格、替代模型或适应性新臂。若两种较简单的替代已足够，应放弃不必要的复杂机制解释。

9.3 若进入开发训练的建议范围与计数

建议继续既有ABC/BCA/CAB三个顺序、单s0、每阶段288步。由于四臂首阶段目标完全相同，每顺序只训练一次共同完整首阶段并分支：

共同首阶段864次单群呈现，后续6,912次各current/history两群，合计14,688次梯度群呈现。三个顺序仍不是三个seed。首阶段共享的是新实验内完整model/Adam/RNG/Memory，不能拿旧S阶段推理权重代替。

结果如何指导机制取舍：
  - New只改善R／缓存或代理量，O无正向证据：不能称历史保持解决了研究问题，不继续单独分析旧C来延长该候选。
  - New较S有O增量，但Match也同样好：可能只需联合响应蒸馏，不能声称收缩是关键；保留更简单解释。
  - New较S有O增量，但Radius也同样好：可能只需限制波动幅度，不能把收益归为历史联合几何。
  - New相对S、Match、Radius均有相应支持且新学习代价合乎前瞻约定：才有有限证据支持所提设计；单seed、已开发数据仍只支持继续确认。
  - New旧域有利而新域受损：报告收益／代价，不以旧域单项改进自动判成功；不看完结果才放宽容忍值。
  - 资格求解失败、超预算或运行无效：属于工程／执行问题，保留账，不混为算法负结果或自动重跑。
