2. 从真实C/S目标作精确分解

以一个历史完整群为单位，k_theta为当前模型所有无向、非自对记录评分组成的向量，t为该群首次入缓存时保存的FP32来源评分。来源评分来自当时同一架构的中文BGE模型，不是额外训练的另一类教师模型。e=k_theta-t。L0把记录评分按原账号归属求均分，L1按这一步的同控重组归属求均分；两者均输出378个账号对评分。

D0 = ||L0 e||² / 378
D1 = ||L1 e||² / 378
J_S = Bbar_current + 0.1 Bbar_history + 0.5 D0
J_C = Bbar_current + 0.1 Bbar_history + 0.25 D0 + 0.25 D1

Bbar为A0、A1两种归属下完整B的平均，B=BCE+query-rank+0.5 top5-hard。当前监督、历史监督、重组、Dropout和完整S设置都保留。实际定义见scripts/step28_record_replay.py的objective、backward_group、update及scripts/step28_alias_ranking.py的objectives。

令P=L0^T(L0 L0^T)^(-1)L0，Q=I-P。L0各行覆盖互不重叠的原跨账号记录对，因而满行秩。P的实际运算很简单：每个原跨账号块中的误差都替换为该块均值；原同账号内部的记录对置零。Q留下块内差异及这些同账号记录对。P不需要构建稠密矩阵或做大矩阵逆，也不使用owners。

定义Dcoarse=||L1 P e||²/378，则

J_C-J_S = A(e)+F(e)
A(e)=0.25(Dcoarse-D0)
F(e)=0.25(D1-Dcoarse)
    =0.25[2<L1Pe,L1Qe>+||L1Qe||²]/378。

A仅由原账号均分误差决定，表示C怎样重新分配这些均分的保持压力；F包含均分看不到的细节及它们与均分误差的耦合。不能把F直接称为“有效知识”、纯细节平方误差或已证实的噪声。即使某一状态Qe=0，F的数值为零，其梯度也未必为零，因为交叉项仍可对Q方向施加作用。来源Q t包含更多数值，并不保证它在未见身份上有用。

因此使用两个二值开关a,f，定义仅用于单步干预的J_af=J_S+a A+f F：

  a=0,f=0：完整S。
  a=1,f=0：只加入均分约束重新分配，历史保持为0.25D0+0.25Dcoarse。
  a=0,f=1：只加入细节及耦合的差项，保持完整S的均分基础。
  a=1,f=1：逐式还原原C。

这四个条件从同一状态分别做一步，随即撤回临时状态；只有S主路径持续训练。F可以为负，例如标量L1Pe=1、L1Qe=-1时，D1=0而Dcoarse>0，所以不把F当独立非负损失或推荐长期训练的候选。原C_plus并未进入比较，也未重新启用其撤下入口。

全部项通过同一学生记录表、实际评分头及编码器反传；t、P、L0、L1和采样归属停止梯度，k_theta不停止梯度。沿用真实分块VJP、当前与历史梯度累加、全梯度裁剪1、AdamW及实际学习率。形式上g_af=g_S+a grad A+f grad F，但实际参数变化由完整优化器状态决定；不会用梯度余弦或线性相加冒充真实更新效果。无外层优化、HVP/JVP或通过valid反传，不恢复已关闭的群体元学习路线。

3. 最小执行范围：一条S路径及96个撤回的单步干预

只用固定s0和ABC日程的前两个阶段A→B。选择按既定域字母和原日程固定，不按已见的某域收益挑选。指定中文BAAI/bge-large-zh-v1.5及原归档revision 79e7739b6ab944e86d6171e44d24c997fc1e0116，记录表头与完整S目标、初始化、数值配置、优化器、阶段日程保持。A训练288步，B训练288步，主路径合计576次物理更新。两阶段各保留6个逐epoch过拟合诊断点，完整呈现当前fit、存活缓存、对应域未见群的变化。

A结束时按原Algorithm R从合法48个fit群保留6群，并在A阶段末eval模式产生原完整记录表来源；总历史载荷仍≤1MiB，来源不刷新。B阶段成员固定；诊断结束前不纳入B群。校准仅用每域原12个校准群，不参与参数更新、探针选择或Memory选择。

在B完成k∈{0,48,144,240}步后暂停主路径。每点遍历6个存活A群，按uid排序后记为r=1,…,6，每个恰好作为一次探针历史输入。当前输入取固定B训练日程的第k+r个群；四个条件均使用下一主更新的学习率stage_lr(k+1)，评分头学习率仍0.001。这里六次探针均从同一个θ和Adam状态出发，不累积，不声称是六步连续训练。0/48/144/240覆盖进入B、第一轮、第三轮及第五轮结束；避免第288步编码器学习率恰为0造成仅评分头作用的误判。

每个(k,r)生成一套探针专用Dropout与重组种子，明确使用data.seed_for(20261011,"retention_probe","ABC",k,r,role,"dropout"或"regroup")，与a/f开关无关；role为current或history。四条件严格复用同一套随机状态。主训练的历史draw_rng、全局Python/NumPy/CPU/CUDA RNG、各模块训练模式、Memory字节、模型及Adam状态在探针后完整恢复，探针不消费主训练抽样。原生核验须证明插入探针后下一次主S更新与未插入者一致。

每个条件实际更新一次，保存原账号A0/eval模式下A/B各20个valid群的盲评分及6个存活缓存群的评分/残差。比较后恢复同一起点；探针分支不保留为候选模型。每点还保存干预前评分，并在全部探针结束、恢复后复核评分与状态。总量：4时点×6群×4条件=96个单步干预；576+96=672次物理更新，其中梯度群呈现为288+2×288+2×96=1,056。不得按探针结果增加点位、步长、群、种子、域顺序或候选。

4. 看什么，以及什么结论不能得出

主要诊断量为A域未见身份的原query-rank损失。其定义沿源码：每群28个查询，对每个查询计算logsumexp(27个候选分数)减同控正例分数的均值，再平均28个查询。它是平滑的排序代理，越小越好；不会把它改称MAP。一步可能只改变分数而不改变名次，所以同时报告MAP、MRR、Recall/NDCG、AP、raw log_loss、Brier与完整既有22指标，不能只凭代理损失改善宣称实际排序提升。

对损失把效用记为V=-loss；对MAP等直接用原指标。每个(k,r,评价群)保存四个值V00、V10、V01、V11。前瞻报告：
  均分重分配效应：V10-V00，以及V11-V01。
  细节参与效应：V01-V00，以及V11-V10。
  实际原C相对S：V11-V00。
  交互：V11-V10-V01+V00。

主报告为A域两项细节效应及C-S，另列A域两项均分效应和交互；B域与缓存均报告相同对照，包含全部四时点、六历史群及固定等权汇总。不会只展示有利时点。实际clip/Adam、模型非线性和评价函数都可能产生交互，因此不能把两个单因素效果之和写成C总收益。

基础识别报告raw及固定A阶段校准映射后的指标，四条件同用该映射，不在各探针重新拟合校准。B最终S状态另按原B校准群拟合阶段映射并报告端点；逐epoch过拟合比较继续采用既有raw定义，不混用校准损失。该两域短路径不计算或冒称三阶段O/N/Z结论。

统一开放后，以实际域内20个完整valid群为重采样单位作5,000次配对bootstrap，种子data.seed_for(20261011,"retention_probe",domain,"bootstrap")；每次所有时点、历史群及四条件用同一组评价群索引。先固定等权汇总24个(k,r)效应，再对评价群重采样；时点、缓存群和四条件都不是独立训练种子。不为单项显著性设新总通过门，不做看到结果后的超参数选择。区间是条件、探索性区间，不能覆盖重新训练、选路线或重复开发valid的不确定性。

解释约束：
  • 细节效应在缓存改善、在未见A恶化，仅支持这些状态下局部作用不一致；不能据此认定Qt全是噪声。
  • 未见A的细节效应改善而C-S不改善，结合均分项和交互，可支持继续研究约束配置或耦合；仍不证明历史C失败的唯一根因。
  • A改善伴随B恶化，报告局部稳定性/新学习代价，不宣布问题解决。
  • 代理损失改善但MAP不变、区间跨零、不同点位相反或影响接近数值误差，报证据不足；不能自动加大探针步长、扩跑或改判据。
  • 即便局部结果理想，也仅支持后续机制设计；不授权把J01直接推广成方法，不证明完整C训练轨迹或第三域表现。

还要区分“该细节项的作用”与“来源细节本身的信息价值”：F同时改变对当前Qk及其与均分误差耦合的约束。它在valid有利，也不能单独排除普通正则化的解释；若后续要主张来源Qt具有特异增益，还须提出有区分力的来源目标对照，不能从本次局部结果跳过这一步。当前不追加该对照或把四条件称为根因已完全隔离。
