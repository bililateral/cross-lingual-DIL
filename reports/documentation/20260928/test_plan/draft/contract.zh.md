## 4. 九项通过条件

以下均按120群先群内计算、域内群等权、三个域等权汇总。`Δ`为候选减对照。**九项必须同时满足**，不以某指标的提升抵消另一指标失败。

| 编号 | 比较 | 通过条件 |
|---|---|---|
| T1 | C_cal − A_cal | 观察ΔMAP ≥ 0.01 |
| T2 | C_cal − A_cal | ΔMAP的双侧条件95%配对区间下界 > 0 |
| T3 | C_cal − A_cal | 观察ΔRecall@5 > 0，保持已确认的严格提升要求 |
| T4 | C_cal − A_cal | 观察ΔAP ≥ 0 |
| T5 | C_cal − A_cal | 观察ΔROC-AUC ≥ 0 |
| T6 | C_cal − A_cal | 观察ΔBrier ≤ 0 |
| T7 | C_cal − A_cal | 观察Δlog_loss ≤ 0 |
| T8 | C_cal − A_raw | 观察ΔBrier ≤ 0 |
| T9 | C_cal − A_raw | 观察Δlog_loss ≤ 0 |

这是固定s0的一组比较，因而不再重复valid的三种子平均／各种子方向条件；没有放宽MAP幅度、Recall@5方向、四项识别保护或原始A概率保护。判定使用未四舍五入的float64结果，不设事后容差、四舍五入通过或接近通过。实现一致性核验的容差不是性能保护允许退化幅度。

MAP≥0.01是延续的研究推进阈值，没有已确定的业务成本依据；MAP区间下界>0也不等于证明总体增益至少0.01。K=5是研究工作点，完整报告其他K。T4—T9是观察值保护，不宣称已证明总体非劣效、每个群／域或每个分类阈值都不退化。若相应区间仍覆盖退化方向，须显式披露；区间未作为这些观察值条件的额外隐藏门槛。

任何一项失败都记为未通过本合同验收，保留全部结果；不得改送s1/s2、改轮次、调整映射或拿同一test重新调参后再称独立验收。具体后续由结果分析决定，不自动重开本次。

## 5. 全部指标与统计定义

保持已审的22指标定义：AP、梯形PR-AUC、ROC-AUC、Recall@FPR≤1%、Brier、log_loss、precision、recall、F1、specificity、balanced accuracy、MCC、MAP、MRR、Recall@1/3/5/10、NDCG@1/3/5/10。

- 曲线指标按每群378对计算；检索按28个查询分别计算后在群内平均，再按域和群汇总。AP不同于梯形PR-AUC；Recall@K是相关账号找回比例，不是Hit@K。
- 排名使用logit，精确并列按公开账号升序稳定排序，不按显示概率或四舍五入概率排序。
- 原始分数保持原推理float32字节；映射和指标用float64。冻结概率数值接口如第2节；Brier不截断，log_loss保留原`[1e-15,1−1e-15]`截断。不能换用另一sigmoid浮点实现后默认为数值相同。
- 分类使用各角色logit≥0，对应未显示舍入的固定概率0.5。报告四角色逐群／逐域／合并TP、FP、FN、TN、precision、recall、F1，区别群宏平均和先合并计数后计算。
- 旧严格自动判定诊断沿用每模型训练内确定的原logit阈值及原决策集合。变换阈值仅记录对应关系，不在变换空间重新比较舍入后的边界；不重新选阈值，不把旧FPR≤0.001／Recall≥0.5当作本次资格线。
- 校准前后逐群完整378分数的顺序和精确并列必须一致；标签评价后14个曲线／检索列保持一致。异常先记录并按实现问题处理，不能用原指标代填掩盖。

### 配对不确定性

使用固定s0的逐群差，按三个域分别整群有放回抽样，各域每次40群；5000次，拟冻结种子20260928，`Generator(PCG64(20260928))`。一次产生`integers(0,40,size=(5000,3,40))`，域维依次A/B/C；所有指标及四比较复用相同索引。先求各域重抽均值，再三域等权平均；取2.5%／97.5%线性分位数。

不把3,360查询或45,360对当作独立样本，不拼成三种子均值，不引入旧实验的余弦分数或另一抽样次数。完整报告四比较全部22指标的点差、三域差和条件区间；主要MAP条件与描述性区间分开，后者没有统一多重校正。区间条件于固定模型、映射、生成机制及阈值，不包括重训、重新校准、数据再生成不确定性；独立test仍只验证这一固定s0系统。
