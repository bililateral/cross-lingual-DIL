## 4. 历史机制确已接入，哪里出现具体风险

本次没有OOM、训练缺项或来源漂移证据。除完整回执外，另在Linux仅汇总六条已保存更新日志的数值字段，见[history_summary.json](history_summary.json)，未保存其中标识、未读Memory/模型/正文/预测。每条第二域2400步、第三域13080步均有历史消费和非零历史记录表示梯度。Full全部15480历史步的蒸馏项均正；ER对应蒸馏恒为0。第一域ER/Full的逐轮聚合损失相同，与相同学习起点一致。

实际入口仍是`update_account → backward_h → h_objective`。当前项为自然/重组多记录监督加RMS辅助CE；历史项为α×历史监督，Full再加β×出生评分MSE，β不另乘α。Full的教师是记录进入保留记忆时保存的评分，幸存教师不刷新；同seed的ER/Full共享当前样本、记忆选取和历史采样规则，Full额外的出生评分项是方法差异。原GPU反传证据与本轮实际非零日志结合支持接线有效，但日志范数不能单独给出蒸馏与当前任务梯度夹角。

支持进一步诊断的具体假设是：在RMS/FIT12母体和仅6群记忆条件下，固定出生绝对评分的约束强度或约束目标与继续学习不匹配。出生评分来自较早模型，维持这些绝对分数未必等于提高全候选FIT12排序。上述目标/梯度尺度及第二域同时降低旧、新能力与这一解释相容，但尚未证明是β过大、梯度冲突、教师质量或记忆覆盖哪一项主因；不能把损失比当梯度比，也不能凭标量大小宣布某个新β必然有效。中文调参系数也没有因此成为英文最优值。

当前结果足以否定“该固定Full配置的历史机制已经产生预期增益”，不足以否定完整H在其他经过合理设计的条件下可能有效。后续若获准诊断，应围绕这一具体缺口形成有限假设，而不是再次大范围改英文表示、随机种子、顺序或筛选有利市场。本轮不执行新的候选或修改现行证据。
