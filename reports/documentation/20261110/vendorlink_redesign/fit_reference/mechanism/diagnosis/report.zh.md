## 2. 尚未学新域，保持项已产生额外误差

在同一个stage1模型、同一批历史文本和同一多记录聚合下，出生参考和eval学生完全一致；唯一的对照是切换学生训练模式并固定16次随机种子。

|seed|确定性自比MSE|训练模式MSE|其中随机方差|其中样本均值偏移平方|乘原β后的MSE|
|---|---:|---:|---:|---:|---:|
|51|0|2.0762|0.9483|1.1279|1.5933|
|52|0|2.1749|0.8966|1.2783|1.6691|
|53|0|2.6095|0.9205|1.6890|2.0027|
|三seed均值|0|2.2869|0.9218|1.3651|—|

单位是原自然多记录分数的平方误差，不是F1百分点。各群内按原无序对平均，跨六群等权；方差用16作为分母，因此有限样本恒等式为`MSE = 方差 + 样本均值相对教师的平方偏移`。该偏移包括非线性/归一化下的模式差异及有限掩码估计误差，不能把它全部解释为新域学习漂移；此时根本没有发生新域训练。

正对平均MSE为6.9109、负对为1.9612，均不是零。实际BERT配置的hidden和attention dropout均为0.1，运行使用torch2.9.1+cu130、transformers4.46.3的SDPA。教师在eval下计算，历史学生在train下计算；因此保持目标还在要求随机学生复现确定性教师。这是一个实际存在的附加正则化要求，并不自动等于实现错误或已证实的有害原因。

这里不称其为“不可消除的噪声地板”：下一节显示训练确实大幅降低了它。也不能把此起点损失与上一份报告的整段训练均值直接相除，当成同一步梯度比例或更新贡献。

## 3. Full把记忆分数保住了，但与全候选能力脱节

以下均为学完Dream后的同一批旧AlphaBay记忆群，参考固定为该seed的stage1出生分数。

|方法/seed|eval确定性MSE|训练模式MSE|训练模式随机方差|样本均值偏移平方|
|---|---:|---:|---:|---:|
|Full51|0.0465|0.0322|0.0286|0.0035|
|Full52|0.0702|0.0327|0.0290|0.0037|
|Full53|0.0730|0.0338|0.0298|0.0040|
|ER51|9.5553|12.4895|0.9216|11.5680|
|ER52|10.5555|13.7534|0.8862|12.8672|
|ER53|12.0732|14.7356|0.9023|13.8333|

Full确定性MSE平均0.0632，ER为10.7280。Full的随机方差由stage1的平均0.9218降至0.0291，ER仍为0.9034。Full终点残余训练模式MSE中约88.15%—89.02%是本诊断的随机方差；**这不是整段训练损失或梯度的88%—89%，更不是性能下降的因果贡献比例。** Full终点的eval MSE反而高于train MSE，不能声称所有时点“关闭dropout都会降低保持损失”。

三种端点在这些群的确定性正对均高于所有群内负对，54组的非正间隔比例全为0。出生/Full stage2/ER stage2的群内平均间隔分别为21.6051/21.9502/22.4412。ER虽然绝对分数漂移较大，仍保留这些群的正确局部排序。ER去除每群共同平移后的MSE仍达8.8063，因此不能把它简化成只有一个无害的公共偏置；可以确定的只是大幅绝对评分变化不必然破坏这些已学群的排序。

与此同时，[已保存正式dev结果](../result/report.zh.md)显示学完Dream后：Full旧AlphaBay宏F1为82.1990%、ER为83.1615%；当前Dream为91.4013%和92.5336%。整个ABC结束后Full相对ER的旧域最终O低0.9650pp、Agora低2.0749pp。**当前Full在有限训练记忆上的绝对评分保持成功，与全候选dev能力不增益同时成立。** 这使“历史项没有执行”或“只要把旧MSE压得更低就会成功”的解释不成立。

但本次只诊断了每seed六个AlphaBay旧训练群及Dream后的端点，没有非记忆组或全候选重评、没有梯度夹角，也没有在相同训练过程中随机分配两种保持模式。故仍不能唯一归因于dropout、β、记忆覆盖或绝对目标本身；更不能据此宣布新候选会成功。

## 4. 唯一优先候选：只分离出生评分保持的随机模式

下一轮最有依据且可归因的候选为：

`当前H监督+RMS CE（原train模式） + α×历史自然/重组监督（原train模式） + β×出生评分MSE（确定性学生，允许求导）`。

保留完整H的文本双通道、记录对MLP、多记录聚合、回放、出生教师不刷新和旧评分保持。α/β、Memory六群、每步历史群、种子、ABC顺序、FIT12候选池、40epoch、优化器和学习率均不同时改动。辅助分类头不替代H评分；不加新目标、不扩记忆、不关掉β。

改动仅在Full的历史MSE分支增加确定性学生前向及反向。原随机历史监督仍走原分支，避免把ER也改掉；这样原SEQ、ER及V两读取器在未变配置下可以直接复用，原Full也保留作主要修改对照。所有梯度仍累加后共同裁剪一次、optimizer更新一次，额外前向须如实计入计算和费用。

**实现不能简单地把整个训练模型长期设为eval。** 已核对实际安装源码：SDPA使用`dropout_p=self.dropout_prob if self.training else 0.0`；BertEncoder激活检查点只在`gradient_checkpointing and self.training`下执行。只改`nn.Dropout`会漏掉SDPA；直接全局eval又可能关闭原来节省显存的检查点。拟实现应只在出生MSE的完整前向及反向期间关闭对应dropout随机性，保留encoder的训练/检查点路径，直到检查点反算完成才恢复原设置；当前学习与原历史监督的随机流和模式须恢复。

届时必要核验只针对该变化：手写独立梯度参考、当前/历史监督随机流不变、真实BERT的确定性学生与eval分数一致、扰动后MSE确实回传encoder/pair梯度、梯度检查点和模式恢复、实际更新入口。关闭随机性不等于冻结模型，也不能用`no_grad`把新保持项断开。本次未实现这些训练改动，当前forward-only证据不能冒称完成其反传核验。
