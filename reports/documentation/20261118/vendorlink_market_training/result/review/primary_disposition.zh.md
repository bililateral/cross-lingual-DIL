# 市场适配器四组结果主审处置

**结案。** 我逐项核对了正式裁决、三颗 seed 的原数、配对差和实际记忆实现。保持 `full_application=false`、`STOP_NO_H_ADVANTAGE` 和 `old_score_increment=false`。结果外审提出的修订涉及数值如何解释、各项保护的区别、记忆容量与附表范围。现有原件足以解决这些问题。[外审全文](external_report.zh.md) · [原生裁决](../decision.json) · [独立算术核对](../aggregate_check.json)

| 审查意见 | 独立核对与处置 |
|---|---|
| 1. 区分平均少忘、取得和末态，限定 Dream 的局部收益 | 采纳。由三 seed 的 R11、R22、R31、R32 得到总体 dO=+0.3376 pp，dQ=−0.5485 pp，dF=dO−dQ=+0.8861 pp。Dream 的 +1.9250 pp 少忘包含 +0.8280 pp 末态差和 −1.0970 pp 取得差。seed 52 的 Dream 末态低 0.5308 pp，51、53 较高。AlphaBay 同起点，末态低 0.1528 pp。报告已明确各幅度及方向。 |
| 2. 区分绝对净学习、严格取得及宽容末态，核对遗忘压力 | 采纳。Full 的 Dream 净学习为 −0.1699、−0.3185、+1.4862 pp，平均 +0.3326 pp。相对 ER 和 SEQ 的 Dream 取得均低 1.0970 pp，严格取得保护失败。Agora 净学习三颗均正，平均 +5.0317 pp。四个相对净学习组合均走平均差 ≥−2 pp 的分支。Full−ER 九个子条件五过、四未过。ER 的两旧域变化相抵，平均 F=0.0014 pp，SEQ 的 F=0.1343 pp，各自平均压力条件均失败。对 SEQ 的两项平均增益也未达 3 pp。 |
| 3. 分别解释 V_SET、V_CLS、V_CLS_ads 和历史实用参照 | 采纳。Full 对 V_SET 的旧域平均末态与少忘逐 seed 均向好，Dream 在 seed 52 的末态较低。完整外部门仅卡在 V_CLS 的 R22 平均差 −2.4628 pp。V_CLS 的未来市场头尚未训练，其净学习只按这个读取器解释。V_CLS_ads 为同一模型的逐商品读数。已说明 468 个辅助指标配对系列只覆盖四个指定对照。新 Full 对原无适配器 ER 的 O、Agora 末态各低 0.1642、4.5435 pp。跨批结果给出替换代价，不能归因到单一组件。 |
| 4. 六群的具体含义及证据范围 | 按实际源码澄清。每条 ER 或 Full 轨迹创建一次 Memory，学完 AlphaBay 和 Dream 才分别调用 retain。retain 从既有 entries 开始，对同一储备池继续 Algorithm R，容量始终为六群。实际回执中的 AlphaBay、Dream 两个键标记两次阶段末快照。进入 Agora 时仍为六群总量，旧群的具体出生市场分布应由相应存活记录确定。此处使用已保存的数量、流身份和已绑定源码，未重新读取 Memory。 |
| 5. 运行有效性与辅助指标的证据层级 | 采纳。主执行者在 Linux 核了 17 个生产来源、12 条成功训练对应的盲评分回执和一次 dev 开放记录，另从匿名聚合值复核 162 格、2,106 个数值及配对汇总。网页审阅者复算的起点也限于包内聚合资料，其明确报告了这一边界。Dream 最终 MAP 改善、Recall@5 下降，并存于原生结果。训练、群流、字节数、评分角色及相应完成回执提供实际运行证据。三颗已用开发 seed 的离散程度与独立确认分开陈述。 |
