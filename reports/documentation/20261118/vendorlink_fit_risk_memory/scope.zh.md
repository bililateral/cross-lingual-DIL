# 在固定候选群中按 fit 混淆风险写入六槽

2026 年 11 月 18 日获准一次无训练开发诊断。使用上轮六份冻结布局的定向构群臂，每个 seed 51、52、53 取原配对序号 1 到 1,000；历史示例 0 不入样。当前域只允许 AlphaBay 或 Dream 自己的 fit。两个市场合计六群，原序列化上限 1,048,576 字节。每种策略给 Full 和 ER 提供同一份清单。实际训练、模型载入和教师评分次数均为零。两种写入策略共用候选、抽样位置和旧域淘汰轨迹。

1. 每账号按原第 0 轮的六份双记录视图轮流取一份作查询，同市场每个账号另十条记录作参考。标题和正文分别按原词级 TF-IDF 计算余弦，两路等权相加。所有账号含自身竞争第一；正最高分平手按原账号顺序，无正分的折弃权。对查询 q，记自身第一的折数 c(q) 和具体错误账号 j 第一的折数 c(q,j)。仅在两者均大于零时预测有向混淆对 q→j，权重取两者最小值。完整有向对、相应折数和权重按市场、seed 冻结，同一市场与 seed 的 1,000 次共用。
2. 主对照为上轮定向成员池中原 Algorithm R 的六槽，完全复用既定位置顺序、市场来源、替换槽和采样器状态。对每次布局，以均匀六槽作起点，旧域槽用本臂在上域同槽存活的群。按槽 0 至 5 对每个当期槽进行一次替换选择。新群必须来自同一冻结置换，记录包、群大小、与其余各槽的成员交叠（含高阶交叠）均相同且不重复。按此前模板的群序遍历，选能最大化六群共同覆盖的有向边权重的合法群。每条有向边只计一次；只有严格提高才替换。优于原槽的并列候选取模板表中最先者，原槽与最优同分优先保留。此为一次顺序贪心，并未求六槽全局组合最优。旧域保留仅沿该次抽样自己的实际存活槽。两域之间不传递旧域词表或风险表。
3. 依据上轮 SHA 恢复置换、成员及实际记录。对新策略每次六槽以原 Memory.bytes、实际记录和原尺寸独立 float32 教师容量占位计量，对照复用已冻结的逐次字节。所有候选布局、预测和两臂清单具名绑定并在 Linux 冻结，随后才登记并读取原 ER 在两个市场三个 seed 的 12 个开发矩阵，每个一次。只能回传匿名聚合及来源身份。相同有向对按查询×seed计，同一次抽样即使出现多群也只计一次。
4. 复用原定义，起点第一正确、终点跌出，配其终点错误第一账号。根据原第 0 轮三个包能否同群，分原漏 47／7 对、原可达补集及全部 49／8 对。按市场、seed 报告固定预测命中、同池可达、出域两臂及配对净差、AlphaBay 进入 Agora 前同槽留存、其中实际预测命中并保留的量。猜中须方向及竞争者身份严格相符。每格为 1,000 次实际配对的平均，跨 seed 合计加各 seed 的均值；另给配对四分区和净差频数。Dream 出域即进入 Agora 前。
5. AlphaBay 原漏事件的出域三 seed 平均净增之和至少 1 对、至少两个 seed 正向、进入 Agora 前净增之和大于零；全部 AlphaBay 事件的出域和留存之和各不退步。Dream 单列。全部条件同时满足才值得讨论下一步；失败即结束本次按 fit 词面风险优先保留精确对的路径。已用开发事件的直接同群机会不能证明模型取得、遗忘或新域学习的改善。
6. Linux 既有 py310、单核、零 GPU。合成核验、冻结、评价的进程生命周期墙钟合计最多 1,800 秒，失败保留费用、已访问材料及现场，不补抽。GPU、confirm、正文向外传输及训练均无本次许可。用户选定一次结果合审，具体匿名包另行确认外发。
