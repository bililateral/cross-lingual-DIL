# VendorLink 六个完整记忆群的覆盖诊断

用户在 2026-11-18 确认先做零训练诊断，允许以 AlphaBay、Dream 当期 fit 及原 ER 六份群索引选群，全部清单冻结后才使用 ER 的 12 个既有开发矩阵。用户另确认“一次结果合审，先完成诊断”。结果外发仍按具体材料授权。

1. 用原 FIT12 机制门绑定的 groups_for、epoch 0、seed 51/52/53 产生完整候选群。每账号六个双记录视图轮流作模拟查询，同折各账号的其余十条为参考。英文词级 unigram、小写、原词频、平滑 IDF、L2 归一化，标题和正文分别以本折本市场的参考账号文档计算词权重，余弦各占一半，空向量记零。每行至多提名五个正分的其他账号，分数相同按原匿名账号序。六轮中每次提名为一个有向账号对增加一分。
2. 比较原 Algorithm R 随机六槽与固定三随机、三定向。两种策略共用原随机候选流与每次淘汰的槽位。按最终入选的当前市场群，零起算槽 1、3、5 依次尝试替换。只从同市场、同原记录包、同账号数的群选择，要求与其他五槽的账号成员重叠格局完全相同，六个群互异。给未被其他五槽覆盖的有向对加总其 fit 分值，严格改善才替换，同分的改善者按群 UID 升序。旧市场的存活槽原样延续。一个市场结束后，词表、提名表和未入选正文不进入该次模拟的历史。
3. 每 seed 除历史原抽样外另做 1,000 次配对蓄水池抽样，两阶段承接同一抽样的 RNG 和 seen。每个市场、每种策略都是六群，以原 Memory.bytes 原样序列化记录、采样状态和原形状的 float32 记录对教师占位。上限 1,048,576 字节；超限照实计数，不补抽，也不按冻结后的评价改变清单。Full 与 ER 共用每一策略的一份按槽固定的群、记录和视图清单。全部名册、候选群成员、账号／记录／视图标识仅留 Linux，密封哈希和匿名汇总可回传。当前与旧市场分阶段处理，跨模拟不得交换候选。
4. 评价器先核全部清单冻结及内容身份，再读取 12 个 H_ER 分数各一次。AlphaBay 为 R11→R31，Dream 为 R22→R32，起点正确第一、终点跌出为全部事件，原列序破同分。主命中须正确账号与终点错误胜者在同一存活群；另记仅胜者在库、双方均在但不同群等情况。记各自出域时点，并追踪进入 Agora 前存活的 AlphaBay 群。候选池内任一完整群曾包含二者给出宽松上界。历史实际抽样与 1,000 次配对分列，分别报告两边均中、仅定向、仅随机、两者均未中、平均净增、波动和正／零／负次数。分位或波动只描述抽群随机性，跨 seed 的查询可能重复。
5. 讨论后续的预定条件为 AlphaBay 三 seed 合计平均至少净多一件、至少两 seed 同向、进入 Agora 前仍有正净增。Dream 单列。覆盖测的是历史 ER 已发生的错误对手，训练收益另需独立实验。手写核验和执行使用 Linux 既有 py310，一 CPU 核、单线程、零 GPU。先以正式原索引核复现，冻结失败不准开评分矩阵。训练、模型、原 Memory 载荷、Agora 正文、confirm 和额外候选均在本次范围之外。技术失败保留现场费用，不补抽或自动重跑正式访问。本批仅本地 Git。
