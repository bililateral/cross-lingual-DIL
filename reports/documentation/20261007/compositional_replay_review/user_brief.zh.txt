一、我们的研究问题

当不同分布的新卖家群体依次到来，而只能保留少量历史训练信息时，如何持续学习新群体的马甲识别能力，同时保持对旧分布中未参与训练的卖家的马甲候选排序和基础识别能力？

请特别注意：

1. 任务是根据卖家账号的商品标题、描述等文本，判断两个账号是否属于同一控制者，并为查询账号排列潜在马甲候选。
2. 研究对象是同控关系，不是不断增加身份类别的卖家分类任务，也不能直接改写为作者身份分类。
3. 不同阶段不是同一批控制者持续增加新账号的追踪任务。
4. 旧能力评价针对旧分布中未参加训练、未进入缓存的卖家身份，不是检查模型是否记住历史缓存中的旧账号。
5. 需要同时处理新群体学习和旧分布泛化保持，不能通过完全冻结模型、拒绝学习新群体来获得表面上的“零遗忘”。
6. 有限历史信息是研究前提，不允许默认读取全部旧训练集，或借研究归档恢复已经淘汰的历史数据。

我们希望形成有实质方法贡献、经过实验后能够支撑科研论文的工作。不要承诺发表、原创性或性能一定提升。

二、我真正要你设计的是什么

- 它如何实际影响后续梯度、参数更新或最终判断？
- 为什么它可能比当前强基线更好，而不只是更复杂？
- 它与最近已有方法相比，究竟有什么实质区别？

我明确反对以下做法：

- 直接写成“LOGIT0.1 + 一个新损失”就称为新算法。
- 堆叠对比学习、蒸馏、注意力、原型、梯度投影等常规模块，再给组合取一个新名字。
- 仅换蒸馏距离、调整权重、改变超参数或换一个记忆统计量，就宣称有核心创新。
- 以“中文”“暗网卖家”“多记录账号”等应用条件的组合替代算法贡献。
- 先假设某个模块是失败根因，再为这个未经证明的诊断设计复杂补丁。
- 为了显得新颖而牺牲问题相关性、可实现性和性能动机。

允许合理复用编码器、优化器、训练基础损失及公平比较基础设施。已有组件可以使用，但方法贡献必须落在明确、必要且有区别的机制上。

我允许改变原算法核心。此前“必须保留旧关系记忆核心”的限制已经被我后续允许修改核心的决定取代。不要为了保住旧公式而限制研究，也不要因为允许改核心就偏离研究问题。

每个域：

固定到达顺序为：

- A→B→C；

这三个顺序不是三个随机种子，也不是三份独立评价数据。

五、当前模型和强基线

当前基础模型：

- BAAI/bge-large-zh-v1.5中文编码器；
- 标题和描述分别编码；
- 对账号内商品记录按通道汇总均值和总体标准差；
- 得到4096维账号表示；
- 对账号对构造对称特征，包括绝对差和逐元素乘积；
- 使用8192→128→1评分头，隐藏层ReLU；
- 编码器与评分头均可训练。

基础群损失记为B，由以下三部分组成：

B = BCE + query-rank + 0.5 × top5-hard。

其中BCE按378对平均，query-rank按28个查询平均，hard按既有合同处理每个查询及其正例。若你的推导依赖这些目标的逐项精确定义，请要求我提供实际源码，不要自己猜测并当成项目原实现。

当前主要对手是LOGIT0.1，其实际目标为：

J_LOGIT =
    B(current)
    + 0.1 × B(history)
    + 0.5 × mean((s_history − t_history)^2)。

注意：

1. “0.1”是整个历史监督B的权重，不是历史logit MSE的权重。
2. 每步抽取一个当前完整群和一个历史完整群。
3. 当前与历史梯度累加后，统一裁剪，再做一次AdamW更新。
4. 当前和历史学生分支均保留训练模式的Dropout。
5. 历史目标是在该群首次进入缓存时，由其所属域阶段末的eval模型产生。
6. 幸存旧群的历史目标不刷新。
7. 没有供后续训练调用的完整旧教师网络。
8. 该方法是已知重放和输出保持思想的任务适配，不是我们已经建立的创新方法。

既有日程每阶段6轮，每轮48群，共288次更新；阶段间延续Adam状态。当前正式开发主要使用固定s0及上述三个顺序。新方案若改变结构、起点、更新次数、随机模式或首域训练，必须明确披露，不能继续声称所有条件相同。

六、已有方法尝试与真实负结果

我们已经尝试过累计关系/函数目标记忆，动机是：不仅保留六群原始样本，还汇总曾经合法见过的拟合群，以便在小缓存条件下保存更广的历史知识。

原路线大意：

- 将关系识别或排序代理写成二次目标；
- 保存累计H、b、c等统计；
- 在小缓存上估计旧表示到当前表示的映射；
- 将历史统计迁移到当前表示空间；
- 通过可微目标影响当前模型更新。

后续函数目标版本修复了一些原方案问题，使用完整基线头和共享首域model/Adam/RNG，并明确处理量化与梯度。其核心设置包括：

- d=129的记忆坐标；
- 规范FP16前向及明确的FP32直通反向；
- epsilon=0.001；
- 当前监督B + 0.1历史监督B + 0.5函数保持D；
- D按几何迹3及累计群数N归一化；
- 当前分支使用训练Dropout，历史分支为确定性；
- 以六群估计表示迁移，累计统计覆盖此前合法拟合群。

这一固定配置已完成正式开发，实际实现和结果审查均已收尾。结论是有效负结果，不是未运行、不接通或简单代码错误。

关键指标如下，差值为函数记忆方法减LOGIT0.1：

1. 最终旧域O MAP：
   LOGIT0.1 = 0.460800
   函数记忆 = 0.425195
   差值 = −0.035606
   条件95%区间约[−0.045135, −0.026472]。

2. 第二阶段新域A2 MAP：
   LOGIT0.1 = 0.465073
   函数记忆 = 0.451536
   差值 = −0.013537。

3. 最终新域Z MAP：
   LOGIT0.1 = 0.468989
   函数记忆 = 0.450481
   差值 = −0.018508。

4. 最终整体final_all MAP：
   LOGIT0.1 = 0.463530
   函数记忆 = 0.433623
   差值 = −0.029906。

5. 最终旧域O AP：
   LOGIT0.1 = 0.311544
   函数记忆 = 0.273902
   差值 = −0.037642。

其中：

- O是最终两个旧域的平均，再对三个顺序平均；
- A2是第二阶段刚学完的新域能力；
- Z是最终阶段的新域能力；
- N=(A2+Z)/2；
- final_all=(2O+Z)/3。

必须纳入设计判断的事实：

- 三个顺序的共同首域模型和保存评价矩阵完全一致，不能解释成我们首域起点较弱。
- 新域获得与旧域保持同时受损，没有形成成功的取舍。
- 起始D约为1e−15，旧版本起点大目标冲突的症状已消失，但效果仍不好。
- 历史项实际进入反传，已有独立微型与原生探针证据；不能无依据断言它根本没接通。
- 1728次新增更新均触发全梯度裁剪，但没有正式分项梯度、夹角及Adam贡献分解，不能据此认定裁剪就是病因。
- D的标量比基础损失小，不能据此认定其梯度弱或直接决定增大权重。
- CAB顺序后期缓存为6A/0C，但在第二阶段旧C仍被重放时就已经明显退化，因此缺C缓存不是全部失败的唯一解释。
- 表示迁移矩阵非恒等，但其奇异值不能直接当成未见群上的迁移误差。
- 固定概率工作点下误报减少伴随大量漏检，不能以precision局部上升宣布识别改善。
- 当前证据没有把压缩、表示迁移、历史模式、目标权重等因素作受控分离，不能声称已经识别唯一失败原因。

这些结果否定的是该固定配置的性能目标，不是整个方法家族的数学可行性或创新可能性。

之前另有“保留完整LOGIT0.1，再增加教师正确次序的排序保护项”的草案，已被我明确否决并撤回。不要把它重新包装成你的首选。
