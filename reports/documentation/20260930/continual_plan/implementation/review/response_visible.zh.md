三、目标、随机配对和Adam续接：实际计算一致
当前／历史目标分别归约，再一次更新

源码： 新方法:231–301；step28_alias_ranking.py:89–129；step28_chinese_base.py:165–191。

令

\[ L(g)=L_{\mathrm{BCE}}(g)+L_{\mathrm{rank}}(g)+0.5L_{\mathrm{hard}}(g), \]

则实际为：

\[ L_{\mathrm{SEQ}}=L(g_{\mathrm{current}}), \]\[ L_{\mathrm{ER}}=L(g_{\mathrm{current}})+L(g_{\mathrm{history}}), \]\[ L_{\mathrm{LOGIT}}=L_{\mathrm{ER}}+ 0.5\,\frac1{378}\sum_{i=1}^{378} (z_{\mathrm{history},i}-z_{\mathrm{reference},i})^2. \]

BCE对378个无向对计算一次；原rank覆盖27候选；hard只选择已知负例前5，索引停止梯度、分数保持梯度，并先按查询归约。没有将双正例查询因比较项更多而加倍加权。

代码先反传当前图，再反传历史合成图，期间没有优化步骤，最后一次clip、一次Adam。LOGIT共用历史train前向，没有额外历史forward或教师网络。

独立可微参考使用另一套边列表构造目标，三臂裁剪及Adam一步后，参数逐值相同；当前forward在三臂间一致，ER／LOGIT的历史forward一致。标量目标最大误差约 \(7.11\times10^{-15}\)，梯度最大差约 \(1.46\times10^{-16}\)。

解释限制也保留正确： ER增加历史计算并改变梯度、裁剪及Adam状态，不是等算力SEQ对照。LOGIT学生train、参考eval，使MSE同时涉及均值偏离和dropout方差，不应称为只保持确定性函数。它是阶段末输出保持适配，不是原DER++完整复现或原创方法。
