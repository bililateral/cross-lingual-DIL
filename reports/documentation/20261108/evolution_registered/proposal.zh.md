## 1. 要回答的问题及旧实验为何不能回答

应用问题：系统先登记一批观察账号，依据每个账号的一部分商品文本学习账号关联；随后登记新账号并继续学习。当旧账号又出现不同商品文本时，能否仍把它检索到正确的已登记账号，同时把新登记账号学好？这里的“登记”指进入本次离线模拟的账号库，不能还原为市场真实注册日期。

本任务仍使用 **Evolution market 的标题和正文**，以同一观察账号 vid 为检索正例。它不验证不同账号是否由同一真实控制者操作，也不使用同名、PGP或论坛用户名配对生成同控真值。

| 对象 | 已结束的季度实验 | 本次建议 |
|---|---|---|
| 主要问题 | 在一季度训练后，对未见账号的文本匹配泛化能否保留 | 学过的账号在后续学习新账号后，其独立文本检索能力能否保留 |
| 账号隔离 | 每季度 fit/dev/test 账号互斥 | 开发与确认账号互斥；同一 cohort 内，一个账号的 fit、gallery、query 身份相同、文本互斥 |
| 顺序 | 固定三个自然季度 | 按预先定义的“第4条 fit 文本首次完整观察日”排序，等额登记三批新账号；不是旧季度顺序改名 |
| 文本需求 | 每账号4条、两份各2条视图 | 推荐每账号至少8条，4 fit＋2 gallery＋2 query，并要求角色之间严格较晚的观察日 |
| 检索池 | 群内15候选；后续另做过127候选诊断 | 每批新增96账号；固定引入时账号库96/192/288用于遗忘，增长账号库单独报应用效果 |
| 独立确认 | 新训练种子在封存的未见账号上评价 | 另一批未用于旧训练/开发、也未用于新开发的账号，重新完成登记与训练，再开确认查询 |

原15候选 H/V 平均遗忘为 −.052591/−.022463；127候选为 −.119520/−.030565，均未形成共同明显遗忘。不能把这次新任务的正结果用于改写旧结论，也不能把扩大候选池当成已有解决办法。旧 H_full/ER 没有进入训练，故旧停止不是完整 H 的抗遗忘检验。

新任务的依据是“增量登记已知作者/账号后仍识别其新文本”这一应用需求。NoveltyTask 的作者新增实验报告了只学习新增作者后旧作者性能下降、回放改善保持；AA-CIL研究新增作者的持续学习。这些来源使用作者分类，**不证明本项目的 H/V 多记录检索一定遗忘**，也不把它们的变化候选集准确率差直接当成本稿固定池遗忘量。来源：[NoveltyTask](https://aclanthology.org/2023.findings-acl.113/)、[AA-CIL](https://arxiv.org/html/2408.08900v1)。

### 2.2 推荐资格规则与可证伪容量目标

推荐一次核对以下唯一主规格，不试多个时期/顺序来挑效果：

1. 以 vid 为观察账号，使用严格池全观察期，不把正文条数门改成旧20条。
2. 每账号先按 `(observed, 固定记录哈希)` 取最早4条为 fit；再取观察日严格晚于第4条 fit 的最早2条为 gallery；再取观察日严格晚于 gallery 末日的最早2条为 query。若任一角色不够，账号不合格。允许 fit 内同一天，不能用同日哈希顺序伪造后续日期。
3. 八条正文的原始记录ID、规范化正文均互斥；对这八条额外作全部28对的原5词shingle Jaccard核对，任一达到原 .8 门则整个账号不合格，不替换另一组八条重试。全局跨账号近重复沿原清洗，不以本项宣称召回完整。

5. 推荐开发288账号＋独立确认288账号，共576账号/4608条角色记录。资格需同时满足：全部合格账号至少576，旧test＋未使用账号至少288，旧fit/dev＋未使用账号至少288；分别报告四类来源。旧test原总数不超过288，后续可优先留作确认，再从未使用账号补足，避免开发吞掉确认池。
6. 资格只公布各排除步骤、旧使用类别、角色日期跨度和合格人数的汇总；不输出账号名、文本、逐账号日期/身份或标签。本阶段不选择正式 cohort，不生成训练输入/qrels，不查看任何效果。

## 3. 资格通过后才冻结的数据合同建议

### 3.1 账号、文本、顺序和人工语言检查

资格通过后，建议优先将合格旧test账号留作确认，不足288则用分配种子41及固定哈希从未使用账号补足，再从旧fit/dev与剩余未使用账号抽288个作开发。一个账号只属一个 cohort。两 cohort 分别按第4条 fit 的观察日排序，日期相同时按同一固定哈希排序，各切连续96个为E1/E2/E3；不遍历顺序。报告每批日期范围和边界同日比例；相同采集日内的次序是固定模拟次序，不冒称真实注册先后。若某 cohort 少于3个不同登记观察日，停止本自然登记次序方案，不重抽。这个实际分配规则尚待新合同确认，本次资格不选择账号。

旧test优先用于新确认只是许可后的研究用途转换，不以其在旧实验中表现好坏选择。原季度路线的结果仍然是dev前置门停止、旧test没有完成原确认；新确认不补写成原季度实验成功。

每 cohort：288个账号、1152条 fit、576条 gallery、576条 query，共2304条；全体576账号/4608条。**不是旧160/64/96拆分**。每账号4条 fit 拆成两个2记录视图，8账号组成一训练群：每批12群、16视图/群、32记录/群。固定分组，不跨批重分组。

每个账号另有一个2记录 gallery视图、一个2记录 query视图。它们既不进入拟合、Memory、出生教师，也不与fit共享原始记录。训练身份与评价正例对应由保管器产生；开发/确认文本无identity导出，qrels分离。身份监督相同是已登记任务的定义，文本独立才是本任务要保护的泛化轴。

正式导出时一次固定抽取每批32条开发 fit 共96条作英文判断，仍用每批至少29/32明确英文的有限门；不足即停止、不换样本。人工样本只来自开发fit，研究者不浏览确认文本。旧语言抽查只作为启发式可行性证据，新96条需要单独的数据访问许可。

新确认 cohort 的 fit 身份标签必须供其训练使用，但确认 gallery/query 真值仅由评价器按完整批次门使用；研究者不查看。它的独立性是**未参与旧训练/开发及本轮开发选择的账号与查询**，不等于官方全局清洗从未机器处理过它们。

### 3.2 固定遗忘池与增长应用池

令 `G_d` 为当前 cohort 前d批 gallery视图，大小96、192、288。令 `R[t,d]` 为第t批训练后，第d批固定query对固定 `G_d` 的MAP；每query恰有一个正确账号gallery，无自身候选。每域96个query，三域288个query；不是把每个文本记录当独立query。

遗忘始终比较同一query、同一gallery、同一候选池：`R[d,d]` 对 `R[3,d]`。E1始终96候选，E2始终192候选。评价器可以在批次训练前使用该批已登记gallery测前置能力，但这些文本只供评分，不交给学习器。离线评价未来批次由独立进程执行，不能据其分数选择训练路径。

另报第t阶段对所有已登记query在增长库 `G_t` 上的检索，以及t=2/3时旧query相对固定池的变化；池增加造成的下降只记为库规模/竞争影响，不算主遗忘。所有方法使用同一gallery与候选顺序。保留MAP、MRR、Recall@1/3/5/10、NDCG@1/3/5/10；只有一个正例时MAP与MRR相同，不将二者当两份独立证据。

学习器在每阶段只能加载当前fit；跨阶段只能用自身存活Memory。完整旧gallery可供评价器检索，并不等于允许训练器回放它。缓存评价表征须按每个模型端点重建，不能用冻结的旧表征隐藏encoder漂移。

## 4. 完整H、基线和真实实现需要改变什么

### 4.1 复用英文母体，不再新增适配搜索

以旧有限开发实际选出的 **H1和V1作为固定迁移起点**，两家本轮调参次数均为0。每条新轨迹从现存 `bert-base-cased`（768维、大小写敏感）和本种子新head开始，不恢复已删除Evolution权重。旧选择只说明其在旧开发上的来源，不宣称它在新任务最优。新资格/能力门失败时不自动调学习率。

H1：末四Transformer层求和后按attention mask平均；标题和正文分别编码、各最多256 token，拼接两个归一化768维向量并除以sqrt(2)。记录对用绝对差与逐元素积进入3072→128→1 head，账号视图用原0.5 mean＋0.5 LogMeanExp聚合。FP32、microbatch8；encoder lr=1.2832655111666686e−5、head lr=.0012832655111666686，head恒定、encoder原调度，weight decay=.01。

H当前监督 `B` 为自然分组与重组分组目标均值，每个目标为 `BCE + 1.3051794547562026 × rank + .5 × hard_top5`。完整H为：

`L = B_current + .1 × B_history + .5 × MSE(raw_history_scores, birth_scores)`。

保留六群Algorithm R Memory、整个序列化历史状态1MiB、每更新最多抽一群、仅在前两阶段结束时产生新存活群的出生教师、存活旧教师不刷新。这是已审英文 .1/.5 母体；中文trial3的历史系数没有英文最优证据，本稿不移植或搜索它们。每群8账号/32记录，所以Memory最多48账号/192记录，约为首批96账号的50%、两批旧账号的25%；不是微小固定比例，也不保证均衡覆盖。

V1：同一bert-base-cased，lr=2e−5、weight decay=0，32记录批、最多512 token，训练为当前账号分类；每批重新建立当前类别head，V_ER还含存活Memory类别。检索仍是末四层求和均值表征及原归一化多记录余弦，不用分类head作检索、不擅自改成累积全作者softmax。`VendorLink_SEQ`只保留为旧内部实现家族名称，报告/运行协议明确写Evolution Registered，不能据内部类名误判数据来源。

### 4.2 必要五系统及可归因范围

| 系统 | 当前监督 | 历史监督 | 出生评分保持 | 可检验贡献 |
|---|---|---|---|---|
| H_SEQ | 完整H当前结构 | 无 | 无 | 无抗遗忘机制的H基线 |
| H_ER | 同H_SEQ | .1，六群/1MiB | 系数0 | H_ER−H_SEQ对应回放 |
| H_full | 同H_SEQ | 与H_ER同配置 | .5 | H_full−H_ER对应旧评分保持 |
| V_SEQ | 原V1 | 无 | 无 | 外部顺序基线 |
| V_ER | 同V_SEQ | .1，六群/1MiB | 无 | 外部回放对照 |

H_ER与H_full共用相同当前顺序、reservoir随机流及抽样；H_ER也保留原教师生成/字节生命周期，但不将保持项加入损失，避免额外改变选择与开销。V_ER共用同一群抽样容量，不生成H教师。所有比较固定40 epochs/批，当前更新相同，回放额外前向/反向另记真实成本；不是声称所有系统耗时相等。

本轮不加H0或新的英文候选搜索，不能声称重新分离/证明了英文适配收益。旧英文适配来源清楚；本次要分离的是回放与旧评分保持。若未来要证明英文表示本身的因果收益，另设对等开发范围，不混入本次结果后补臂。

不另写通用训练框架，不改H数学核心。必要Linux CPU核验限于上述新行为；GPU重复资格不默认新增，若实际改动使旧12.1875GiB证据失效，再明确具体缺口。不能以辅助函数存在、手工标签正确或退出码0代替真实生产接线。

## 5. 有限阶段、成功及停止条件

以下全是**待确认的前瞻判据**；新任务数据资格之前不冻结“必然够用”或“必然遗忘”。5个百分点指MAP绝对差 .05，不是相对百分比。

### 5.1 轨迹和结果开放

| 阶段 | 数据/方法/种子 | 新轨迹 | 进入下一阶段的条件 |
|---|---|---:|---|
| 资格准备 | 一次CPU、聚合容量；无模型 | 0 | 满足第2节；新合同/实现/审查及执行许可完备 |
| P：能力与遗忘 | 开发cohort，H_SEQ/V_SEQ，31/32/33 | 6条三批轨迹 | 两基线同时达到能力、新学习、明显遗忘门 |
| M：机制开发 | 同开发cohort，H_ER/H_full/V_ER，31/32/33 | 9条三批轨迹 | 与P共15条完整，Full内部/外部目标和质量保护均满足；不能只看最好的seed |
| C：独立确认 | 未见cohort，全部五系统，51/52/53 | 15条三批轨迹 | 一次完整开分，按全部预定门判断，不改参数/种子/端点 |

最多30条完整轨迹、90个训练阶段。每阶段12群×40轮=480更新，每轨迹1440，最大43200当前更新；三种回放臂在后两批共17280次历史群使用。先做的仅6条、8640更新；P失败则其余24条不启动。M不通过也不进入C。P/M只作开发判断，独立确认不能复用其训练或把新seed当新账号。

固定评分格为(0,1)、(1,1)、(1,2)、(2,1)、(2,2)、(2,3)、(3,1)、(3,2)、(3,3)，每条9格。0为新head/原预训练起点，t<d只评价紧邻新批次的前置能力。整阶段所有方法/seed/端点及盲分数齐全才开该阶段标签；确认只开一次。固定/增长池附加格前瞻列入同批，不追加选择机会。

### 5.2 基线必须先学好且明显遗忘

逐seed、逐旧批：`Q_d=R[d,d]`，`O_d=R[3,d]`，`F_d=Q_d−O_d`（d=1,2）；`Q/O/F`为两旧批等权均值。新批学习量 `G_d=R[d,d]−R[d−1,d]`（d=1,2,3）。同时报告全部逐批/逐seed值，不以最终平均MAP替代。

P中 **H_SEQ和V_SEQ各自均须**：

- 每批初学的三seed平均MAP≥.60、Recall@1≥.45，且每seed/每批MAP≥.55。
- 每批平均G≥.01，各seed G≥0。若零样本已很强却没有可测的新学习，本实验也不满足“新账号仍在学”的前提。
- 平均F≥.05；两个旧批各自平均F_d≥.03；三个seed的F全部>0，至少两个≥.04。

.60/.45/.55是推荐的预实验可用性门，不是假装已有业务SLA；在96—288候选下要求实际排序能力，而非仅高于随机。.05/.03要求超过用户明确不接受的约1个百分点下降。它们不能从本次尚未见的结果倒推。

两者任一未过：停止，分类记录 `STOP_LEARNING` 或 `STOP_NO_JOINT_FORGETTING`；**仅H遗忘同样停止**。不加epochs、不换批次/顺序、不挑seed、不换池、不为造遗忘解冻更多层或调高学习率。

### 5.3 Full成功不能来自少学旧批或新批

对Full和四个参考分别核对，不能混用不同参考的条件：

1. Full每批初学也通过上面的绝对能力门；每个旧批/seed的初学MAP不得比相应参考低超过.02。
2. Full最终旧批MAP：每批三seed均值≥.60，每seed/旧批≥.55，旧批平均Recall@1≥.45；最终两个旧批都不能靠一个批次补偿另一个失守。
3. Full每批平均G≥.01、每seed G≥0；E2/E3学后每seed MAP不得比对应参考低超过.02。净增量比较允许两条逐批路径：`Full G ≥ reference G−.01`；或者Full前置平均MAP至少高.02、学后平均MAP不低于参考，并仍满足上述正学习与逐seed保护。第二条修正“起点更高、学后更强却因增量小被拒”的问题，不能用于放行负学习。
4. 对H_SEQ和V_SEQ：Full平均最终旧能力O至少高.03，平均F至少减少.03；每个旧批平均O不低于参考、F不大于参考。
5. 对两个主要对手 **H_ER和V_ER**：Full的O平均至少高.02，F至少减少.02；两个旧批分别O至少高.01、F至少减少.01；三seed的O/F改善方向都为正。

P的能力/遗忘门在C的两个SEQ上必须重新成立；开发中出现遗忘不能替代确认中复现。M按点值和逐seed门决定是否值得进入C。C再要求Full相对H_ER及V_ER的O/F四个配对差之97.5%双侧条件区间均支持改善方向：固定2000次、按旧批分层、以账号query为单元、方法和seed配对的bootstrap；不重新拟合或扫描重采样设定。区间条件于固定gallery和三个训练seed，不代表市场总体或完整重训分布，逐seed结果另列。

只有上述能力、忘得少、最终旧能力更好、新批仍学得好和稳定性共同成立，才称“本固定新任务的独立确认支持完整H优势”。Full只胜H_SEQ、不胜H_ER，则只支持回放组合或不足以支持旧评分保持；内部过而外部不过则不能称整体优于外部对照。任何失败完整保留，C不通过不接第二次确认。
