2. 为什么改变评分函数，而非再增加保持项

实际scripts/step28_record_replay.py的record_vectors、pair_table、account_logits、objective、backward_group、update、reference、score定义了现行路径。记录r的标题／描述分别由可训练中文BGE编码、归一化和拼接，得到2048维z_r；对称4096→128→1头产生K(r,t)。自然账号X、Y的当前评分为

    s_mean(X,Y)=sum_(r in X,t in Y) K(r,t)/(n_X n_Y)。

对固定K，这个汇总只保留块均值，无法区分同一组高低值是覆盖两侧记录还是集中在单条记录。这里的限定是评分聚合：S的编码器／记录头能够学习，A1监督也能感受一些A0均值看不到的变化，不能声称S整个训练看不到记录交互或其函数类永远无法学好这些例子。

此前C、C_plus、C_cf及Q/C_q等已训练候选主要改变历史监督、来源或保持，最后自然账号评价仍用均值。C_q已关闭结果显示缓存R较Q低，但未建立自然未见账号MAP收益，不能据此断定细节约束一定无用。其历史目标对部分零行列和交互W盲，而本候选使W直接进入最终预测；这是运算差别，不是对C_q失败根因的诊断。

待检验假设H：存在一部分同控账号，身份相关的相容性分布在两侧多条记录之间，均匀全交叉比较把这种对应关系稀释；而部分异控假相似只由单条容易匹配的记录产生。对两侧每条记录都分配固定总匹配量，可以利用前者，限制后者。

H没有从既有结果得到确证。本轮未读取逐样本文本或隐变量来确认其发生比例。若身份信号本来均匀存在于所有跨记录对，或多数记录与身份无关，H可能不成立。缺少一般泛化保证不单独否决候选，但不能把H写成事实。

3. 唯一主候选的完整数学定义

给定一个账号对的n×m有限实数logit块K，n,m均为现有完整记录数2—8。令a_i=1/n，b_j=1/m，U_ij=a_i b_j。允许的P为

    P_ij >= 0；sum_j P_ij=a_i；sum_i P_ij=b_j。

P总和为1。记录数量不等时是分数质量分配，不是强制一一匹配。它不使用账号ID、控制者、域标签、owners或生成隐变量作为推理特征。

定义

    F_tau(K)=max_P {sum_ij P_ij K_ij - tau sum_ij P_ij log(P_ij/U_ij)}。

本提案只有tau=1这一固定设计点，以原logit尺度为单位；没有温度网格、逐账号温度、可学习质量、额外门控或损失系数。固定1是设计选择，不是已证明最佳或无超参数；head logit尺度改变会改变有效选择强度。

候选自然评分s_bal(X,Y)=F_1(K_XY)。训练A1时按真实重组后的两个账号槽位取块，使用同一F_1。原始完整标题／描述、全部记录、BGE、记录头、A0/A1重组分布和两视图监督均保留。正负账号对完全使用同一评分公式。

保留熵项在最终评分内：仅求P后输出sum(P*K)是另一种函数，其完整梯度一般也不是P，不能在实现中悄悄替换。

4. 数学作用及三个手算对象

有限K、tau>0、正边际保证严格凹目标的唯一最优P*。本提案使用其最优值而非把任意迭代矩阵称为最优解。

（a）常数块K=c时，P*=U，F_tau=c。因此KL相对U归一化避免把n,m带来的纯熵常数混进分数。精确数学下交换账号、同时转置K不改分数，账号内部记录置换也不改分数。任意有限实数K都可求该优化，不要求记录头形成PSD核，但也不因此宣称F是满足三角不等式的距离。

（b）令G_tau(K)=tau log[(1/(nm)) sum_ij exp(K_ij/tau)]，即只有总质量约束的熵正则最大化，则

    mean(K) <= F_tau(K) <= G_tau(K) <= max(K)。

第一项来自可行U，第二项来自去掉边际约束扩大可行域。候选输出相对相同K上升不等于准确率上升，BCE、校准及排序均须重新按候选的实际训练输出评价。

（c）对任意行／列加性项u_i+v_j，所有可行P对它的加权平均均固定，故

    F_tau(K+u1^T+1v^T)=F_tau(K)+mean(u)+mean(v)。

写K=mu+alpha_i+beta_j+W_ij，alpha/beta均值为0、W各行列和为0，则

    F_tau(K)=mu+F_tau(W)。

这说明相对均值的新增量只由交互结构W决定；它没有消除原有行／列偏置，原均值mu仍在。对于非零W，沿U+epsilon W作足够小的可行扰动，一阶收益正而KL从二阶开始，故F_tau(W)>0。这也暴露风险：无用噪声交互也会得到正奖励，不能把新增量叫作身份信息。

（d）一对2×2手写分数块：

    K_cover = [[2,0],[0,2]]；K_row = [[2,2],[0,0]]。

两者均值都是1，最大值都是2，全局G_tau也相同。K_cover的最优P对角两项各p/2、非对角各(1-p)/2，p=1/(1+exp(-2/tau))，代入得到

    F_tau(K_cover)=1+tau log cosh(1/tau)。

K_row只有行加性变化，所有可行P的线性项都为1，KL在U最小，所以F_tau(K_row)=1。tau=1时F严格区分两者，而均值和G不区分。它展示双边覆盖真正增加的运算，不是模型在正式文本上的已验证优势。

（e）反例同样完整。若真实正例的块全部为c=1+(1/2)log cosh(1)，真实负例却恰好为K_cover，则均值给出c>1的正确次序，F_1却把负例提高到1+log cosh(1)>c，反转为错误次序。不同控制者具有可匹配主题／模板时就有类似风险。不能靠把例子的标签指定为正例来证明效果。

上述是人工解析推导，没有在Windows执行矩阵算法、科学测试、重采样或从项目数据验证。将来仍需Linux独立数值参考核验实际求解器及其梯度。

5. 目标、梯度与实际接线

沿用B=BCE+逐查询rank+0.5 top5-hard，令对每臂评分函数f，Bbar_f=[B(s_f(A0))+B(s_f(A1))]/2。每条轨迹保留自身出生域末、eval模式下的原记录表T，不调用其他旧教师，不重建已删权重。

    D_f = mean_(378自然账号对) [s_f(K_current,A0)-s_f(T_birth,A0)]^2；
    J_f = Bbar_f(current)+0.1 Bbar_f(history)+0.5 D_f。

首阶段只有当前监督。完整S使用f=mean；主候选使用f=F_1；第7节机制对照使用f=G_1。D_f随预测函数一致改变，不能把它声称为完全保留原均值D0的数值目标。S的原公式和来源保持不动。整体比较同时含训练、保持和推理聚合的变化，不是单独推理重评分消融。

准确求解时，最优值对K的导数为P*；均值则是U。一个账号对的上游标量梯度dJ/ds会把P*而非U分配给记录对，进而经既有proxy表求导、512对确定性head分块VJP、leaf记录梯度及live encoder反传，最后当前／历史累计、clip=1及原AdamW。唯一最优值的包络导数允许不对精确P*的求解过程求导；这不授权对未收敛P随意stop-gradient并冒称准确梯度。

若实施，需要让新评分器实际贯通以下入口，而非只改训练objective或加日志：
- 新实验入口和objective中的A0/A1监督及D_f；原生真实encoder/head更新。
- 最终score、校准前raw分数、盲预测、所有保存恢复比较。
- scripts/step28_replay_diagnostics.py当前score分支和teacher_errors。该模块目前非LOGIT路径默认调用record.score，残差也直接调用record.account_logits；仅传一个新arm名字会静默仍用均值，这是本候选具体的伪实现风险，必须显式接线且保留S行为。
- 元数据／模型恢复绑定pooling模式和tau；来源T用同一f生成停止梯度的目标。不能在恢复后悄悄回退mean。

tau固定且无新增可训练参数，不表示学习轨迹、表达能力、过拟合或开销不变。首阶段监督已经不同，三个臂须从相同未训练初始化独立完成A；不允许共享已经训练的S首阶段完整状态。

6. 求解、保管与资源边界

拟用批量、log域的Sinkhorn行列缩放；K仍由原BF16 encoder／FP32头产生，小块求解可转FP64。对固定正边际，核为逐项exp(K/tau)，P=diag(u)exp(K/tau)diag(v)。log域更新为

    log u_i = log a_i - logsumexp_j(K_ij/tau + log v_j)；
    log v_j = log b_j - logsumexp_i(K_ij/tau + log u_i)。

只在实际n×m有效块上计算，不给padding分配质量。有限迭代不自动得到精确双边约束、转置对称或包络梯度。实施合同须明确收敛判据、最大迭代、最优值／梯度误差及失败行为，并以手写最坏形状验证；本提案不假定20轮够用、不设置悄悄回退mean或单边softmax的分支，也不声称已有数值资格。此处是实施前需要落实的数值条件，不是已取得的许可。

单账号块最大8×8，每群每视图378块；原分组和重组共756次小块聚合，历史还需停止梯度的来源聚合。若每块I轮，每视图工作量O(I sum_(i<j)n_i n_j)，224记录时跨账号项最多24,192；上限I尚未由资格确定。新增BGE前向次数无需因这个数学定义增加，但GPU小算子调度、同步、FP64及诊断累计时间必须实测，不能从8×8就宣称零开销或沿用旧C_q时间上限。

继续六群Algorithm R、完整现有Memory≤1MiB。保留原FP32全表T，不新增教师网络、每步旧模型、全域缓存或永久耦合矩阵。P为派生临时量；若实现中缓存来源聚合或跨步派生对象，须明确计入实际持久／驻留开销，不用“可再算”豁免。推理不调用历史Memory，输入仍仅当前两个自然账号的完整记录。

7. 最小可证伪比较草图——尚未批准

只提出完整S（mean）、全局softmax聚合（G_1）、平衡匹配（F_1）三臂，所有原训练项、重组分布、数据供给、随机键、优化器、模型和每阶段更新数配对；各臂保持自己的来源轨迹。G_1是去掉双边覆盖的机制对照，不是某篇完整DeepEMD的冒名复现。无需先跑一组，再看结果临时补第三组。

第一轮可限定s0、A→B，各臂独立两阶段，各阶段288更新：3×2×288=1,728次optimizer调用；梯度群呈现为3×(288+2×288)=2,592；6个物理端点、36个逐epoch诊断点。以上只是可审查工作量，不是启动许可；CPU/GPU核验、额外纯前向、完整恢复、预计时长／磁盘及标签访问需另外形成合同。旧S／C_q权重已删除，不复用不存在的起点。

预定问题：F_1−S回答整体性能价值；F_1−G_1回答在共同熵优化及tau下双边约束的条件作用；G_1−S说明普通择优聚合是否足够解释提升。分别报告最终旧域A与新域B自然账号MAP、配对条件区间、原完整排序／概率指标、阈值TP/FP/宏率和成本。没有新总通过门、旧23项移植或结果后设非劣幅度。

首阶段也报告，才能看出新评分是否首先改善学习；同时保留最终旧域绝对表现和遗忘量，不能仅靠较低首阶段起点声称保持改善。训练／缓存—valid诊断必须用该臂真实F/G评分，沿既有严格标签和原差距值共同解释。仅训练loss降低、F输出普遍升高或solver PASS均不算效果。

若F未建立相对S收益，结束本固定候选，不自动降温度、改边际、换最佳epoch或添保持项。如果F胜S但未胜G，则双边覆盖的必要性尚未建立，可能普通非线性聚合已解释收益。如果只在B改善而A退化，如实报告取舍，不能称两域全面超过S。即使首轮正向，它仍是单seed、已开发valid上的候选结果，确认范围另定，不把它改名为独立最终留出。

未来最小实现核验只围绕新增池化：第4节闭式例、行列加性性质、常数块／不同n,m／转置／置换、去掉边际会落到G、固定K上均值与F实际不同；收敛与独立有限差分／参考梯度、encoder/head实际更新、推理／诊断／恢复确用正确f。未变VJP、数据及统计证据按适用范围复用，不全仓回归。

8. 与已有方法、旧路线的关系

DeepEMD（CVPR 2020及作者扩展版）已经把局部特征匹配、传输边际、最终集合相似度和端到端学习接在一起；其cross-reference生成节点质量，也可减少无关背景。本文用完整文本记录、对称可训练pair head、均匀边际、KL相对独立计划的最优值，并纳入S的联合重组和出生输出保持。差异可描述，但核心“匹配聚合比均值更好”不是新原则，也不能根据其图像结果预计本项目会赢。

Cuturi的Sinkhorn工作已经给出熵正则传输、矩阵缩放与批量计算。唯一解、置换性质、包络导数及第4节常见优化性质不能列成原创贡献。矩阵最优值用于有限记录关系排序是任务化适配，目前未建立足以单独支撑最终方法论文的新颖性。

既有收缩保持静态候选使用的是历史排序响应之间的弱OT／凸序约束，本候选则在每次账号预测中匹配两侧原记录。二者不是同一计算位置、对象或训练目标；不恢复其旧实现／预算／许可，先前静态否决仍有效。Q/C_q改变历史查询增强和保持，当前候选从首阶段起更换预测聚合，不能把旧Q负结果视为本候选已被测试。

现有S可仍作为论文主体；本候选若有用，可以作为系统改进。若用户要求的是已经确立独立原创机制的新主算法，本轮交付尚未达到这一要求，不能用新缩写或复杂求解器补足。

9. 反对性风险与静态审查重点

最强风险是第4(e)的错误匹配，以及A1同控重组可能使两槽共享原账号来源的不同记录，产生比自然未见账号更容易的匹配。当前保留A1，未声称消除该现象，也未追加来源屏蔽；若实证发生，它可能使候选比S更差。均匀边际还会强制无信息记录参与，记录数量不等时也没有天然对应真值。正则熵只能缓和择优，不能证明匹配身份正确。

此外，固定tau可能因head尺度变化失效；新分数的D_f仍只保护六个缓存群，不保证未见身份；无新增参数仍可扩大有效函数选择和过拟合。候选与S相同计算更新数不等于相同墙钟。数学定义清楚和直接近邻已知，不替代这些实证问题。

送审只请判断：此假设和实际运算是否值得有限性能检验；是否存在使其等价／退化、梯度错误或必然不公平的关键问题；上述三臂能区分哪些解释；如何诚实定位新颖性。不同意时指出最小致命理由，不为救方案自动增添可学习边际、双分支、更多损失或温度搜索。此轮不要求它保证获胜，也不以“缺少全新定理”单独否决性能研究。
