## 2. 核心算法判断

**接受“未发现已证实核心科学阻断”，不接受将其扩大为效果或创新已经成立。** 此轮的实质改进是固定baseline完整头和共享首域起点，用阶段末函数目标替代立即拉回±1／间隔2的硬目标，同时保留全部合法历史拟合群的累计统计与六群表示迁移。

第一，当前与历史监督仍使用真实FP32评分和完整B，函数分支才使用统一FP16前向坐标。末层w来自真实参数拼接，未新增或截断参数。自定义直通梯度明确是估计；它避免额外梯度量化，但不等于离散舍入的真导数。

第二，H/b/c对应固定规范坐标下的函数平方残差，逐query先平均、再平均28个query。几何迹3成立，因此D除3N与合同一致。它不是BCE/rank/hard的精确历史摘要，也不保证与LOGIT的0.5MSE梯度等强。生产solve保留经p及直接epsilon*w两条梯度通道，当前反传之后历史0.1B+0.5D联合反传，统一clip和Adam一次，关键项实际进入更新。

第三，新建目标同参数时D和梯度应为零。外审独立得到D约3.47e-18、Y/w梯度范数约5.28e-17/2.02e-16，符合浮点抵消尺度。这有针对性地消除了旧硬目标在正确大间隔上立即施压的机制；它并不意味着后续两个目标不冲突，或已证明旧退化由Q独自造成。当前B、历史B和已有Adam动量仍会改变参数。

第四，固化实际先联合旧六群估计T，再运输H和b，c保留；加入当前48群新教师后才更新reservoir与参考。外审不同群漂移例中联合T与仅首群T最大差0.518111，实际H与独立参考差6.96e-13，b与错误重置H*w_new的差26.444672。该证据比原相同z用例更有区分力，支持旧目标确实保留。直接复用该可复核证据，不为了测试数量再跑相同项目用例。

第五，历史确定性模式覆盖forward、backward及checkpoint重算，退出后恢复。当前B仍保留baseline随机模式，因此只能说共享头／起点／日程等条件，不能说与LOGIT全部训练条件完全相同。拟在同一次原生步中轻量记录实际版本、attention类和历史内外Dropout概率，不追加运行次数。
