# 持续学习抗遗忘科研进展汇报

汇报日期：2026年10月22日。本文整理已完成、已开放的实验结果；正在运行的实验采用最近一次服务器实查快照（10月22日10:50，北京时间）。除特别注明外，指标以0—1小数表示，保留六位小数。

## 一、科研主线与目前进展

本项目围绕**卖家多账号关联识别与候选排序中的持续学习抗遗忘问题**展开：随着新的数据域依次到达，模型既要学习新域的表达方式，又要在有限历史记忆下保留对旧域的识别和排序能力。当前实验在受控合成数据上开展，模型只使用屏蔽身份信息后的商品标题和描述，不把账号ID、控制者身份或域标签作为模型特征。

研究主线是：**建立遗忘问题与基础参照 → 检查经验重放和历史输出保持 → 引入记录级匹配与同控重组监督 → 改进账号评分和排序目标 → 通过公平调参与复验检验收益是否稳定。**

| 阶段 | 主要工作 | 已获得的认识 |
| --- | --- | --- |
| 问题建立 | 从固定特征、LaBSE探索推进到BGE三域持续学习，比较SEQ、ER与LOGIT | 初期设置并非都能产生稳定遗忘；在后续表达机制变化的设置中建立了遗忘现象，不能只靠“顺序训练”就假定抗遗忘方法有效。 |
| 基础方法比较 | 建立SEQ、有限缓存ER、历史logit保持LOGIT，并比较历史监督权重 | 重放强度过大会损害新域学习；降低历史监督权重后有所改善，LOGIT进一步改善旧域保持，但收益需要同时检查新域代价。 |
| 记录结构与重组监督 | 从账号整体表示转向记录对评分，建立R0与完整S；完成三域、三顺序归因实验 | 完整S相对同架构无重组的R0，在旧域、新域和最终最新域MAP上均有正向条件区间证据，成为后续主要内部对照。 |

**当前最值得汇报的候选是H_pos：固定A→B实验中，旧域A的MAP达到0.526069，较完整S提高0.031937；新域B的MAP为0.499687，较S低0.006184，差值区间跨零。因此已有旧域局部正向证据，但尚未达到双域同时超过S的目标。**

## 二、任务设置与方法定义

近期BGE实验共用`BAAI/bge-large-zh-v1.5`，编码器与评分头联合训练。每个候选群有28个账号，每个查询在其余27个账号中排序，包含1或2个同控正例；每群同时产生378个无向账号对。每域使用48群拟合、12群校准、20群开发评价。每阶段训练6轮、288次参数更新，使用历史记忆的方法最多保留6个完整群，记忆及相关状态不超过1 MiB。

设单群监督损失为`L = BCE + rank + 0.5 × hard`，其中hard关注top-5已知负例；`D0`表示历史自然视图上的出生教师logit保持损失。

| 方法 | 核心设计 | 本文采用的配置与角色 |
| --- | --- | --- |
| SEQ | 只用当前域训练，不重放历史样本 | 基础顺序学习参照，用于观察遗忘与学习能力。 |
| ER | 当前损失 + λ × 历史监督损失 | 主表明确采用ER0.1，即λ=0.1；三域汇总同时保留ER1，展示降低重放权重后的变化。 |
| LOGIT | 当前损失 + λ × 历史监督损失 + 0.5D0 | 主表采用LOGIT0.1；这是本项目具体适配的输出保持基线，不能直接等同于未修改的标准DER++实现。 |
| S | 记录对评分取均值；自然视图和同控重组视图的监督取平均，再加0.1历史监督与0.5D0 | 主要内部强对照；区别于SEQ／ER／LOGIT的账号整体表示架构。 |
| H_pos | 记录对混合池化评分 + 逐正例排序；其余沿用S/H的训练与记忆框架 | 目前重点研究的候选；下面所有H_pos结果均加粗。 |

ER和LOGIT后缀的0.1是**历史监督权重**；正在搜索的`lambda_rank`是**排序损失权重**，两者不是同一个参数。S与H_pos的差异同时涉及评分池化和排序目标；单独评估新排序目标在H上的作用，应查看H_pos与原H的比较。

## 四、H_pos的实验设计简述

H_pos继承记录级匹配框架，主要有两个组成部分。

**第一，记录对混合池化。** 每条商品记录的标题和描述分别经BGE编码、归一化后拼接为2,048维记录向量。对两个账号的记录向量构造对称配对特征，通过`4096 → 128 → 1`的评分头得到记录对分数矩阵K。账号对分数沿用原H的固定混合方式：

```text
score_H(K) = 0.5 × mean(K) + 0.5 × log(mean(exp(K)))
```

温度固定为1。均值部分保留整体匹配信息，log-mean-exp部分相对强调较高记录对分数；实际池化使用稳定计算。它与S只取均值的评分方式不同。

**第二，逐正例排序目标。** 对查询q的每一个正例p，分别计算它相对全部已知负例的排序损失，再对正例和查询取平均：

```text
L_pos(q) = mean_{p∈P(q)} log(1 + Σ_{n∈N(q)} exp(z_n − z_p))
```

另一正例不进入负例集合。该目标属于已有RINCE相关目标的任务适配；原rank也是合法目标，因此本实验是在改变梯度分配和有效损失权重，不能称为修复原目标错误或已经证明原创机制。

自然分组视图A0保留原账号分组；同控重组视图A1只在训练标签允许的同控账号内部打乱完整记录，再按原账号的记录数量重新分配，不跨控制者、不拆开标题和描述，评价时仍使用自然分组。两种视图均使用新rank，当前群和历史群也全部替换。完整训练目标为：

```text
B_pos(view) = BCE(view) + L_pos(view) + 0.5 × hard(view)
Bbar(group) = [B_pos(A0) + B_pos(A1)] / 2

A阶段：J_A = Bbar(current)
B阶段：J_B = Bbar(current) + 0.1 × Bbar(history) + 0.5 × D0(history)
```

D0只保持本臂自然视图的历史出生教师输出，独立使用0.5权重；不再额外叠加旧rank或H_cons的一致性损失。编码器、评分头均参与真实梯度更新。固定H_pos实验独立初始化，训练A、B各6轮，共576次参数更新、864次梯度群呈现，保留A末和B末两个评价端点；上述效果来自这一固定配置，不是Optuna筛选后的最好结果。

## 五、正在开展的实验：三臂公平Optuna调参

当前实验同时覆盖**S、S_pos、H_pos三臂**，检验在有限范围内调整排序损失权重和学习率后，候选能否改善双域表现，并让原S获得可比的调参机会。即使本轮未获得优势，也只能约束该搜索范围下的结果，不能否定整个方法家族。

| 项目 | 当前执行设置 |

## 六、汇报时应保留的结论边界

1. **已完成的进展**：建立了问题、基础方法和完整S对照；三域归因支持重组监督的增量价值；H_pos已有旧域局部正向结果，并正在接受三臂等机会调参与复验。
2. **尚未完成的结论**：没有证明H_pos在旧域和新域上同时稳定优于S，也没有证明其在三域、不同顺序、多训练种子或独立数据上普遍有效。
3. **持续学习主线需要的后续证据**：最终候选冻结后，仍需在明确方案和预算下补充完整三域、多个顺序及种子的比较，并安排合适的独立确认。它们是待规划的工作，当前运行的36+9次A→B不会自动完成这些验证。
4. **编码器与模型扩展的定位**：第二编码器、记忆容量敏感性等可用于检验适用范围，但目前没有启动这些新实验；当前优先完成既有三臂搜索和复验，再依据完整证据决定后续范围。
