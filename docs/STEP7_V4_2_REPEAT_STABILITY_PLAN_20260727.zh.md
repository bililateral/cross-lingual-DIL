# Step 7-v4.2：M0 新分折种子重复稳定性审计

## 目的

本轮在 Windows CPU 上重复 Step 7-v4.1 的完整英文模型比较，但使用五个此前未使用的卖家身份分量折种子。它回答：

> 在数据、特征、22个候选、分类器网格和选模规则完全不变时，`LightGBM + legacy18 + LaBSE` 是否仍是聚合训练折外结果的第一名？

同种子原样重跑只验证确定性；新种子重复可以检查候选是否依赖某一次分折。但数据仍是原来的401条英文 pair，因此本轮不是独立确认集，不能证明唯一最强或真实泛化。

## 冻结边界

- 主候选在运行前固定为 `lightgbm__legacy18_labse`。
- 新外层种子固定为 `2026072701–2026072705`。
- 主集与完整去精确文本克隆压力测试都从分折、折内参考统计、调参、校准和阈值重新运行。
- 旧 valid 和历史 test 标签值均不得读取。
- 现有 Step 7-v4/v4.1 产物不得覆盖；新输出写入 `reports/step7_v4_2_repeat_stability/v1_20260727/`。

## 指标

完整报告 pair 等权与身份分量等权的 ROC-AUC、AP、PR-AUC、Precision、Recall、F1、Balanced Accuracy、Brier 和 Log loss。检索诊断增加 MAP、MRR、Hits@1、Precision@1/3/5/10、Recall@1/3/5/10，并强制报告有效查询数；由于真实英文候选标签图不完整，检索指标不参与选模。

## 解释

- 若主候选仍为聚合第一，只能说明它在另一组合法分折下重复为当前同数据第一。
- 若主候选不再第一，则不能继续把它描述成稳定赢家；仍可由研究协议预先指定为固定来源基线，但必须报告候选敏感性。
- 无论结果如何，只有新的、模型冻结后收集的真实英文确认数据才能支持“独立确认的最强英文模型”。
