## 1. 要回答的问题及四臂的作用

目标是在学习新域B之后，提高自然旧域A中未见账号的排序，同时报告新域B的学习代价。完整S为主要内部对照，架构、训练方式和有效设置均保留。候选只改变历史分支：保留完整自然账号作为查询，把该账号的全部记录排除出候选重组池，并在原历史均分约束之外，保持旧模型对其他来源记录的中心化响应。

这里的“旧模型／教师”只指本轮同一中文BGE在A结束时给六个存活历史群保存的评分表T。B阶段继续更新的同结构模型是学生；不引入另一个外部教师模型。主张是这些旧响应可能帮助识别旧分布中的新账号，不把记住六个缓存群当成目标本身。

| 臂 | 当前群目标 | 历史群目标 | 该比较可回答什么 |
|---|---|---|---|
| S | 完整S的两视图监督 | 0.1 Bbar＋0.5 D0 | 主要对照，原配置完整保留 |
| Q | 同S | 0.1 Bbar_q＋0.5 D0 | Q−S：整套历史增强替换的收益及代价 |
| C_q | 同S | 0.1 Bbar_q＋0.5 D0＋0.25 R_q | C_q−S：候选整体价值；C_q−Q：在Q增强下加入R_q的条件增量 |
| C_b | 同S | 0.1 Bbar_b＋0.5 D0＋0.25 R_q | C_q−C_b：固定同一保持项时，跨账号无放回重组相对账号内bootstrap的价值 |

四个比较事前固定，分别判读；不增加S＋R、R_boot、C_perm、旧C、C_plus或随机R臂。C_b是嵌入共同框架的普通策略对照，不冒充某篇论文的完整复现，也不是其自身抽样律下的最优设计。Q−S同时改变查询自然性、单双端重组、候选相关性、正例多样性和交互可见性；C_q−C_b同时改变跨账号混合、有／无放回及记录覆盖。两者均不能单独确诊旧S的来源捷径，也不能证明来源排除本身的纯因果作用。C_q−Q不证明Q与R存在独特协同。

## 3. 新历史分支的精确定义及实际更新

### 3.1 查询锚定、来源排除与随机键

以已有Group／Memory中的账号和记录次序为规范顺序，不重新按文本或评分排序。X_a为原账号a的完整记录集，n_a为记录数。正关系图必须校验为既定8K2＋4K3，分量按其最小规范账号索引排序；不从owners或隐藏控制者字段重建。

一次历史群呈现遍历全部28个自然查询q。固定完整X_q；对每个正关系分量g，令`H_qg=g\{q}`、`M_qg=sum(n_a, a∈H_qg)`。将H_qg中全部记录的规范索引均匀无放回打乱，再按H_qg账号的规范次序及原n_j分槽，得到Y_qj。每行有27个候选、槽大小不变、原标签y_qj不变；该行所有非查询记录恰好使用一次，X_q的任何记录都不得进入任一候选。若H只含一个账号，候选就是其完整原账号，不额外抽样。

各查询独立抽取行条件分配；记录可在不同查询行重复使用。同名候选j在不同行不必是同一个合成账号，故Q通常有向。计算

    Q_qj = sum(K_sr, s∈X_q, r∈Y_qj) / (n_q*n_j), j!=q。

不得取上三角后复制、强制对称、漏掉反方向或给对角线标签。可先算原查询均值`u_qr=mean_s∈X_q K_sr`再按索引池化，复用同一K，不进行28次encoder前向。

随机抽样使用局部`random.Random`及现有`seed_for`序列化：C_q与Q共同采用`seed_for(20260918,"query_replay", "ABC",stage,step,history_uid,q,component_index)`。这里`query_replay`是增强规则标识，不能替换为Q／C_q臂名。C_b使用`seed_for(20260918,"within_account_bootstrap","ABC",stage,step,history_uid,q,j)`，对原X_j有放回独立抽取n_j次、按多重集计权。各规则均不消费数据顺序、Memory抽取、当前A1或dropout的随机流；不因臂的执行顺序改变样本。

C_b也固定完整X_q并排除查询来源，候选大小／27标签和C_q相同；它可能重复或漏用某些记录，不满足C_q的行内全记录守恒。这些不同要随结果一起解释，不称为全部因素匹配。

### 3.2 有向监督与解析保持项

对有向Q定义P_q为正例候选、N_q为已知负例，H_q为其中当前分数最高的5个负例。top5只停止对索引选择求导，所选logit仍有梯度；相同分数按原规范账号索引打破并列。全部项排除j=q：

    B_row(Q) = (1/756) sum_q sum_j!=q BCEWithLogits(Q_qj,y_qj)
             + (1/28) sum_q [logsumexp_j!=q Q_qj - mean_p∈P_q Q_qp]
             + (0.5/28) sum_q mean_(p∈P_q,n∈H_q) softplus(Q_qn-Q_qp)。
    Bbar_q = [B(A0)+B_row(Q)]/2；Bbar_b用Q_b替换Q。

自然对称分数下B_row(A0)与原B(A0)在实数代数上等价；浮点规约顺序可不同，不预设逐bit相同。正式A0监督继续调用原B，不用这一代数等价重写S。

对于r∈X_a、a!=q，定义

    u_qr(K)=mean_s∈X_q K_sr；mu_qa(K)=mean_r∈X_a u_qr(K)；
    v_qr(K)=u_qr(K)-mu_qa(K)；e_qr=v_qr(K_theta)-v_qr(T)。
    b_qg = sum_j∈H_qg (M_qg-n_j)/(n_j*M_qg*(M_qg-1))；
    R_q = (1/756) sum_q sum_g b_qg sum_a∈H_qg sum_r∈X_a e_qr^2。

所有合法n_a≥2，非空H的M≥2，不用epsilon改分母。查询所在K2的唯一正候选满足M=n_j，系数严格为0；其余结构非零系数不保证模型梯度非零。教师T及其v停止梯度；K、查询均值、中心化及R中的学生路径不得detach。

R_q是以下随机平方的精确期望：令`c_qja=|Y_qj∩X_a|/n_j`，`delta_qj(K)=Q_qj(K)-sum_a c_qja*mu_qa(K)`，则`E[(1/756)sum_(q,j) (delta_qj(K_theta)-delta_qj(T))^2]=R_q`。正式只用解析式，不额外采样随机R，不用`B_row(E Q)`替代`E B_row(Q)`。

C_q最终目标为`Bbar(current)+0.1 Bbar_q(history)+0.5 D0+0.25 R_q`。C_b采用完全相同的R_q，不换成其自身bootstrap律的保持项：后者单候选均值误差的二阶矩通常为`sum_r∈X_a e_qr^2/n_a^2`，与上述b不同。固定同一R是条件控制，不是证明两种抽样律等价。系数0.25只有这一固定点，无网格、自动归一化、退火或事后调参。

### 3.3 从目标接到真实参数更新

拟新增`step28_query_replay.py`的查询分配、B_row、解析R及候选objective/update包装；通过现有`record.backward_group(..., objective_fn=...)`接线。无reference的当前分支严格调用原S目标；有reference的历史分支按S／Q／C_q／C_b选择上述目标。S走原路径，不靠候选逻辑中的相似公式模拟S。

实际链路是：encoder得到记录表示→head分块得到K→proxy上的真实目标求`dJ/dK`→既有head分块VJP累加head及记录叶梯度→`z.backward`进入encoder→当前／历史合并、clip、AdamW。不能只记录R、只改缓存值、在no_grad中计算学生目标，或另做一次独立优化更新。

对对称存储的异账号记录对s∈X_q、r∈X_a，R表导数包含两个查询角色：

    dR/dK_sr = (2/756) [b_q,g(a)*e_qr/n_q + b_a,g(q)*e_as/n_a]。

再乘0.25进入总目标。Q对所用K的直接权重为1/(n_q*n_j)，C_b按重复次数累加。候选历史目标对同原账号记录对的直接表梯度应为0；这不表示共享encoder／head参数完全不受这些记录影响，也不表示当前S分支排除了同来源作用。

### 3.4 保留的信息、损失的信息与近邻界限

R保留的是“完整自然查询对某条异账号记录的响应，相对该记录所属自然账号平均响应偏高／偏低多少”的数值幅度。只有当这种旧响应能在账号之外迁移、旧评分有用且新约束没有过度妨碍B学习时，才可能改善旧域未见账号排序；这些条件由本次自然A0结果检验，不能从R下降或缓存拟合改善推出。

对异来源K误差块，写`E_sr=m+alpha_s+beta_r+W_sr`，其中alpha／beta各自零均值、W行列和均为0。D0看到m；R看到相应行／列边际。**整个候选历史目标**都看不到W，S的双端重组可能看到它；并非只R有这一盲区。K2正例两端都不变且两方向b=0，所以该正例块中所有总均值为0的变化都不可见，其盲区维度为n_q*n_a−1。一般W盲区维度为(n_q−1)(n_a−1)。

上述K2总零均值块盲区针对Q／C_q；C_b的账号内bootstrap可见K2正例的部分边际变化，不能把其盲区也扩大成相同结论。Q／C_q每群16个K2查询的正候选保持自然账号；12个K3查询各有2个正候选可重组。756个有向单位中40个为正，其中24个具有非平凡正例重组的结构条件；716个为负。不得把所有正例都称为增强，或把结构非退化等同实际非零更新。

R仍可保持查询无关的记录偏置。例如`E_sr=t_s+t_r`且各原账号内t均值为0时，D0可为0而R为正；排序不变的幅度变化也可能被惩罚。因此不称R为纯身份信息、纯排名保持或已经剔除公共风格。训练中的student dropout与出生T的eval模式不同，同权重不自动意味着R=0；只有实际两张表满足条件时才能作零值核验。

已有ConSlide／PseMix／ReMix／C²Aug覆盖同类袋或特征重组，FDR／DER覆盖函数响应保持，RankDistil覆盖排序蒸馏，中心化／标准化也有先例。相关作者正文、阅读范围及具体区别复用[原方案§11](../reports/documentation/20261013/query_replay/proposal.zh.txt)和[主审§7](../reports/documentation/20261013/query_replay/review/primary_disposition.zh.txt)。本候选可主张的增量在“自然查询完整且来源排除的关系输入分配＋与其抽样律对应的旧边际响应选择”这一具体运算与取舍；平方误差、无放回、中心化或教师本身不作首创点。无需为本次合同扩建全方法基准。

| 四个B分支更新 | 4×288=1152 |

    W_projected = ceil[1.10*(2*W_F + 5*W_I + 2GiB)]。

两份完整状态覆盖共享A与当前B，五份推理状态覆盖五个端点；2GiB覆盖Memory、盲分数、统计／诊断、日志、冻结来源、资格及编排旁文件，另留10%序列化余量。原生临时大型文件先留身份并清理，不与正式峰值叠加。旧实测W_F=3,904,607,789、W_I=1,304,377,675代入得18,126,446,362字节，约16.881569GiB，因此本轮建议18GiB，不能直接沿用旧16GiB。

启动用新实测验证投影≤18GiB。每次写大文件前核对目录当前占用及保守reserve；持续监控RSS、CUDA reserved和独立workspace实际输出，包含资格证据及启动／监听旁文件，不跟随正式输入软链接扫描数据。不得额外复制一个完整模型文件后仍按两份计数；若实现产生临时副本必须计入峰值。主存也不通过多模型常驻换取未计时间。

每个Linux阶段先核对用户、项目路径、同作业PID／监听及他人资源。正式GPU0无其他计算作业、空闲显存≥30GiB、主机可用内存≥72GiB、项目盘可用≥18GiB且覆盖实际峰值reserve、单CPU有余量才启动；旧资源观测不是现场证据。资格按自己的6GiB临时范围核对。不得停他人作业或扩大清理范围。

本轮执行获准且审查／资格／投影齐全后，若只因资源不足等待，依纪律沿用或创建一个一次性监听；确认没有原作业／监听才创建，既定条件满足只启动一次。确认正式实际更新后删除Linux活动监听源码，保留冻结脚本及启动／自删回执。监听不因GPU空闲越过前提、不重启失败作业；手写资格与正式前提分开核对。
