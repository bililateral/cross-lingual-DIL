## 已批准的诊断指标与判断规则

对首域 X、后续域 Y，在相同 valid 群上分别计算：

- 同域学习余地：同域分支最终在 X 的指标减去首阶段在 X 的指标。
- 换域的新学习：换域分支最终在 Y 的指标减去首阶段在 Y 的指标。
- 换域的旧能力变化：换域分支最终在 X 的指标减去首阶段在 X 的指标。
- 同等更新下的旧域差：换域分支最终在 X 的指标减去同域分支最终在 X 的指标。仅此差为负不代表遗忘，因为同域分支可能继续提高。

采用 AP 作为排序诊断的主要尺度、MAP 作为预先指定的检索核对，并完整报告原 22 项指标、固定 logit=0 的 F1/Recall/误报与训练集 log loss。保留阈值收益，不按哪项显著就改主尺度或搜索阈值。此处 AP 已获用户确认，不是持续学习的唯一能力标准。

每项按三方向等权汇总；对 valid 各域的 20 个完整群做配对 bootstrap，5,000 次、种子 20260909、95% 分位数区间。重抽群在同一域的所有模型和对比中共享，不把三方向当成三个独立数据集。现有 valid 已被观察，结果属于固定设置下的开发诊断，不能称新的独立确认性检验；单域区间与其余指标作描述，不以多重比较寻找阳性。

预先采用以下解释与投入规则：

1. 同域分支的旧域 AP 增益均值区间下界大于零，且至少两个方向为正，支持“三轮后仍有可利用的学习余地”；结合训练集误差区分拟合改善是否延伸到 valid。它不证明该因素是原无遗忘现象的唯一原因，也不证明六轮已经充分学会。
2. 换域分支在最终固定端点的新域 AP 增益均值区间下界大于零、旧域 AP 变化均值区间上界小于零，并且至少两个相同方向同时表现为新域提高/旧域下降，才支持当前设置存在较一致的学习与保持冲突。另检查 MAP 是否在这些方向同样呈现该矛盾；AP/MAP 不一致则明确限制结论，不自动进入新方法开发。
3. 若同域仍能提高，而换域也提高旧域，则有当前预算下有益迁移的证据。若换域旧域变化区间跨零，只能说未检出明确下降，不能证明保持或共享信息；若新域也未改善，尤其不能把零结果解释为共享规律已证实。训练集改善而 valid 不改善须按同域、同基准和同一指标解释，不能用 train log loss 下降对比 valid AP 不升来单独断言泛化受限。若两者都无改善，仍不能区分优化、表示或输入信息限制，记为证据不足。
4. “没有通过上述条件”不等于统计证明没有遗忘，也不否定所有持续学习。按用户已确认的有限诊断原则，此时停止当前防遗忘分支的直接方法扩展，不追加轮数、换种子或调生成机制继续寻找矛盾；确有实现错误则修复后另行界定有效运行。

即使观察到冲突，也只支持本合成场景，不自动获得真实中文市场的场景依据或论文创新；新方法方案仍须另行确认。本诊断不保证会把两种解释完全分开，允许结论为证据不足。

换域分支的旧域净下降，只能说明该分支新学习伴随旧能力下降。还需单独报告“换域减同域”的旧域差，才能判断相对于同域延续是否额外下降；若同域下降更多，不能把全部净下降归因于换域。MAP 核对使用 AP 已满足新升旧降的相同方向，至少两个方向同样满足 MAP 新升旧降；不另加 MAP 区间显著性门。
