## 对主线的判断

1. **已支持的结论：**完成了一次可审计、真实训练的同源合成文本持续更新比较；本配置 ER 在有限字节下没有收益且主要终点变差。这是应保留的有效负结果。
2. **未支持的结论：**旧关系发生可分离的遗忘、随机重放有效、关系选择器有已证实提升空间、真实中文暗网有效，以及已经形成可发表的方法创新。
3. **当前建议：**停止按原设置直接堆叠选择器或扩大 GPU 训练。主线名称暂不改；如果仍研究“兼顾旧关系保持和新数据学习”，先明确现有输入能否提供可区分这两者的评价对象，以及最小对照为何能回答它，再由用户确认。不得事后把随机世界批换称真实时序／域，也不得为翻转负结果改数据、种子或端点。
4. **仍需区分：**此次 ER 负结果不证明所有记忆方法无效；累计小幅优势不等于完全没有空间。是否值得继续该科研问题，需要进一步明确可检验命题，而非假定换一个缓存选择器就会得到好论文。
