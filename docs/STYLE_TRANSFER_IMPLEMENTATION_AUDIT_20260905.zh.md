## 已证实需要收窄的表述

**字符投影不等于模型可见风格。**本机直接加载冻结 LaBSE 的 `BertTokenizerFast`：`W5 W4`、`W5\nW4`、`W5  W4` 的词元编号均为 `[101,160,15965,160,16006,102]`。中文 `文字，商品。` 与 `文字；商品！` 的投影也同为 `W2.W2.`，简繁体等长文字同样被折叠。换行可能影响分块边界，但不能声称编码器直接区分这些空白、标点种类或简繁风格。字母表相同也不代表中英文分布相同：英文 W 长度多为单词长度，中文常是连续短语长度。是否存在有用迁移只能由实验回答。

受影响主张是“具体排版／标点／语言风格机制已保留并学到”。最小处理是明确可见性限制，保持冻结投影，不临时增加专用符号或重造数据。联合消融只支持剩余顺序与格式信息的整体诊断，不能分解成单种风格因素的因果贡献。

**当前重抽样区间条件于固定三个种子。**`paired_world_intervals` 先对三条种子的逐世界 AP 差值取均值，再只重抽样世界，未重抽样来源种子、目标种子或训练子集。可手算反例：两世界完全相同，三个种子差值为 `+0.5,+0.5,-0.5`，当前函数给出均值与 95% 区间均为 `1/6`，尽管一个种子为负。该实现符合“共同抽取世界”的现有公式，却不能证明对新训练种子稳定。最小处理是按固定三条种子的条件性开发候选解释，并逐种子呈现差值；不把区间冒充算法总体不确定性，也不事后换种子。

**原主要汇总没有完整展现第四臂，本次已补齐。**原来源 `model_metrics.json` 和目标 `model_results.json` 会保存各消融模型指标，但主要汇总只计算正确−通用和正确−置乱，目标消融仅另列描述性 pooled AP。新增 `paired_arm_summary` 展示四臂均值、逐种子 AP 及正确臂相对三个对照的配对差值；中文六档均使用逐世界等权口径。消融保持描述性，不增加成功门、置信区间或训练臂。

## 真实运行尚未验证的部分

本机没有 PyTorch 和 sentence-transformers，不能把专项测试写成 GPU 训练通过。审查开始时，来源 smoke 只检查两遍回传和非零编码器梯度，未与直接反向传播作独立数值比较，也没有执行来源优化器更新；目标 smoke 执行一步更新但未断言参数确实改变。正式训练只有合并梯度范数，不能据此排除仅头在学习。

本次已在原 smoke 中补入直接 BCE 反传与两遍回传的全参数梯度比较、编码器／头实际更新坐标检查，以及来源模型临时保存重载后账号向量精确一致检查；临时检查点由上下文管理器清理。梯度比较容差 `rtol=1e-4, atol=1e-6` 只用于混合精度 smoke 的数值等价诊断，不放宽正式来源分数逐元素精确重放规则。来源与目标正式训练的第一步也记录编码器和头的非零梯度坐标及真实参数位移；零来源轮数没有更新，明确保留空记录。这些检查代码尚未在真实 GPU 执行，不能称已通过。

两遍回传在确定性相同前向函数下符合链式法则：先算损失对账号向量的梯度，再乘编码器的向量雅可比积。实际框架、混合精度、训练／评价模式是否满足前提，以及完整更新是否在目标 GPU 内存中可运行，仍须最小实际运行验证。不能把可能出现的问题写成已经发生的错误。

正式运行前需要一次受影响训练链的最小验证：实际编码器与头的梯度及参数位移、来源两遍回传与直接反传的一致性、明确的评价模式、目标配对随机性、必要的保存重载，以及实际规模的代表批次。沿用现有 smoke 入口补足即可，不新建复杂执行系统。通过前保持“静态已核对，GPU 实现未验证”。

两个启动脚本原本在启动时删除旧 `.building`、失败时删除本轮 `.building`，没有先保存失败阶段和关键证据。本次已改为拒绝未知残留，并在失败时写入运行标识、命令阶段、退出码和“无科研结论”的小型回执；来源、目标每完成一个模型即保存小型指标／训练记录，来源重放记录也及时保存。执行者必须随后立即查明根因、记录暴露的评价边界和关键散列，再删除失败载荷及临时模型；回执不冒充完整失败分析，不允许为可能以后检查而长期保留大型失败目录。两个入口都已在隔离目录模拟失败验证，未操作真实实验根。

来源 `load_encoder` 现显式调用 `eval()`，统一通用评价和来源 smoke 的模式；没有在共享编码函数强制评价模式，中文训练继续按合同启用 dropout。不能据旧代码缺少显式调用，就断言旧模型实际上启用了 dropout；[Transformers 官方文档](https://huggingface.co/docs/transformers/main_classes/model) 说明预训练载入通常默认评价模式，实际子模块仍须在执行环境确认。本次修复使入口明确落实预定条件。

以上三项按 `REPRODUCIBILITY_DEFECT` 处理：分别影响对照评价条件、第四臂诊断的完整汇总和失败科研证据留存。输入可见性与固定种子区间只收窄解释，不改数据、不新增实验门。未发现足以推翻当前四臂设计的已证实 `SCIENTIFIC_BLOCKER`。
