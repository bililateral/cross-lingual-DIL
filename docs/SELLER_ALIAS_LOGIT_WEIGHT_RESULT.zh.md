# 匹配LOGIT0.25的三方法比较结果

2026-10-03，时间为Asia/Shanghai。正式训练、唯一valid评价、完整小结果回传和Linux保存结果独立核验已完成。**LOGIT0.25相对匹配ER0.25通过原23/23项，相对SEQ通过16/23项；旧ER0.25相对SEQ仍为4/23。输出保持机制有明确的匹配增量和局部抗遗忘收益，尚未实现对SEQ的全部新旧域保护。实际结果外审及最终主审尚待完成。**

## 1 结论与正负结果

- 相对ER0.25，O MAP增加0.036125，条件95%区间[0.026500,0.045934]；O Recall@5增加0.048810，N/Z MAP分别增加0.024265/0.025034，首域MAP遗忘减少0.031518，原23项全部通过。这支持已知LOGIT机制在固定历史监督0.25下的增量。
- 相对SEQ，O MAP增加0.031526，区间[0.020665,0.042198]；O Recall@5增加0.029315，区间[0.012500,0.046577]；首域MAP遗忘减少0.032368，区间[−0.048898,−0.015391]；final_all MAP增加0.019001，区间[0.010967,0.026878]。三个顺序的O MAP差值均为正。
- 相对SEQ，N MAP观察值下降0.003219，N Recall@5下降0.002827，Z MAP下降0.006049；这些差值区间跨0，不能称已证明总体退化，但仍未满足预先规定的观察均值不下降。连同N/Z的AP和Brier，共7项失败，不能因区间跨0就改判通过。
- 有效实验、匹配比较成功、相对SEQ局部正向和原整体验收未过可以同时成立。旧ER0.25相对SEQ仍只有4项raw概率参照保护通过，不能省略其负结果，也不能用这次LOGIT改写旧LOGIT1或ER历史。

## 2 固定干预与公平比较

按[冻结合同](SELLER_ALIAS_LOGIT_WEIGHT.zh.md)，仅新增`L_base(current)+0.25 L_base(history)+0.5 mean_378((z_history−target)^2)`，其中`L_base=BCE+query_rank+0.5 known_top5_hard`。MSE独立乘0.5，不是0.125；当前与历史各一次train前向，历史监督和MSE共用历史图，累加后一次裁剪/AdamW。目标为来源阶段末eval模型的无梯度float32原始logit。

三条路径恢复原共同首域完整model/Adam/RNG、LOGIT首域缓存及首映射；SEQ和ER0.25复用原有效结果，未重训它们。六群Algorithm R和1MiB全部历史附属状态预算不变，当前/历史日程及dropout对原ER配对。阶段二结束新入群目标来自本路径阶段二eval模型，原存活目标不刷新、淘汰群不恢复，三个顺序的目标来源均核对通过。

这检验了学生train／目标eval条件下的完整输出保持配置，包含dropout方差作用，不能将其解释为纯确定性函数保持或单一因果机制。它是FDR/DER类已知思想的受控适配，不构成方法创新证据。

原主比较仍为LOGIT0.25−ER0.25，另完整报告ER0.25−SEQ与LOGIT0.25−SEQ。同期ER0.1独立合同的入选不把本轮参照偷偷换为0.1，也不授权新LOGIT系数、种子或再次训练。
