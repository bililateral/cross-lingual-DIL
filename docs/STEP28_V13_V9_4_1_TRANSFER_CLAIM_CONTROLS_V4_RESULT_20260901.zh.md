# Step28-v13 V9.4.1 迁移主张对照 V4 开发结果

## 结论

第一阶段开发对照正常完成，状态为 `POSTHOC_DEVELOPMENT_CONTROL_COMPLETE_AUDIT_TRUTH_SEALED`。在相同训练行、33项身份历史、无标签变换、二范数惩罚 `0.01` 和未惩罚截距下，加入冻结英文 M0 没有提高主要指标，反而使开发集平均精确率下降 `0.064562`。9,999次按世界重抽样的百分之九十五区间为 `[-0.068876,-0.060245]`，完全低于零，预设开发假设门未通过。

该结果否定“当前 M2 已证明英文马甲识别能力正向迁移到中文合成任务”的表述。它不否定身份历史本身的价值，也不是审核甲结论。

## 科研解释与下一步

现有强结果来自中文合成身份历史本身，而不是已被证明的英文来源能力。当前主线应停止把 M2 描述为已经成功的跨语言能力迁移。下一步按照已冻结 V4 合同实现完整中文文本分块的 LaBSE 直接微调，并在相同训练世界预算下与 I0、T1、M3-joint 比较。旧的审核甲真值评价 V1 暂不执行；新增模型在真值封存时完成盲预测后，才能决定新的审核评价边界。
