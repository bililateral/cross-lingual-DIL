# Step28-v13 v1.13 V9.4.1 完整英文兼容性重放 v2 结果

日期：2026-08-30
状态：`PASSED_FULL_ENGLISH_LABSE_EXACT_COMPATIBILITY_REPLAY`

## 1. 运行目的

本轮只验证当前 Linux 图形处理器环境能否精确重放冻结 Step7 的完整 LaBSE
编码和聚合链。它不训练模型、不选择阈值、不计算监督性能，也不打开训练、开发
或审核甲乙真值。

旧 v1 把原 41,808 块缩为 49 块后要求十二位分数不变，改变了长度排序、批次和
补齐上下文，估计目标无效。v2 不再使用小夹具，而是重建完整工作负载。

## 2. 正式结果

Linux 唯一运行完整处理 33,434 个去重英文文本、41,808 个共享文本块和 733 个
无标签卖家对。4,226 个文本需要分块；四个冻结分词器下均无超预算块。

- LaBSE 矩阵形状：`41808×768`，连续小端单精度；
- 矩阵原始字节 SHA-256：
  `635b932cb6e50e9d2e917f627ecb89222f20a6f62fc31c0bfed13bf158fae978`；
- 733 对完整聚合分数 SHA-256：
  `9597497613493d04f4cc2b9dbb663341e6756677fa60c89e199fdae52937d282`；
- 两者均与冻结 Step7 记录逐字节相同；
- 未使用数值容差、夹具重选或事后舍入修复。

成功清单为 8,498 字节，文件 SHA-256
`12df46e3df520f6371dc596cd7b64a0b2b0b58a4ae55f3e99d920e75bed88a8d`，
规范自哈希
`49370a4732b2cbfba9ff36d04780f053361ef9d5783a7c5976fd2149e94c80e1`。
观察分数文件为 141,007 字节，733 个配对标识全部唯一。描述字段有 7 行结构性
空值，与冻结原文件逐字节一致；其余非空数值均有限，文件中没有标签、真值、
控制者、成员关系或检索相关性字段。

## 3. 运行和隔离边界

精确环境为 Python 3.10.19、NumPy 2.2.6、PyTorch 2.9.1+cu130、CUDA 13.0、
cuDNN 9.13、Transformers 4.46.3、sentence-transformers 5.6.0 和
NVIDIA GeForce RTX 5090；张量浮点 32 位矩阵乘法与 cuDNN 浮点 32 位快速模式
关闭，确定性算法开启。

清单明确记录：监督标签、identity33、控制者、成员关系、检索真值和审核真值
读取均为假；模型参数更新、训练和阈值选择均为假。同步回 Windows 后，正式
`validate-output` 只读复核通过；兼容性及第三版回归分区合同合计 17／17 通过。

## 4. 科研结论与下一步

本结果关闭了 LaBSE 完整英文数值兼容性前置门，并证明旧 v1 漂移来自无效的缩小
工作负载比较，而不是当前 Linux 环境无法复放冻结 Step7。它不证明 LaBSE 性能、
M0 优越性、中文迁移效果或真实中文外部泛化。

V9.4.1 正式中文数据仍保持 `training_qualified=true`；本结果发布后
`m0_m1_m2_m3_training_authorized` 仍为 `false`，审核甲乙真值读取仍为零。
下一步只能另起后继版本，冻结并实现 M0、五个 M1、M2、M3-base、M3-joint
训练和盲评合同，经回归、提交及一次性授权后再运行。
