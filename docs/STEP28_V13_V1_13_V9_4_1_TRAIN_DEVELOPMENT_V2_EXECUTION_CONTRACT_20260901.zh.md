# Step28-v13 V9.4.1 训练与开发评估 V2 执行合同

## 科研目的

本阶段只完成正式中文合成数据上的训练和开发集评估，为后续盲审计冻结模型与阈值。它比较固定的英文基底模型、五个无身份信息对照、身份迁移模块以及两个直接监督模型，不产生审计集结论。

正式比较对象为：

- C0：只使用十八项传统特征的冻结英文对照；
- M0：使用十八项传统特征与 LaBSE（语言无关句向量模型）特征的冻结英文基底；
- M1-r01 至 M1-r05：五个训练期身份特征错配对照；
- M2：在 M0 概率上学习三十三项中文身份关系特征的残差迁移模块；
- M3-base：直接使用二十四项公开基础特征训练；
- M3-joint：直接使用二十四项基础特征和三十三项身份特征联合训练。

## 数据边界

公开输入固定为 V9.4.1 公共投影，训练集和开发集各 500 个世界、189,000 对；每个世界 28 个卖家、378 对，其中 20 对为同一控制者，358 对为不同控制者。

本阶段只允许各读取一次：

1. 训练集配对标签；
2. 开发集配对标签；
3. 开发集检索真值。

训练集检索真值、审计 A 和审计 B 的标签及检索真值读取次数必须为零。不得生成审计预测，不得查看审计结果。标签必须逐行与公开的世界编号和规范配对编号一致；开发集配对标签必须与检索真值完全一致。

## 训练与选择

M1 和 M2 共用九个二范数正则候选值以及按世界隔离的五折交叉验证；变换参数只由相应训练折的正确身份特征估计。M1 仅在拟合时使用世界内固定错配身份特征，验证和开发预测均使用正确可见特征。M3-base 与 M3-joint 共用冻结的八组 LightGBM（轻量梯度提升树）候选，并按训练集折外平均精确率选择。

C0 和 M0 使用英文阶段已冻结阈值；其余模型在开发集按“世界等权 F1 分数最大、并列时取更高阈值”选择阈值。阈值搜索实现为一次排序和累计计数，与原穷举规则完全等价，不改变实验定义。

## 输出与判定

正式输出目录为 `reports/step28_model_experiment/v9_4_1_train_development_v2_20260901/`，保存最终模型、训练集折外预测、开发集预测、开发阈值、完整评估和文件哈希清单。两份树模型必须以原始 UTF-8 字节保存，发布前从磁盘重新载入，并要求重放的开发概率与训练进程内概率逐字节一致。

每个模型必须分别报告平均精确率、梯形精确率—召回率曲线下面积、受试者工作特征曲线下面积、概率误差、对数损失、固定误报率召回、精确率、召回率、F1 分数、特异度、平衡准确率、马修斯相关系数，以及平均倒数排名、平均准确率均值、前 1/3/5/10 召回率和归一化折损累计增益。

开发集只检验五个 M1 对照相对 M0 的等价性。通过仅允许进入后续盲审计预测；失败是有效的负结果，必须如实发布并继续封存审计真值。机械故障不构成科研结果，应删除未完成目录，记录根因后用新版本修复。
