# Step28-v13 v1.13 V9.4.1 公开投影 V1 实现就绪记录

日期：2026-08-31

## 科研目的与边界

本阶段只实现正式中文四拆分的单次、无标签公开投影链，为后续 M0、五个 M1、M2、M3-base 和 M3-joint 提供冻结模型输入。它没有执行正式投影，没有读取训练、开发或审核监督，没有训练模型，也没有生成审核甲、审核乙预测。

正式数据根继续保持 `training_qualified=true`；本阶段政策中的公开投影、训练、审核预测和审核真值授权全部为假。审核甲乙真值读取仍为零。

## 冻结实现

实现把公开投影拆成三个物理边界：

1. Windows 中央处理器准备端验证正式公开根，冻结行键、legacy18 和不透明文本工作负载；四拆分拆成四个不带拆分名称的分片，不携带标签、控制者、检索相关性或身份真值。
2. Linux 图形处理器隔离工作区只接收最小图形处理器政策、四个冻结分词器/模型载荷和不透明分片。四个分词器共同重建相同文本块，只由 LaBSE 编码并返回六项卖家对语义分数。运行前后都验证精确文件全集；缓存、额外文件和载荷漂移均失败关闭。
3. Windows 中央处理器重新绑定正式来源，组合 legacy18 与六项 LaBSE 分数形成 base24，调用冻结 M0/C0；身份侧由独立进程冻结 identity33 和训练拆分五个 M1 错配映射，最终协议要求基础侧与身份侧行键逐字一致后才可组合。

图形处理器返回必须同时证明：共享分块的分词标识摘要与 SentenceTransformer 实际预处理摘要相同、长度逐块相同、均不超过冻结上限，并完成相同输入的确定性重放。即使攻击者重新计算分片和根自摘要，缺少共享摘要、两摘要不等或重放标志为假仍会被中央处理器拒绝。
