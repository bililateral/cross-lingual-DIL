# Step28-v13 V9.4.1 审核甲盲预测 V1 执行合同

## 目标与边界

本阶段只使用已经冻结的 V2 模型、开发集阈值和审核甲公开投影，生成十个模型在审核甲 189,000 个卖家对上的概率。程序不得挂载或读取审核甲标签、检索相关性、控制者成员关系或任何审核乙输入；不计算指标，不更新模型和阈值，也不形成审核结论。

审核甲盲预测通过后，只能说明预测文件已经在真值封存状态下冻结。是否允许打开审核甲真值并计算平均精确率、梯形精确率—召回率曲线面积、平均倒数排名、平均准确率均值及其余冻结指标，必须作为下一阶段单独决定。

## 冻结输入

- 公开投影清单规范自哈希：`1614e70bd84b76c292098d41f8b8aa0a51666c26f73631b943bf42576b9bba28`；
- V2 训练清单规范自哈希：`7cab52a64081bc3871081a0f8a5bfd308813c2d80b9d433a7cbe277e9cb35364`；
- 审核甲行数：500 个世界 × 378 对，共 189,000 对；
- 模型：C0、M0、五个 M1、M2、M3-base、M3-joint；
- 阈值：直接复用 V2 已冻结的十个开发阈值。

政策不包含任何 `private_custody/` 路径。审核甲、审核乙标签或检索真值读取预算均为零，审核乙预测权限为假。

## 执行方法

正式运行首先从 V2 目录重载六个残差逻辑回归和两份 LightGBM（轻量梯度提升树）模型，在开发公开投影上重新生成十组概率，并要求与 V2 已保存开发预测逐字节一致。该步骤不读取开发标签，只验证模型加载和推理接线。

开发重放通过后，程序加载审核甲的 24 项基础矩阵、M0／C0 概率和正确的 33 项身份历史。五个 M1 与 M2 在审核推理时都使用正确身份历史；错配只发生在 M1 训练阶段。输出只保存十组双精度概率、冻结阈值、行键引用和完整性清单，不保存或推断标签。
