## 2. 固定数学与实际更新

模型h=ReLU(W1u+b1)∈R128，原评分s=aᵀh+b0。w=[a;b0]来自实际末层参数的保留图拼接，不另造Parameter、不detach、不重复加入Adam。原FP32评分用于所有B、校准和推理。

函数分支规范坐标z=[FP32(FP16(h));1]；参考、统计、函数教师和live表示全部使用同一定义。前向真实FP16舍入且检查有限值；反向明确为FP32恒等直通估计，不称舍入真导数，不将梯度再次转FP16。历史参考存小端FP16，H/b/c、Gram、p、solve及二次式为FP64。

对每群m=378边，G为I/m加逐查询均匀平均的全部正负边差外积。28查询各自先平均，不以全局1016比较平均替代。G只用于数学定义/独立参考，生产不持久保存。tr(G)=3。

阶段末该群规范Z及教师w_t形成H_g=ZGZᵀ、b_g=H_gw_t、c_g=w_tᵀH_gw_t。目标为旧函数分数残差的边均方＋查询正负差残差均方；不是BCE/rank/hard的精确摘要，也不再是±1／间隔2的硬标签目标。

训练抽到的历史群参考X、当前规范Y：

\[
K=XX^T/378+0.001I,\quad p=Y^Tw,\quad v=K^{-1}(Xp/378+0.001w),\qquad
D=\frac{v^THv-2b^Tv+c}{3N}.
\]

唯一总项：

\[
J=B_{train}(C)+0.1B_{det}(H_{buf})+0.5D.
\]

B保持原BCE＋query-rank＋0.5 top5-hard。没有额外缓存logit MSE、单独旧R、全教师或额外持久统计。除3是误差几何定标，不是与baseline梯度等强或最优系数保证。

一次当前B反传并释放图；一次历史前向共用h计算原FP32 B和规范D，联合反传；全参数统一clip=1一次、AdamW一次。当前保留baseline训练Dropout。历史临时归零实际生效概率、保持train和非重入checkpoint，范围包含forward、backward及全部重算，之后恢复；固化/参考同规范模式但no_grad。保留当前/历史抽取和种子流；记录历史确定性与LOGIT随机历史模式的差异。

历史H/b/c、X固定，Y和w可微。以a=2(Hv−b)/(3N)、t=K^−T a、g=Xᵀt/378表示，独立连续坐标梯度应为dD/dY=w gᵀ、dD/dw=Yg+.001t；再按指定直通传回h。不得漏掉epsilon w路径。

## 3. 固化、保存与数值边界

首域48fit各一次建立累计N=48和Algorithm R参考。第二阶段末：用更新缓存前的旧6群联合估计T；H←THTᵀ、b←Tb、c不变；当前48fit各一次加入各自H_g/b_g/c_g，N=96；再Algorithm R、刷新幸存规范参考。不得重置旧b/c为最新w，不额外保存按域教师。第三阶段无后继时不固化下一份记忆。

新格式与原32维容器区分。6份FP16参考585144字节，H/b/c/N共134176字节，数值总719320；其余原文、标签、RNG、索引、校准映射、元数据均进入完整1048576字节门。机械估算约0.90—0.93MB不是实测通过。超限停止，不减群、换成员、藏入model buffer或静默换精度。新容器实际写读、完整模型/Adam/RNG保存恢复均补受影响证据；不复制无变化历史测试。

数值策略在新执行前固定：FP16 overflow、非有限值或不可解即失败；FP64 solve归一残差≤1e−10，归一分母为||K||F||v||2+||rhs||2+机器epsilon。手写显式平方和与统计展开差，以及新域初建负值，只允许≤1e−10×(1+|vᵀHv|+2|bᵀv|+|c|)/(3N)的FP64抵消误差，保留原值而不clamp。这只是数值正确性门，不是性能线；不能依据正式结果调整ridge、容忍或目标。原生同参数规范参考/live必须字节一致；模式/RNG不一致应查明停止，不直接放宽为统计误差。
