## 1. 科研目的与权限

本合同承接 v9 训练序号 0—283 内存因果回放。该回放证明 v8 序号 283 的精确文档容量缺陷已被结构性消除，但 284 个世界均由候选 0 一次接受、六类碰撞均为零，不能据此认定数据质量合格。逐商品可见代码及其派生表面可能成为 M0、M3 或文本探针可利用的捷径，必须在看到 1,004 世界设计数据以前冻结审计方法。

本合同只授权实现政策、审计器和测试，并提交独立运行前审查。它不授权 1,004 世界重建、质量审计运行、正式 500×4 数据、审核真值解封或 M0／M1／M2／M3 训练。原科学实验合同、质量审计 C 修订件和 v8 设计规模修订件未被本文件替换的条款继续生效。

## 2. 固定数据单位

未来一次设计级输入仍固定为训练 500 世界、开发 500 世界、审核甲 2 世界、审核乙 2 世界。训练和开发每世界必须有 28 个卖家、378 个无序卖家对和 20 个正例。所有模型挂载视图始终保留同一 378 对键空间、世界、商品、卖家、卖家对顺序和五份错配映射；任何视图不得删行、换候选、换代码、换自然表达或重新生成世界。split 与 UID 只允许路由、连接、分组、闭合和规范排序，禁止成为数值、哈希、字符或顺序特征。

审核甲乙只做无标签结构、字节、泄漏和调用链审计，不进入监督探针。候选序号分布、六类碰撞计数和代码登记数量只作完整性回执，不是质量通过门，也不得用于选择世界。

未来 v9 设计根不能只保存完整视图。每个候选不可逆接受后、调用 `_build_private_truth` 以前，标签无关视图器必须在内存中一次性生成并冻结：完整、字面折叠、通道中和三份逐商品模型输入，三份由各自商品重算的卖家模型画像，以及彼此物理隔离的三份私有白名单输入：

- `public_code_probe_input` 顶层只含世界／卖家 join key、自有代码集合、商品与五个卖家挂载字段的代码出现投影，以及六项完整减中和数值画像差；每条出现投影严格只含 `field`、`code`、`is_own`。商品 UID、跨度、文本摘要、语法树节点、override、clone 原因、机制、模板角色或代码派生原因一律不得进入该输入；用于验证遮蔽正确性的跨度、文本摘要和语法树节点只可留在 `channel_structure_audit`；
- `text_probe_eligibility_input` 每世界恰含完整 378 个 `canonical_pair_uid`、`world_uid` 和事前资格布尔值，只由六个冻结 override 的 `canonical_pair_uid` 生成，恰有 372 个真、6 个假；不含标签、负例标记或 override 原因；
- `channel_structure_audit` 才可含候选／基础模板节点映射、载体节点、修饰语／英语标签来源、foreign 合法原因和登记 clone 方向，只作零容忍结构检查，禁止进入任何监督特征。

两者均不得包含控制者、positive targets、negative flags、pair labels、qrels、机制分配或质量结果。标签无关视图器只能接收明确白名单字段投影，禁止把完整 `world_generation_audit` 或完整私有 world 对象交给它再依靠“未读取”计数自证隔离。

六份模型输入和三份私有输入都必须进入拆分清单与根清单，记录行数、大小和 SHA-256。训练／开发的三份私有输入分别只允许对应白名单准备器读取；审核甲乙另提供不含 truth 的结构投影供字节与结构检查，controller membership、pair labels、qrels、positive targets 和 negative flags 文件的 open 调用数、read 调用数、物化行数必须作为三个独立字段分别为 0。缺少任何一份物化视图或白名单输入时，不得在质量阶段通过重建世界、猜测模板或从完整字符串反推来补救，设计根直接不具备审计资格。

## 3. 三种冻结可见文本视图

三个视图必须由同一已接受世界一次性确定，先于任何标签读取生成并冻结字节、行序和摘要。

### 3.1 `surface_full`

生产解析、脱敏后实际提供给模型的标题和描述，不做任何修改。

### 3.2 `surface_code_masked`

只把登记语法树节点和登记 clone 复制跨度确认的每一次完整 `Q[A-P]{10}` 代码替换为固定十一字符 `QXXXXXXXXXX`。替换必须覆盖商品自己的代码和精确标题克隆带入的登记外来代码，保持字段、位置、周围字符、空值模式和长度不变。不得用 `str.replace` 或只靠正则猜测；登记节点以外出现相同字符串或代码样式直接失败。替换后必须重新解析，并证明身份槽 UID、字段、顺序、raw surface、规范值及相对前后语法树节点的边界关系不变。

该视图有意保留标题修饰语、英语标签和原代码载体句式，但把所有代码的字符身份及相等／不等关系折叠为同一占位符；机器名称固定为 `literal_code_identity_collapsed_view`，不得表述为只删字符而保留代码等值拓扑。

### 3.3 `surface_code_neutralized`

从同一候选的登记语法树重放，不允许对最终字符串作自由改写：

1. 每个已接受候选的标题／描述模板都必须在机器政策登记 `source_template_id`、`neutral_template_id`、`is_code_carrier`、`carrier_ast_node_id`、`removed_literal_tokens`、`retained_non_code_placeholders` 和 `neutral_carrier_ast`；每个商品另登记 `derived_title_modifier_node_id`、`conditional_english_tag_visibility_node_id`、`english_tag_value_node_id` 及 clone 后实际可见标题的来源商品；实际代码载体模板通过冻结 `_capacity_index_map` 的严格逆映射恢复到原 0—7 基础模板，非载体字段不得新增代码或占位符；原本无代码的基础模板由此删除 v9 新增容量子句，原本含代码的基础模板保留其原有载体词；映射缺失、不唯一或不覆盖恰好八个基础模板时失败；
2. 为满足冻结生产链对同世界商品代码唯一及高语义端点代码不等的既有验证，中和器不得修改共享生产链。它按商品 UID 的 UTF-8 升序取得从零连续的临时序号，把序号写成八位 A—P 十六进制字符，并固定追加 `BA`，形成 `Q + 八位序号 + BA` 的合法、不持久化中和代码族；序号零固定为 `QAAAAAAAABA`。全部代码的倒数第二位均固定选择标题修饰语“常规款”，最后一位均固定打开英语标签门。`effective_style.english_tag` 非空时保留其原文本并始终显示，为空时仍为空；临时代码序号只用于通过生产闭包，生产链完成后全部折叠为同一占位符，禁止进入模型或特征；不得读取实际代码值决定中和代码或任何中和字段；
3. 生产解析、脱敏和身份／噪声保护链完成后，只把中和代码替换为等长 `QXXXXXXXXXX`；原基础模板不含代码时不得另加占位符；
4. 规范语法树载体字面使用模板登记的简体字节；可见表面继续经过冻结简繁风格转换，因此繁体表面可以是“編號”，不得硬要求所有最终文本出现简体“编号”；
5. 该节点映射和固定中和代码族共同定义全部模板的中和规则，不建立可按结果修改的自由文本模板，不允许运行时猜测或自由改写；
6. 原字段空／非空模式、joint-empty 的既定投影方向、商品归属、产品、属性、服务、交付、风格、噪声、上下文保护和身份子句均保持不变；
7. 先完成两端中和原生渲染，再按冻结端点和方向复制来源中和标题；精确标题克隆在中和视图中仍须逐字相同。目标描述严格服从其原 0—7 基础描述模板：原模板含代码载体时保留等长占位代码，原模板不含代码时不因 clone 身份新增占位符；不得为 clone 目标建立运行时例外。

中和视图只消除代码值及其派生表面，不消除任务所需身份文本，不改变缺失模式，也不重新运行候选选择。

三个视图必须通过逐商品字段键集合、空值模式、身份区域、克隆端点和卖家归属的相等审计。遮蔽或中和产生的文本不得回写正式数据。

每个视图都必须从各自的商品标题／描述重新运行冻结生产画像，得到 M0／M3 实际挂载的卖家五个文本字段、商品数、标题／描述长度、数字／标点比例、重复标题／描述比例和其他允许数值字段；不得遮蔽商品表却复用完整视图卖家画像。中和视图必须先把全部临时唯一代码折叠为 `QXXXXXXXXXX`，再从折叠后的逐商品字节重建 profile-safe items 和完整卖家画像；禁止先用临时唯一代码计算画像再只替换五个画像文本字段。字段顺序、清洗、280 字截断、top-k、拼接和空值规则与生产链逐字节一致。三个视图分别保存完整模型挂载字节摘要。

另建 `non_code_projection_commitment`：只能删除机器政策逐模板登记的代码语法树节点、`removed_literal_tokens`、`derived_title_modifier_node_id` 和 `conditional_english_tag_visibility_node_id`，禁止自由字符串表或正则扩大删除范围。标题修饰语和英语标签可见性是允许变化的两个代码派生节点；`english_tag_value_node_id` 的原始值及其摘要必须保持不变。clone 目标按登记来源商品比较最终标题。删除上述允许变化节点后，所有其他文字节点、非代码占位槽及其顺序必须相同；商品、属性、服务、交付、噪声、上下文保护和身份槽逐项相等。身份／噪声比较固定使用槽 UID、字段、顺序、raw surface、规范值、重新解析跨度及相对前后语法树节点的边界关系，不要求载体长度变化后的绝对 start/end 偏移相等。

“对任意合法代码置换不变”不通过阶乘穷举证明。中和器验证代码格式和登记关系后，允许读取集合必须排除原代码字符；中和模板、修饰语、英语标签门及其余分支只能读取固定中和代码族规则和非代码风格。运行时隔离使用 `NeutralItemProjection[NeutralItemMetadata]` 能力对象，其逐商品字段严格为世界、卖家、商品、时间桶和类别，不含标题、描述或代码；入口先用字段级 read guard 统计每个允许字段的实际值读取次数，禁止字段读取会立即失败，receipt 中的读取次数必须来自该运行时审计而非固定常数。读触发器反例必须证明不读取原标题／描述值，中和器函数签名不得再接收完整商品对象。测试另穷举倒数第二／最后两个派生符号的 `16×16` 状态，并把真实单世界的中和商品与重算后卖家画像模型挂载字节接入穷举断言；同时覆盖 clone 来源／目标、title-only、description-only 和双字段的交换、循环置换反例。

## 4. 文本捷径探针

质量审计 C 的七个视图 `fs_full`、`fs_title`、`fs_template_surface`、`p_full`、`p_topic`、`p_template_surface`、`u_joint_full` 分别在三种文本视图上重放。各视图宽度依次固定为 33、14、30、75、14、56、124；三种表面共 `3×(33+14+30+75+14+56+124)=1,038` 个事前登记单特征。每个视图仍使用冻结的二范数逻辑回归和深度 2 直方图梯度提升树集成，共 42 个模型。训练集拟合、开发集过门；不得自动发现特征、调参、删模型或按结果选择文本视图。

无标签视图器必须在候选接受后、私有标签构造前物化 `private/text_probe_eligibility_input.jsonl`：仅从六个冻结 override 的 `canonical_pair_uid` 对完整 378 对打资格布尔值，不从三种模型挂载视图删除任何行。三种表面和七类文本特征共用该文件中的同一 372 行资格空间，并单独冻结 378 行完整键空间与 372 行资格空间的 row-order SHA-256。公共／私有编码矩阵继续使用完整 378 行。质量阶段不得从 `channel_structure_audit` 推导或另行生成第二份 mask。

监督验证器打开训练／开发标签后必须证明每世界 mask 恰排除 6 个不同 pair、六对全部为负例、未删除正例且仍有 20 个正例；否则失败。全部探针行权重严格为 float64 的 `1.0`：StandardScaler、两类模型、受试者工作特征曲线下面积、平均精确率和重抽样均不接收非平凡 sample weight。世界在重抽样中出现 `k` 次时，其全部行按原顺序重复 `k` 次，等价于整数权重 `k`。因此文本和编码平均精确率基线分别固定为 `20/372` 与 `20/378`。完整文本不能由遮蔽或中和结果救活：任一视图失败即整套设计数据失败。

## 5. 编码专用公共探针

公共探针只能读取登记代码字符串、可见字段、own 归属、五个已物化画像字段中的代码出现投影、六项完整减中和数值画像差，以及只作路由／连接／排序的世界／卖家 join key。跨度、文本摘要、语法树节点和商品 UID 不进入该白名单输入。world／seller／item／pair UID 和 split 禁止数值化、哈希化、字符化或进入列／行序分数；商品语义和身份文本本身不得成为编码专用特征。登记 clone 原因、override 种类、foreign 合法原因、某修饰语或英语标签的生成器来源只能进入私有零容忍结构审计，禁止进入公共监督矩阵。

每个无序卖家对固定生成 2,992 项交换对称特征：

1. 商品行可解释关系摘要 40 项：自有代码数、可见代码出现数、标题出现数、描述出现数、外来不同代码数五个卖家量的绝对差与和 10 项；两端自有／全部可见代码集合的交集数与 Jaccard 4 项；全部跨代码组合的逐位字符相同比例、共同前缀比例和共同后缀比例各取最大值与均值 6 项；十个位置的十六分类频率总变差与内积 20 项。
2. 自有代码绝对字符组成 320 项：对十个位置和 A—P 十六个符号，分别计算两端自有代码归一化频率的绝对差与和，即 `10×16×2`。
3. 全部模型可见代码绝对字符组成 2,560 项：先对商品标题、商品描述和五个实际卖家挂载字段合并后的全部可见代码按出现次数计算 `10×16×2=320` 项；再对上述七个字段分别计算 `7×10×16×2=2,240` 项。own 和 foreign 一视同仁，字段为空时该字段频率向量固定全零。该组必须通过“own 代码、数量、集合关系和相对相似度完全相同，仅 foreign-code 字符不同”的碰撞反例。
4. 五个实际卖家文本挂载字段的代码统计 60 项：每字段、每卖家的代码出现数、distinct 数、own 数、foreign 数分别取绝对差与和，共 `5×4×2=40`；每字段两端可见代码集合的交集数与 Jaccard 共 `5×2=10`；每字段自有代码存活率取绝对差与和，共 `5×2=10`。画像字段必须使用各自真实 top-k、280 字截断、排序和拼接结果，不能从商品行推测。
5. 代码造成的允许数值画像变化 12 项：同一卖家完整视图减中和视图的标题长度中位数、描述长度中位数、数字比例、标点比例、重复标题比例、重复描述比例六项，再对两个卖家的六项变化取绝对差与和。商品数和最大类别占比理论上不受代码通道影响，必须逐字节相等而不进入该矩阵。

总数为 `40+320+2,560+60+12=2,992`。空集合 Jaccard 固定为零；跨代码组合为空直接失败，因为每个卖家必须至少拥有一个代码。全部名称、顺序、float64 数据类型和公式必须写入机器政策并由正反例钉住。

2,992 项输入分别进入冻结二范数逻辑回归和深度 2 直方图梯度提升树集成。两模型只在训练集拟合，在开发集过门。登记 clone 方向／来源、代码载体节点、修饰语／英语标签来源和外来代码合法性另存私有结构回执，只做零容忍闭合，不得加入这 2,992 列。

## 6. 私有解码槽位探针

该探针只能在钉住的特权验证器内部使用代码子键逆变换；代码子键、解码值和逐行槽位不得出现在公共文件、标准输出、异常消息或质量回执。

每个自有代码必须恢复同一世界全局序号、该卖家的唯一创建槽位及连续无缺口的商品创建槽位。一个卖家内世界或卖家槽位不一致、商品槽重复或有缺口时直接失败。

每个无序卖家对固定生成：

- 28 选 2 的无序卖家创建槽组合独热向量，共 378 项；
- 两个卖家槽位的最小值、最大值、绝对差与和，共 4 项；
- 两端商品槽位占用数的绝对差与和，共 2 项；
- 两端八位商品槽位占用掩码的交集数、并集数、Jaccard 相似度和汉明距离，共 4 项。

总计 388 项，进入同一冻结二范数逻辑回归和深度 2 直方图梯度提升树集成。世界全局序号本身不得作为模型特征。特权验证器只输出特征模式摘要、模型指标、硬门判定和规范哈希，不输出矩阵或标签。

## 7. 统一统计硬门

编码公共两模型与私有槽位两模型组成一个四模型家族，使用全部 378 对和 20 个正例，平均精确率基线为 `20/378`。三种文本视图的 42 模型继续使用 `20/372`。所有门都是事前效应量门，不宣称已校准家族第一类错误率。

全部探针共用以下冻结拟合程序。逻辑回归先仅用训练集拟合 `StandardScaler`，再使用 `penalty=l2`、`C=1.0`、`solver=lbfgs`、`fit_intercept=true`、`max_iter=10000`、`tol=1e-10`、`class_weight=null`、`random_state=793820367`；迭代数达到上限即失败。深度 2 直方图梯度提升树集成固定为 `HistGradientBoostingClassifier`，使用 `loss=log_loss`、`learning_rate=0.03`、`max_iter=200`、`max_depth=2`、`max_leaf_nodes=31`、`min_samples_leaf=20`、`l2_regularization=1.0`、`max_bins=255`、`early_stopping=false`、`class_weight=null`、`random_state=793820367`，其余参数逐字段写入机器政策并与冻结实现测试相等。逻辑回归读取训练标准化值，树集成读取原值；两个模型都不得重采样、加类别权重、调参或用开发集拟合。

运行语义固定为 Python 3.10.11、NumPy 2.2.6、scikit-learn 1.7.2、float64、单线程。正例标签严格为整数 `1`，负例为整数 `0`，分数固定取 `predict_proba[:,1]`；非有限输入、系数、概率或指标立即失败。`StandardScaler`、`roc_auc_score` 和 `average_precision_score` 的并列分数、权重与排序语义以该 scikit-learn 版本为准且全部不传 `sample_weight`；分位数固定用 NumPy 2.2.6 的 `quantile(method="linear")`。环境或版本不符不得近似替代。

以下门对文本 42 模型家族和编码／槽位四模型家族分别计算，任一失败即设计数据失败：

- 全部冻结单特征最大对称受试者工作特征曲线下面积不超过 `0.52`；
- 模型家族最大对称受试者工作特征曲线下面积不超过 `0.53`；
- 模型家族最大平均精确率相对相应基线的提升不超过 `0.01`；
- 9,999 次按开发世界有放回重抽样的家族最大对称曲线下面积 95% 上界不超过 `0.53`；
- 同一批重抽样的家族最大平均精确率提升 95% 上界不超过 `0.015`。

重抽样固定使用 `Generator(PCG64(281320260810)).integers(0,500,size=(9999,500),dtype=int64,endpoint=False)` 一次生成的索引矩阵。世界轴严格按未来清单的开发拆分 world ordinal 0—499 升序，重复抽中一个世界就按原 pair 顺序重复该世界全部行；任何 UID、物理文件顺序或哈希排序都不能替代 world ordinal。该矩阵按 little-endian `<i8`、C 顺序的 39,996,000 原始字节 SHA-256 固定为 `111b1338cc607c6bd78bad88efe47606ffa2230e9cc764eec940e84f86e56661`。流式批量为 16，每次重抽样先在对应完整家族内取最大值，不重新拟合；保存每个模型按冻结开发行序排列的 `<f8` 概率向量 SHA-256，以及 9,999 个家族最大值向量的 `<f8` SHA-256。对称曲线下面积为 `max(AUC,1-AUC)`；任何非有限值或预测长度／顺序不一致立即失败。单特征门在文本家族覆盖精确 1,038 列，在编码／槽位家族覆盖精确 `2,992+388=3,380` 列，两家族不得合并后取最大值。

数值权威逐字段固定：`0.52`、`0.53`、`0.01`、`0.015`、二范数逻辑回归与两类基线来自科学实验合同第 4 节第 4—5 项和质量审计 C 修订件第 3 节；七视图及 33／14／30／75／14／56／124 列来自质量审计 C 修订件第 2 节；训练／开发各 500 世界、9,999 次和质量门来自 v8 设计规模修订件第 2、4 节，PCG64、批量 16、矩阵形状与线性分位数来自其第 5 节第 2 项。机器政策必须逐字段重复这些值和来源路径、文件哈希、章节，不得只写一个总引用。

以下结构门为零容忍：遮蔽和中和视图中 `Q[A-P]{10}` 命中为 0；未登记代码样式、旧世界代码泄漏和非登记 clone 外来代码均为 0；中和视图对同世界合法代码任意置换的模型挂载字节差异为 0；三个视图的世界／卖家／商品／卖家对键集合差异为 0；审核甲乙监督读取行数为 0；生成器、候选器和视图器读取质量结果次数为 0。

训练与开发分别要求十个字符位置的 A—P 边际频率与 `1/16` 的最大绝对偏差不超过 `0.01`。由模型挂载字节直接计算的代码交集／Jaccard／字符相似度、全部 own／foreign 字符组成、foreign-code 数和标题／描述可见次数已包含在 2,992 项公共单特征门中；clone 方向／来源、容量模板角色、代码派生修饰语来源和英语标签来源只进入私有结构零容忍闭合，不得成为监督列。登记代码、语法树期望次数与实际可见次数必须精确相等。既有私有字面、跨拆分隔离、真实文本防复制、生产重放、重复率和模型画像闭合门继续执行，不得因代码遮蔽而省略。

## 9. M0／M3 预登记敏感性

若设计质量通过且未来另行获得训练授权，M0、五个 M1、M2、M3-base 和 M3-joint 必须在完整、字面遮蔽和通道中和三种视图上使用相同卖家对、拆分、权重、折分和随机种子成对重放。M0 始终使用冻结英文流水线，不重新拟合；M3 在每个视图上只用训练集按同一冻结程序拟合。另需把完整视图训练的 M3 原样应用到遮蔽和中和输入，作为分布改变下的依赖诊断，不得据此重新选模型。

三种视图分别报告 M2−五个 M1 均值、M2−M0、M3-joint−M3-base 和 M2−M3-joint。机器指标键固定至少包含 `average_precision`（平均精确率）、`pr_auc_trapezoidal`（梯形精确率—召回率曲线下面积）、`mrr`（平均倒数排名）、`map`（查询级平均精确率的均值）、`recall_at_1/3/5/10` 和 `ndcg_at_1/3/5/10`，并包含科学实验合同冻结的其余指标。`average_precision`、`pr_auc_trapezoidal` 与 `map` 不得混称。

敏感性结果不得筛选数据、改变正式代码、Feistel 域／子键／轮数、模板、盐、候选或主结果。对 M0、每个 M1、M2、M3-base、M3-joint 及上述四类模型差值，分别计算完整减字面遮蔽、完整减通道中和、字面遮蔽减通道中和三组开发集平均精确率差。每组固定 `D_hat=AP_left-AP_right`，使用同一批 9,999 次按世界配对有放回重抽样得到 `D_b`。若 `abs(D_hat)>0.01` 或 `Q_0.95(abs(D_b))>0.015`，只能把对应结果表述为“对编码通道敏感”，不得声称跨语言身份迁移效果与编码通道无关；该诊断不能由审核集结果补救。
