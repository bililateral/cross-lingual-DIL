## 0. 关闭结果

该合同错误地假定 Linux 正式工作区能够使用与 Windows 相同的 Git 提交和树；实际批准的部署边界是用户只从 Windows 复制文件到 Linux，不在 Linux 操作 Git。授权尝试一在 Windows 已消费并完成无标签准备，但在 Linux 写入执行声明、加载模型或编码以前即暴露此不兼容。

尝试一按机械失败关闭：未执行 Linux 编码、未发布公开投影、未训练、未读取监督或审核真值，不形成模型或数据结论。36 个准备文件共 954,060,779 字节已经删除；只保留公开授权、消费／清理／准备／终态小回执和本文档。终态 SHA-256 为 `1fddc8c4715fd3c9af7fb18f9003a3142ac75359fc763978e33d525d17d5088b`。私有签发声明删除前为 1,568 字节／`e8cc81b01f4ecf5f9d20d63caa029162f629a551b7262ac7d6082381bd58d2b3`，现已删除，私有保管目录为空。V1 专用授权政策、签发器、状态机、隔离运行器和测试已经删除，不得再次调用。

## 1. 授权目的

本合同只允许把已经取得训练资格的正式中文四拆分，按已冻结的 V1 实现生成无标签公开投影。授权不允许读取训练、开发、审核甲或审核乙的标签、控制者、成员关系或检索相关性，不允许拟合模型、选择超参数、选择阈值、生成审核预测或计算有监督指标。

投影实现提交固定为 `a49151d64b8496a75d28420ac51338b3345d81df`。一次性授权必须另行签发，并绑定签发时的授权实现提交、树、全部授权实现文件、公开投影政策和上述投影实现提交。当前合同、机器政策和代码本身不授予运行权限。

## 2. 单次权限

签发器生成一枚 32 字节随机运行权限，只在授权中公开其 SHA-256 承诺，原始字节不得返回或打印。签发声明必须在抽取权限以前独占写入；声明、授权路径、状态路径、暂存根或正式输出任一已存在时均拒绝再次签发。签发中断后保留声明并删除已产生的原始权限，本次尝试永久占用。

Windows 准备阶段在读取第一个正式数据行以前验证并消费运行权限，先独占写出消费回执，再删除 32 字节运行权限并写清理回执。Linux 返回包必须由冻结转运清单、分块清单、数组哈希、模型指纹和执行回执逐层闭合；Windows 在合并前重新计算并核验这些字节。该机制用于发现同步损坏、错文件、漏文件和非预期改写，不把“攻击者同时篡改载荷及全部清单”作为科研实验威胁模型。消费后任一阶段失败均不恢复权限、不重跑本尝试；只保留小型失败边界，删除原始权限、暂存根、图形处理器工作区和未发布输出。

## 4. 三阶段执行

1. `prepare-windows`：要求签发提交与当前 Git 提交/树一致，工作区除唯一授权文件外无变化，正式输出、暂存和状态路径均不存在。消费权限后，基础侧和身份侧必须由两个独立子进程分别构造中央处理器暂存/无身份不透明转运包与身份投影；协调器不得在同一正式输入进程中同时打开商品文本和 identity33。该阶段不发布正式根。
2. `encode-linux`：只接受已消费回执、准备回执和冻结转运包。它先独占写入图形处理器执行声明，再在仓库外物化精确隔离工作区；隔离进程只见最小图形处理器政策、不透明转运包、冻结模型和精确钉住的最小启动器。成功只回收六项 LaBSE 聚合分数及清单，随后删除隔离工作区。
3. `finalize-windows`：重新验证全部回执和暂存字节，重绑正式公开来源，生成 base24、冻结 M0/C0 概率，逐字闭合基础/身份行键。删除中央处理器暂存、转运包和图形处理器返回后，才写总清单并原子发布正式根。

任何阶段只允许从不存在的目标开始。图形处理器执行声明一旦存在即禁止再次编码；消费回执一旦存在即禁止再次准备；正式根一旦存在只允许验证，不允许覆盖。签发前或签发后尚未消费时误调用 `encode-linux`/`finalize-windows` 只能拒绝，不得创建失败终态、删除任何权限或占用本次尝试。

## 5. 成功与失败边界

成功根的顶层只能包含 `base_v1`、`identity_v1` 和 `public_projection_manifest.json`。四拆分共 756,000 行必须闭合；中央处理器暂存、不透明转运、图形处理器返回、分块和块向量均不得保留。总清单必须继续声明监督读取为零、参数更新为假、阈值选择为假、训练授权为假。

机械失败不形成模型或数据质量结论。失败记录只保存授权摘要、消费摘要、失败阶段、异常类型、异常消息摘要、路径清理状态以及“不得重跑”；不得保存半成品矩阵、文本转运或图形处理器工作区。
