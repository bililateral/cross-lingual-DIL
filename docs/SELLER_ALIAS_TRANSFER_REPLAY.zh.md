# 跨卖家修复迁移驱动的重放：讨论草案

2026-10-03。用户否决此前排序底线联合投影，明确要求“重新设计”；该未提交草稿撤回，不实现、不送审。用户“先讨论方案，暂不上传”的指令继续有效。本稿是新候选，未实现、未测试、未证实新颖性或性能，不授权新的正式计算。LOGIT0.1活动合同不变。

## 研究对象与假设

主线：有限历史训练数据下，学习新分布的卖家，同时保持旧分布未见卖家的马甲候选排序与基础识别。模型只见屏蔽标题/描述，当前是中文合成受控任务。保持记忆训练群自身的能力，不等于保持旧分布泛化。

已有ER0.1和LOGIT0.25结果提示旧能力与新学习仍有取舍，但并未证明记忆过拟合或某种梯度干扰就是原因。本候选检验：按“重放一组卖家对其他卖家的净修复作用”选择历史训练材料，是否比按自身难度、随机抽样或一般迁移收益选择更有效。

## 一次训练如何做

记忆仍随机保留最多6个完整拟合群、全部历史状态≤1MiB，不增加历史选择机会。改变的是存活记忆内本次重放的选择规则，须在新合同中明确。

每次候选选择从当前拟合群取训练群C及与C身份不重叠的观察群V_new；从6个记忆群按固定随机规则分出2个候选重放群H1/H2和剩余4个观察群V_old。完整群间身份隔离先依允许的元数据验证，不用owners。观察群只用于选择本次更新，不参与候选梯度；角色按预定规则轮换。

V_old/V_new都属于允许的训练数据，不是正式valid/test，不增加独立留出。它们过去可能已经参与训练，仅与本次被检验更新的拟合身份隔离，因此不能把它们叫真正未见卖家或用其收益作最终泛化证据。

所有候选从同一个模型theta和AdamW状态s出发，当前梯度g_C及每个候选历史梯度g_H均在theta计算，损失采用现有L_base=BCE+query_rank+0.5 known_top5_hard。历史系数的首个提议沿用0.1，暂不并入LOGIT项，以便先与同目标的ER/MIR等比较；LOGIT仍作为效果参照。

定义U_s(g)为该起点上按真实学习率、梯度裁剪、AdamW动量和权重衰减执行**一次**虚拟更新后的参数。为每个H比较：

    theta_0  = U_s(0)
    theta_C  = U_s(g_C)
    theta_H  = U_s(0.1 g_H)
    theta_CH = U_s(g_C + 0.1 g_H)

theta_0必须是同一步的零数据梯度对照；AdamW有动量/衰减时它通常不等于theta。所有虚拟分支从同一状态独立计算，不连续推进真实优化器，不偷偷累计多个更新。候选梯度使用固定且配对的随机流，观察群用相同eval模式计算损失，不让dropout噪声被当作修复作用。实际选择后的更新复用对应梯度/状态映射，只推进真实Adam一次。

令R_v为某个旧观察群的固定基础损失，低为好。先计算本次当前数据作用造成的损伤：

    d_v = R_v(theta_C) - R_v(theta_0)

只对d_v>0的观察群构成集合D。对H计算：

    B(H) = mean_{v in D} [R_v(theta_C) - R_v(theta_CH)]
    A(H) = mean_{v in D} [R_v(theta_0) - R_v(theta_H)]
    I(H) = B(H) - A(H)
    K(H) = max(0, R_new(theta_CH) - R_new(theta_C))
    S(H) = I(H) - K(H)

B是受到本次新学习影响后，该重放的跨卖家收益；A是没有当前数据梯度时它的一般跨卖家收益；I为两者差分。此处“反事实”只指可重放的优化分支对照，不是已识别真实文本因果机制。I受模型曲率、裁剪和Adam非线性共同影响，不可直接等同纯Hessian项。

原型选择规则建议：D非空、B>0且S>0时选择S最大的H，并列按预定顺序；否则执行theta_C。这是固定的首个候选规则，非已确认最优规则。K的减法允许一定新损失代价，不提供新域非劣保证。长期累积损伤、损伤筛选偏差与差分估计噪声均需验证。

重要区分：候选选择要改变实际历史群及实际梯度。如果只计算S、打印日志，最终仍随机重放，就没有实现本方法。也不能只在head上虚拟更新却声称评估了完整encoder/head更新。

## 创新候选与直接近邻

拟研究的具体差异是：**身份隔离的观察群＋四个一致优化分支的净修复差分＋新群体代价**。核心对象是“某次重放能否修复对其他卖家造成的干扰”，不是保存更多旧文本或保证缓存内原有名次。

- MIR（NeurIPS 2019）按预计新更新会怎样损伤某个历史样本来取样。本候选用另外的身份评价候选重放的效果。已读§3.1： https://arxiv.org/pdf/1908.04742
- MER（ICLR 2019）已有以迁移/干扰和梯度对齐为中心的元重放。“让旧知识帮助新知识”不能作为本候选独占贡献。已读§2—3： https://arxiv.org/pdf/1810.11910
- RER已有双层学习、自适应任务关系和样本权重。本候选不据“自适应重放”认定创新；需核对净修复差分是否超出其机制。已读摘要/引言机制说明，尚未逐项审计全文公式和源码： https://arxiv.org/pdf/2112.15402
- OCS已有代表性、多样性和历史梯度亲和选择。已读原论文概述，尚未实现： https://openreview.net/pdf?id=f9D-5WNG4Nv

当前只能把上述具体差异列为创新假设。不能凭本次定向检索宣称首次，也不能用样本分组换名证明实质创新。若I与简单选择效果/行为等价，就不把四分支复杂性当贡献。

## 必要区分与成本

1. 对同样候选集合与可用观察群比较随机ER、MIR及适配的迁移/重加权近邻；LOGIT为另外必须报告的强效果参照。
2. 将观察群换成重放群自身，检验跨身份评价的作用。
3. 将I替换为B，检验扣除一般学习收益是否必要；它可能无益甚至丢掉有用重放，需要允许反证。
4. 保留实际计算但随机置换候选得分，区分评分机制和额外计算/监督机会。计算配平对照与实际开销均披露。
5. 最终主要证据来自旧分布留出卖家的O MAP/Recall@5，并完整报告N/Z、概率和全部既有指标；训练观察群不充当独立验证。

手写核验应区分四分支差分、真实优化器零梯度分支、选择改变实际更新、身份分离和随机状态恢复。原型明确估计完整模型更新，额外encoder前向/梯度、临时状态和观察次数都计入预算，不能只报一次实际optimizer.step。首次实现前应先核查现有环境能否低内存实现一致的虚拟AdamW；不得自动新建环境。

计算代价可能很高，六群估计也可能噪声很大。候选/观察频率、总运行数和预算尚未确认；本稿不擅自运行，也不承诺旧5—7小时适用于该方法。只有讨论认可、形成有限合同并满足相应审查/授权后才进入计算。
