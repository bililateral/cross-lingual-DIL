## 1. 问题、对照与结论范围

研究问题是：在有限历史训练信息下依次学习新群体时，C_cf 能否相对完整 S 改善旧分布未见账号排序，代价是什么。主要对照始终为完整 S。C_cf 是 C 研究线的新候选，不把 S 已有结构与重组收益算作候选贡献。

保留的信息是同控正候选相对异控负候选的最低评分差。全域训练来源 F 和未用该完整群参加本域训练的来源 O 都支持该顺序时，取双方正分差的较小值；不支持的比较不启用历史约束。后续超过下限不拉回，跌破下限才惩罚。

目标统一称“折外支持的混合目标”：它还依赖 F 和该群训练标签，不是整个目标统计独立、两个独立专家或真实间隔的置信下界。未拟合该群的来源条件与未见身份有关，但共同伪线索、容易关系、来源较弱及迁移失败都仍可能发生。

本轮检验已知构件上的任务增量策略，不声称 cross-fitting、排序／选择性蒸馏首创。C_cf−S 是保持对象、惩罚几何及有效强度共同变化的系统比较，额外来源成本单列；C_cf−C_perm 仅比较原赋值和一次固定可行错配，不能证明折外信息的独立必要性。

## 2. 三臂计算与固定数值

沿用 BAAI/bge-large-zh-v1.5，revision `79e7739b6ab944e86d6171e44d24c997fc1e0116`，以及 schema/step28_chinese_base_policy.json 中 hard_bge_separate_moments 的既有本地模型身份。模型始终同款；额外来源是不同训练范围得到的参数状态。每群28账号、每账号2—8完整记录、最多224记录；仅屏蔽后的标题与描述，分别归一化再拼接除以 √2 得2048维记录表示，4096→128→1对称记录对头，按跨账号记录对均分。256 token、microbatch=4、pair chunk=512，不截断或降采样；UID、域、控制者不进入模型特征。

令 A0 为原账号分组，A1 为同控连通分量内重组完整记录且维持账号条数。所有主臂、所有辅助来源均使用 Bbar=(B(A0)+B(A1))/2，其中 B=BCE+query-rank+0.5 top5-hard。两视图共享一份 live 记录图，不增加物理更新。

| 臂 | B阶段每次实际更新的目标 | 历史目标 |
|---|---|---|
| 完整 S | Bbar(current)+0.1 Bbar(history)+0.5 D0(history) | 原完整FP32记录对表；D0仅比较A0的378个账号分数MSE |
| C_cf | Bbar(current)+0.1 Bbar(history)+0.5 D_cf(history) | 下述1016维FP32下限 b |
| C_perm | 与C_cf相同，只将 b 换成 b_perm | §3一次生成的可行错配下限 |

A阶段三臂相同且没有历史项，故只实际训练一次。当前／历史各一群，梯度相加后共同 clip=1、一次 AdamW。沿用 betas=(0.9,0.999)、eps=1e-8、foreach=False、encoder weight decay=0.01、head weight decay=0，head lr=1e-3。主编码器局部阶段步 t=1..288：t≤29时 lr=1e-5×t/29；其余 lr=1e-5×(288−t)/259；主 Adam 从0连续到288、576。BF16仅用于encoder前向，参数、head、梯度和Adam矩保持FP32，启用既有activation checkpointing。

每次载模前显式调用 configure_numerics，实际读回 deterministic=True、warn_only=False、CUDA matmul TF32=False、cuDNN TF32=False、cuDNN benchmark=False。Python启动前设置 CUBLAS_WORKSPACE_CONFIG=:4096:8；核验与正式入口均留实际读回值。

每群按账号规范顺序 q、同控 p、异控 n 递增构造1016个比较：16×1×26+12×2×25。账号顺序、原始记录顺序继承公开供给；不按分数重排索引。

    mF_e = FP32(F(q,p) − F(q,n))
    mO_e = FP32(O(q,p) − O(q,n))
    b_e = min(mF_e,mO_e)，仅当两者严格>0；否则 b_e=0（未启用）
    D_cf = Σ_(q,p,n) [1/(28 |P_q| |N_q|)] 1[b_e>0] relu(b_e−m_theta,e)^2

F/O评分、间隔、下限及当前m_theta须有限；差值先按约定FP32求得，出生校验、min和错配复用这些值，不能为“提高精度”改用先升FP64再相减。零不是零margin约束；无阈值、温度、按启用数重新归一化或自动删非有限项。出生F/O的账号池化与训练A0使用同一运算／设备数值路径，序列化不改变b字节。

目标常量无梯度。活跃条目对正／负账号分数分别产生 −2w(b−m)、+2w(b−m)，外层再乘0.5；同一无向边被多个查询使用时累加。账号到记录均分导数为1/(r_i r_j)，对称表存储不额外乘2。经表代理、分块head VJP、live BGE反向，和监督梯度共同裁剪／更新；不能以总梯度非零冒称新项接通。

科学补正适用于全部日志和结论：仅某查询自身子项对其候选分数共同平移不变；对称整群项对全部378个无向分数共同平移不变。这是实数性质，非任意尺度或FP32逐位性质。相同0.5不是同等强度；新项为零不保证缓存MAP或未见账号排序不下降。正常日志同时保存违约数，不能因FP32平方下溢或显示舍入而将其当作无违约。

## 3. 来源、错配及真实执行顺序

### 3.1 固定随机流和来源

初始化seed=20260909，主schedule/regroup/dropout沿用20260918，Memory沿用20260930。实验显示名为AB；为复用完整S的同一A/B前缀，主过程随机流命名空间固定用既有 `ABC` 的stage1／2。它只是继承随机派生，不授权C域。主current排列、历史抽样和record.update中的dropout/regroup种子均沿现行函数，臂名不参与派生。三臂共同六群成员及288次历史群序列须相同。

A的48个fit群按 SHA256(UTF-8("C_cf/fold/s0/"+UID)) 排序，并列按UID的UTF-8序；前24为F0、后24为F1，不看分数或标签分布划折。完整群不拆开。复用固定生成／拆分资格，不新读owners；公共账号／记录UID隔离须在允许输入中检查。既有完整群资格不适用则停止。

U0只训练F1、只给存活F0群生成O；U1反之。二者都从A之前同一个预训练BGE、同一个head初始化和空Adam开始，完整model与optimizer初始身份逐项核对；不得从A末训练状态微调回来。无需另存一份域前权重：按同一归档及初始化重建并核对实际身份。

每个U固定6轮×24群=144实际更新，Bbar、无history、无calibration／valid。排列调用data.schedule(other_fold,6,seed_for(20260918,"C_cf","s0","A",role,"current"))；每步dropout种子为seed_for(20260918,"C_cf","s0","A",role,t,"dropout")，regroup再包含群UID和"regroup"。角色为U0/U1，t=1..144。辅助Adam真实计数为t，编码器lr取parent.stage_lr(2t)，不是把Adam步数伪写成2t；head lr不变。辅助工作不能改变主模型保存的RNG、Algorithm R或抽样流。

Algorithm R先依原规则从A的48 fit群选六群，与分数无关。F由共享A末eval完整记录表按同一A0运算取得；O由对应辅助来源末态eval取得。只为这六个存活群生成来源分数，每群一次F、一次O；不挑checkpoint。即使某折无存活群，两份144步来源工作仍照合同完成，不临时改变工作量。

### 3.2 一次固定错配与停止

PCG64(20261012)仅初始化一次。六群按UID的UTF-8序，再按(q,p)规范序处理；正b降序，并列按原三元索引。依次从未分配且mF(q,p,n)≥当前下限的负候选中均匀抽一个，候选列表按n递增；剩余赋零。复用已生成FP32 mF，不重新相减或容差扩充集合。无可选位置是实现／数值错误，立即失败。

逐块核对正条目数、正b精确多重集合、固定宏平均权重和F出生可行性。它不匹配出生松弛mF−b、O支持、候选难度、活跃梯度，不产生总体置换p值。

A末六群全部b为零，或两臂六群下限逐值全部相同：留来源及停止记录，在任何B更新和valid标签解析前停止，不重抽、不改折、不改系数。部分相同则继续并报告变化条目数／比例。此为机制／比较退化，不自动等于程序失败或全方法无效。

### 3.3 作业次序及共同起点

1. 新独立workspace内核对来源／资格／资源，登记访问账，读取§5允许的输入。初始化共享主模型与空Adam，保存其完整身份；不新增未训练valid预测端点。
2. A主学习288步，6次正常epoch诊断。A末完成12群calibration和40群valid盲评分、校准、六群留存及F目标、完整保存／恢复和推理导出；共享A完整model／Adam／RNG一直保留到全部B分支完成。
3. 释放A活动模型；顺序构造U0、U1，各从域前身份开始完成144步，生成各自六群子集的O。保存来源身份、训练输入UID序列、更新／生成日志和必要小评分证据；两份辅助权重不写成持久checkpoint，不支持来源中途恢复。来源模型及Adam只在工作内存中，角色结束即释放；可复用最后一个同结构实例作为随后恢复载体，但其实际状态必须完整覆盖为共享A。
4. 生成b、一次b_perm与三个独立Memory；校验出生及退化。共同model／Adam／RNG、六群成员顺序、seen／retention状态一致；S存完整表、另两臂存各自b，整个Memory哈希不要求相同。
5. 固定依次执行B_S、B_cf、B_perm，各先实际恢复共享A model／Adam／RNG和自己的A末Memory，核对实际张量／optimizer／模式／RNG身份，清空前一臂梯度及数据引用，开始相同history draw流。每分支288步、6次诊断，B末12群calibration、40群盲评分、完整恢复及推理导出。B是终点：不retain B、不建立B历史目标、不训练B辅助来源。
6. 所有更新、恢复、来源、调用量、数据边界与盲预测通过后，登记before_valid，再解析一次valid标签并统一生成评价；保存完整指标／计数后作比较。失败或退化不借“收尾”开放未满足前提的valid。

## 4. Memory、正常诊断和检查点

每臂仅六群，总历史载荷≤1MiB：完整存活文本、训练标签、账号／记录顺序、目标、schema／dtype／出生／折与来源身份、Algorithm R seen／RNG、历史draw状态、必要校准映射、阶段位置及恢复辅助RNG均计入。model／Adam为工作状态另计，不允许额外来源模型跨入B学习信息。裸b为6×1016×4=24,384字节，不等于全Memory大小。

C_cf和C_perm用b替换完整记录表，不另存F/O、mF/mO或第二份目标供训练／恢复。B恢复必须只依赖该臂自己的Memory及共享／本臂model、Adam和合法恢复状态；禁止从来源档案重建遗漏信息、刷新b或恢复淘汰群。S原完整表格式及其目标保持。A末保存三份各自Memory，三个B末各保存本臂末态；共享A的公共模型checkpoint不把S的Memory作为候选恢复依赖。

F/O出生账号分数允许保留在本次Linux审计输出，供同作业出生一致性核对；它们不是B学习器输入，不进入其Memory恢复路径。源码、来源哈希、UID／折列表与汇总可回传；正式文本／标签、完整Memory只留Linux，不进Git或外审包。各分支供给函数只返回其当前fit及自身Memory，不把全调度器或其他臂档案交给训练函数。

每48主更新捕获A0／eval／无梯度诊断：当前48 fit、首阶段0或B阶段6 cache、A/B共40 valid。fit/cache保存MAP、Recall@5、log_loss；valid只盲存预测，统一开放后算同三指标和六点曲线，固定epoch1→6比较，不选最佳轮。S保持旧D0/D1等正常残差诊断；候选用其自身b记录启用数、下限范围、严格违约数和D_cf，不将1016维b送进完整记录表池化，不添旧来源表仅为兼容旧诊断。B缓存按出生域A与A-valid比较；没有C域点，首阶段空缓存为N/A。

诊断恢复各子模块模式、Python／NumPy／Torch及CUDA RNG，不能改参数、已有梯度、Adam、Memory字节或下一次实际更新。source eval和额外工作同样不推进主随机流。正常训练日志可观察，但不据此调阈值、臂、轮数、折或种子。

四个主端点各保存并实际恢复完整model／Adam／RNG／Memory，metadata同时记录各子模块模式和阶段位置，在全部12个当前calibration和40个valid群逐位比较恢复前后raw分数；推理导出另实际恢复并核对完整模型身份。各臂共同A的额外三次恢复核对全部实际model／Adam／RNG和公共成员身份，已确认同一张量状态后不为身份核对重复全量前向。

共享A完整状态只保存一份，不复制三份；三个B临时完整状态依次产生、核对后留身份再删除，最多并存“共享A完整＋当前B完整＋四份已导出的主推理状态”。来源不落完整权重文件；不得偷偷增加临时复制或完整中间epoch权重。全部B完成后共享A完整状态无分支依赖，保留身份及完成证据后释放。四份推理权重先保留至结果／审查依赖核实；按既有用户要求确认无用后先留记录再删。失败状态先留访问、耗时、阶段及可用证据，不能按成功路径误删仍可能需说明的现场。

### 8.1 固定调用量和时间公式

全部实测以最大合法形状、同步CUDA后的墙钟为准，不按正式短样本回推预算。令 t_A=主current实测、t_U=辅助current实测，t_S/t_cf/t_perm=各臂current+history配对实测；同种已测多个值取最大。f为所有原生eval完整群／来源表生成的最大群耗时；h为每群FP32目标生成、错配及出生核对耗时上界。L为一次同配置预训练加载／初始化／身份核对时间；s_F/r_F为完整状态保存／恢复（含身份核对），s_I/r_I为推理状态保存／恢复。

| 纯前向用途 | 群次数 |
|---|---:|
| A六次诊断：6×(48 fit+40 blind) | 528 |
| B_S六次诊断：6×(48+6+40+6额外完整来源表诊断) | 600 |
| 两候选B各六次诊断：2×6×(48+6+40)，下限诊断复用cache分数 | 1128 |
| 四端点完整恢复前后：4×2×(12 calibration+40 blind) | 416 |
| A末六群F及对应O：6+6 | 12 |
| 合计 | 2684 |

    T_train = 288 t_A + 288 t_U + 288(t_S+t_cf+t_perm)
    T_eval = 2684 f + 6 h
    T_IO = 3 L + 4 s_F + 7 r_F + 4 s_I + 4 r_I
    T_projected = 1.25 × (T_train + T_eval + T_IO + 3600秒)

3L为主模型、U0、U1初始化；后续B复用现存同结构对象实际恢复共享A，无额外预训练载入。4个完整保存／端点恢复加3次B共同起点恢复为4s_F+7r_F；推理四份各保存／恢复一次。若实现另有实际加载或重复前向，须在实现审查前修正调用量，不能丢进已测数值或省略。

3600秒固定覆盖文件身份／允许合表扫描、token边界检查、4次校准拟合、fit/cache指标、完整valid评价／条件bootstrap／曲线统计、状态摘要、正常日志／小文件IO和作业内收尾；大型模型加载与checkpoint IO已单列，不声称3600秒为新实测。统一25%余量后，投影须≤57,600秒才取得正式时间资格；全过程实际仍受16小时硬限。
