## 1. 从用户目标到实际计算

用户要求在马甲识别概率不退化的保护下提高候选排序，并选择[冻结C＋概率校准合同](SELLER_ALIAS_CALIBRATION.zh.md)。执行目标是保留C相对D的既有排序提升、检验两项概率损失能否修复；不是继续提升C本身的排序，也不是新持续学习方法。旧13项失败不会回写为通过。

| 要求 | 实现与证据 | 结论边界 |
|---|---|---|
| 排序收益保留 | `transform`使用正斜率仿射logit；`preserve_order`逐群检查全部对的稳定顺序和并列块；评价再次核对全部曲线／检索指标精确相同 | 实数单调性有数学保证，浮点实现仍须在正式分数上实际检查；概率饱和不用于排名 |
| 修复概率输出 | 只拟合a/b，NLL及解析梯度，L-BFGS-B有界求解；已知解析最优点、有限差分和实际六次求解通过 | NLL是训练目标；valid Brier／log_loss均不退化仍是待检验结果，不是求解器保证 |
| 公平对照 | A/C三种子E6都使用同一36群和同一拟合过程；不挑B、E3、s1或某个校准族 | 新主要比较是校准C−校准A，并保护相对原始A，不能仅因对照校准变坏而通过 |
| 一次合法监督 | `parse_once`在解析前独占写入访问记录；train六次共享，valid在六映射完整保存、恢复及来源核验之后；不读取正式文本／权重 | 新正式解析均尚未执行；手工CSV用例不是实际正式标签验证 |
| 对齐和普通复现 | 固定旧作业及分区／模型／分数身份；新映射绑定模型状态和分数；完整排序账号对；保存集合绑定来源和政策；重核数据清单 | 历史模型正确性依赖已有保存恢复实证，本阶段不新加载权重；还需正式预检实际分数 |
| 完整结果后判定 | 先保存12份valid矩阵与计数，再比较、bootstrap、17项验收；故障用例保全全部结果，仅凭保存证据完成汇总 | 采集完成前发生故障不保证完整保全，也不授权自动标签重读 |
| 完整识别与检索报告 | 继承22指标，AP与梯形PR-AUC分开；固定概率0.5群宏和合并计数、各域／种子／条件区间；极低误报诊断保留原决策集合 | 保护平均及s0观察值，不保证每域、每阈值、各seed所有指标或总体非劣效 |

只使用两参数概率校准的标准形式。正斜率保证严格单调；截距允许调整零点。NLL对a/b的梯度为`mean((sigmoid(a*z+b)-y)*z)`和`mean(sigmoid(a*z+b)-y)`。类别比例保持每群20／378，既不重加权也不把训练目标变成正负各半。群大小和域群数相同，展平平均与群／域等权平均一致。
