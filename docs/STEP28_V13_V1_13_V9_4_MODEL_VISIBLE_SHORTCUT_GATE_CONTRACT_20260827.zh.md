## 1. 目的与主线

V9.4 只修复 V9.3-R2 的审计器真值污染，不改变科研主线：先构建独立的 1,004 世界中文合成方法资格数据并完成质量审计，质量通过后才允许比较冻结英文 M0、错配身份历史对照 M1、正确身份历史迁移模块 M2 和直接中文监督 M3。

R2 的机器文件虽写出 `DATASET_INVALIDATED_PREBUILD_STRUCTURE_GATE`，但其所谓“噪声可见”矩阵含有控制者规模、登记处理和端点角色等私有真值派生量，故没有形成数据质量结论。V9.4 不修补或重跑 R2，不复用其随机权威、矩阵、分数或输出路径。

## 2. 固定数据边界

方法资格规模保持训练 500、开发 500、审核甲 2、审核乙 2 个世界，共 1,004 世界。每世界 28 个卖家、12 个控制者、378 个无序卖家对，其中 20 个同控制者正例、358 个异控制者负例。

训练拆分的公开残差继续如实记为 `20／20／20`，开发拆分记为 `22／22／22`，分别表示一范数违例、平方目标和非零单元数。二者只是 5,324 项构造平衡的已知有限残差，不是模型输入、标签定义、质量通过证据或不可满足证明。V9.4 不再求解 `20→0` 或 `22→0`，也不再提高残差边界。

为避免看见结果后挑种子，V9.4 保持 R2 已登记的公开设计种子和确定性轨迹，只在新版本、新代码和新输出路径中从零重放；不得直接读取 R2 五文件计划。重放必须重新证明训练／开发计划不相同、规范全局重标号拒绝和既有拆分距离门。方法资格随机权威必须重新独立创建，审核甲乙真值保持封存。

## 3. 唯一允许进入捷径模型的 14 项特征

每个卖家只有七项无身份变量：

1. 商品数量；
2. 标题缺失率；
3. 描述缺失率；
4. 四个时间桶各自的商品比例。

每个卖家对只计算七项绝对差和七项两端之和，按上述顺序组成固定 14 维矩阵。行键只用于连接和排序，不进入模型。该定义恢复 `docs/STEP28_V13_SYNTHETIC_CHINESE_DATASET_BUILD_CONTRACT_20260727.zh.md` 已冻结的无关变量边界。

前置门从公开联合噪声计划生成无标签代理矩阵；方法根生成后，必须再从实际公开脱敏商品和公开时间索引重算同一 14 维矩阵，并要求逐行、逐列、逐位一致。代理与最终公开表面不一致即机械失败，不能产生数据结论。

## 4. 明确禁止的审计输入

下列字段及其任何编码、散列、聚合、交互或代理不得进入特征矩阵：控制者归属、控制者规模、配对标签、登记处理、克隆或语义端点计数、四类端点角色、登记商品序号、候选序号、回退类型、卖家槽、噪声槽、配对序号、私有商品坐标、身份值、三十三维身份历史、作者风格、自由文本、M0 分数和模型结果。

代码必须同时执行三层拒绝：精确列白名单、依赖闭包禁用模块／字段扫描，以及运行时矩阵列名和维数复核。标签只能在 14 维矩阵冻结并记录摘要后，由窄连接器读取训练和开发真值各一次；审核甲乙真值读取次数必须为零。

登记处理、角色和控制者规模仍须接受精确机械计数与合同重放，但只能写入私有审计回执，不能训练捷径分类器。它们对公开文本造成的溢出影响继续由既有作者风格错排反事实文本门检查，不能用私有处理指示替代公开表面审计。

## 5. 冻结统计门

完整 378 对使用训练世界拟合、开发世界评估。逻辑回归固定为只在训练集拟合标准化器、`C=1`、`solver=lbfgs`、`penalty=l2`、`max_iter=10000`、`tol=1e-10`、`random_state=793820367`。浅树固定为 `HistGradientBoostingClassifier`，原始 14 维输入、`max_depth=2`、`max_iter=200`、`learning_rate=0.03`、`l2_regularization=1`、`min_samples_leaf=20`、`early_stopping=false`、`random_state=793820367`；其余参数必须由机器政策逐项钉住。不拼接其他视图，不动态增列，不运行后调参。固定报告：

- 最大单特征对称接收者操作特征曲线下面积；
- 两模型最大对称接收者操作特征曲线下面积；
- 两模型最大平均精确率相对 `20/378` 的提升；
- 固定开发预测上按世界进行 9,999 次重抽样的两项百分之九十五上界。

重抽样固定使用 `numpy.random.Generator(PCG64)`、种子 `281320260810`、形状 `9999×500`、有放回世界索引、每批 16；抽样整数矩阵原始摘要必须为 `111b1338cc607c6bd78bad88efe47606ffa2230e9cc764eec940e84f86e56661`。每个重复先在两模型内取最大值，再用线性分位数法取 `0.95` 分位；不在重复内重训模型。

硬门保持单特征不超过 `0.52`、模型家族不超过 `0.53`、平均精确率提升不超过 `0.01`，两项重抽样上界分别不超过 `0.53` 和 `0.015`。任一数值不可计算、输入闭包不合格或硬门失败均关闭 V9.4；全部通过只能表述为“未检出 14 项已登记模型可见无关变量超过冻结阈值的捷径”，不能表述为不存在任何捷径。

## 6. 方法根后的完整质量审计

前置门通过只授权构建一次 1,004 世界方法资格根，不授权训练。方法根发布后必须完成：

1. 实际公开表面 14 维矩阵与前置代理逐位重放；
2. 人工商品码和私有标识符零出现；
3. 私有坐标非干预、文档碰撞、拆分隔离和清单摘要闭合；
4. 作者风格错排反事实文本硬门及原作者表面描述性结果；
5. 身份资产、控制者内共享关系、三十三维身份历史和作者风格渲染的机制性正控制；
6. 所有登记观察完整出现，且审核甲乙真值仍未打开。

只有完整质量审计全部通过，方法资格数据才可用于后续 M0／M1／M2／M3 实验准备。审核甲乙仍须在模型、阈值、预测和统计代码冻结后顺序解封。
