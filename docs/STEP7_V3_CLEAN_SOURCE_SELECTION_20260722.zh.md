# Step 7-v3：干净英文马甲数据上的编码器与完整流水线历史选择

> **当前术语纠正（2026-07-24）：**本文件记录已经退役的 v3 实验及其当时采用的资格规则。当前 M0 是“仅用真实英文马甲标签训练并在 Step 28 前冻结的完整英文来源域分类器”，不是编码器，也不要求编码器必须对 18 项特征产生独立增益。权威定义见 `docs/STEP7_STEP28_M0_ROLE_DEFINITION_20260724.zh.md`。下文涉及“编码器增量”的门槛只用于归因分析，不再作为 M0 资格门槛。

## 最终状态与结论边界

Step 7-v3 已完成 Linux GPU 编码和 Windows 选择，但没有得到唯一编码器赢家，编码器相对无编码器对照的独立增量也未获支持。它同样没有提供可冻结为当前 M0 的稳定完整流水线。随后审计发现统一的 512-token 单窗口会截断 `494–513/855` 个卖家（`57.8%–60.0%`）；不同 tokenizer 的完整长度中位数为 `756–867` token，最长为 `7176–7548` token。因此它只能回答“统一单窗口条件下的表现”，不能回答“完整卖家历史下哪个完整分类流水线最可靠”。该实现、policy、tests、runner 和结果产物现已退役删除，本文件是唯一保留的 v3 实验记录；五个模型快照继续由 v3.1 复用。

Step 7-v2 在正式 GPU 打分前撤销。原因有两项：`same_market_bool`、`same_source_dataset_bool` 与标签明显相关，属于数据集捷径；原来的 15 个候选同时改变编码器、附加特征和重排器，无法把胜负归因给编码器。v2 产物和实现不再作为当前实验输入。

## 固定数据边界

- 英文审核对共 `734` 条：训练 `401`（正 `116`、负 `285`），验证 `152`（正 `42`、负 `110`），历史测试 `181`（正 `51`、负 `130`）。
- 卖家共 `855` 个；训练、验证、测试分别含 `229/28/38` 个重算连通分量，卖家和分量跨集合重叠均为零。
- 历史测试已被旧实验使用，只能作选择冻结后的内部开发检查，不能作前瞻确认。
- 所有编码器读取完全相同的五段清洗文本：类别、签名标题、标题、签名描述、描述。卖家名、市场名、联系方式、结构化快照和已登记身份片段均不得进入模型文本。

## 先回答“哪个编码器最强”

比较五个冻结编码器：GTE multilingual base、BGE-M3、multilingual-E5-large、LaBSE、multilingual MPNet。每个模型只生成卖家向量和 pair 余弦分数。

编码器排名直接使用验证集原始余弦，不训练逻辑回归，不加入 18 个迁移特征，也不加入共享重排器。因此这个排名不会被分类头、正则化强度或附加特征改变。E5 仅作为历史连续性对照，不享有保送或并列优先权。

## 防止市场/来源捷径

两个已确认捷径仍会生成，但只用于审计：任何可选编码器或完整分类流水线若包含它们，程序立即失败。

仅从输入中删列还不够，因为模型可能从文本风格间接识别来源。主指标因此按 `(是否同市场, 是否同来源数据集)` 分层，在每个同时含正负标签的分层内计算“连通分量等权 AP”，再对可估计分层等权平均。这样，某个分层整体正例率更高不能直接制造赢家。全体验证集的分量等权 AP 和逐行 AP 都是强制排名一致性检查；不一致时不声称唯一赢家。

## 历史管线与编码器归因对照

每个编码器固定四档，共 `20` 个可选管线：

1. 仅编码器余弦；
2. 编码器余弦 + 18 个不含市场/来源的迁移特征；
3. 编码器余弦 + 共享双向重排器；
4. 编码器余弦 + 18 个迁移特征 + 共享双向重排器。

另有四个不可选择的匹配对照：仅截距、仅迁移特征、仅重排器、迁移特征加重排器。每档编码器管线只与特征完全相同但去掉编码器余弦的对照比较。另训练一个只含两项捷径的审计模型，但它不能参与任何排名。

轻量头统一为标准化 LR/L2。训练只用 `401` 条训练对；L2 在五折连通分量隔离 OOF 上按分层主 AP 选择；阈值只从训练 OOF 的分量等权平衡准确率确定。求解器使用 Newton 方向和 Armijo 回溯，只有最终归一化梯度无穷范数不高于 `1e-9` 才记录收敛，不能再用“参数变化很小”代替最优性检查。验证集只用于冻结候选，测试标签在冻结前不得读取、哈希或参与选择。

一个管线只有同时满足以下条件才可称为“清晰且可归因于编码器的验证赢家”：分层主 AP 比第二名至少高 `0.02`；连通分量 bootstrap 的 95% 下界大于零；全局分量等权 AP、逐行 AP 和均匀训练权重敏感性仍排第一；困难负例和直接正例门槛不恶化；并且相对匹配无编码器对照的分层 AP 增量至少 `0.02`、bootstrap 下界大于零。否则当时会携带验证排名前两名编码器管线进入后续开发，并标记“未区分”或“编码器增量未获支持”。

v3 当时写下的“无编码器对照绝不能被选作 M0”是把编码器归因要求错误提升成了完整模型资格要求，现已撤销。按照当前定义，只要完整、可重放的英文分类流水线满足冻结数据边界并在独立英文确认数据上胜出，无论它使用 18 项特征、编码器特征还是二者融合，都可以成为 M0。编码器是否产生独立贡献必须另列消融结论，不能决定 M0 资格。由于验证集只有 `28` 个分量，bootstrap 只是内部选择稳定性门槛，不是经过选择后或多重比较校正的确认性显著性结论。

## 正式结果

原始冻结编码器按“市场/来源分层内、连通分量等权 AP”排序为：GTE `0.733250`、MPNet `0.721820`、LaBSE `0.719920`、E5 `0.708868`、BGE-M3 `0.609077`。GTE 相对 MPNet 仅高 `0.011431`，小于预注册的 `0.02`；分量 bootstrap 95% 区间为 `[-0.124158, 0.144816]`，且全局分量 AP 和逐行 AP 的第一名分别变为 LaBSE 和 MPNet，所以不能称 GTE 最强。

管线分层主 AP 前两名是 GTE+迁移特征 `0.911597` 与 LaBSE+迁移特征 `0.910936`，差值只有 `0.000661`，bootstrap 95% 区间为 `[-0.006471, 0.007275]`。更关键的是，完全不含编码器的“仅迁移特征”对照为 `0.911909`，GTE 管线相对它反而低 `0.000312`，对应区间 `[-0.003164, 0.001515]`。所以高分主要来自迁移特征，不能归功于编码器。

最终历史结论是：v3 未区分出唯一编码器，编码器增量也未获支持；当时仅把 GTE+迁移特征和 LaBSE+迁移特征记为开发候选。历史测试标签在选择阶段没有读取或哈希，未产生可保留的测试结论。由于随后确认了大面积截断，这两个候选也不再直接进入 Step 28，改由 v3.1 的完整文本共享分块实验重新比较。
