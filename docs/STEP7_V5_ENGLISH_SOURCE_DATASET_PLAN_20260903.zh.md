# Step 7 V5 英文源数据集重构方案（2026-09-03）

## 1. 研究目的

本数据集只服务于一条主线：先从真实英文马甲关系中学习卖家身份判别能力，再检验这份英文监督是否能提高中文马甲识别。它不以英文域内分数最高为最终目标，也不把商品主题相似当作身份能力。

旧 Step 7 的 401 条训练对和 151 条验证对保留为历史结果，不再作为新英文源模型的正式训练或认证数据。其正例大量依赖完全相同的标题、描述或模型可见身份串，且旧验证集已反复用于选择。2026-09-03 的重构探查还误读了旧测试标签的汇总计数（只读取标签及证据类别，未读取测试预测或分数）；因此旧测试集也永久退出 V5 的选择、评估和盲测声明。

## 2. 原始数据与证据边界

正式构建只读取以下冻结原始文件：

- `suspected_sockpuppet_strong.csv`：同一完整公钥指纹的强关系候选；
- `suspected_sockpuppet_weak.csv`：只用于排除可能的假负例；
- `suspected_imposter_rows.csv`：排除冒充账号；
- `tijkc3xx.sql`：核对市场、卖家编号、账号名和冒充标志；
- `3z669jwe.sql`：核对完整公钥指纹确实包含相应卖家编号；
- `2017-12-05-philipjames11-darknetmarketplacedataagora20142015.xlsx`：唯一的模型可见英文商品文本来源。

只采用 Agora 市场（原始市场编号 1），避免市场来源成为标签捷径。同一完整公钥指纹记为正关系，但证据等级仍写作“跨源核验的强银标签”，不虚称人工确认真值。不同控制者组只能形成“经过冲突排除的高置信对照负例”，不能解释为绝对证明二者不是同一控制者。

## 3. 模型可见文本

模型只可读取清洗后的标题和描述，类别只用于匹配和审计，不能进入模型。以下内容先全局删除：

1. 公钥块、签名块、完整或短公钥指纹；
2. 网址、洋葱地址、邮箱、即时通信账号、电话号码和加密货币地址；
3. 本批账号名及公钥别名；
4. 在两个或更多 Agora 卖家中完全相同的标题或描述字段。

第 4 项在不知道标签的情况下对全市场统一执行，而不是只清洗正例。清洗后每个入选账号至少保留 2 条非空商品记录。账号编号、配对编号、折号和行号仅用于连接或划分，严禁进入模型特征。

V3 同时发布两个预先确定的输入视图：

- `full_clean`：保留清洗后的原始措辞，用于完整英文监督和语义对照；
- `style_projection`：在完全不知道标签和配对的情况下，把每个字母词、汉字串和数字替换为“字符类型＋长度＋大小写形态”，只保留标点、分句、词长、大小写和数字书写形式。它是去商品词义的风格敏感性视图，不替代完整文本。

对固定候选账号和商品，同一商品从 `full_clean` 到 `style_projection` 的转换不读取配对、标签或证据类别；改变配对标签不得改变该商品的投影内容。最终发布哪些账号和商品端点仍由确定性配对选择决定，不虚称整个发布文件与配对选择无关。

## 4. 配对、负例与划分

- 正例：两个合格账号属于同一份经三源核对的完整公钥指纹。
- 负例：两端均能由卖家表和原始公钥表唯一对应到一份完整公钥，但二者属于不同身份组，且强表、弱表和原始公钥表均无共同身份关系；冒充账号和高度近似账号名组合排除。负例端不要求自身属于多账号强关系组，这样可以从同一 Agora 市场的大量单账号公钥卖家中找到主题真正接近正例的困难对照。
- 身份冲突图必须先在所有身份资料合格的候选账号上闭合，再应用商品数量和词数门槛。因文本不足或强证据冲突而不能训练的账号仍保留为只在内存存在的保守桥节点，防止把 `A—B—C` 误拆为两个身份分量。经核验强证据中的全部公钥别名和指纹都进入冲突图，不能只取第一行。
- 每条正例确定性匹配 2 条不重复的困难负例。最初预设的 5 条在实际构建中会迫使第 4、第 5 条对照远离正例分布，反而形成商品主题捷径，因此在保持全部质量门不变的前提下收缩为 2 条。匹配变量仅包括清洗后的商品数量、文本长度、类别重合度和词项重合度。
- 控制者组先被确定性分到 5 折；同一控制者的所有账号只能位于同一折，负例也只能在同一折内部形成。模型选择使用控制者隔离的折外预测。
- 最终行顺序和左右端顺序由公开固定种子的散列确定，不能编码标签。

## 5. 质量门槛

数据发布前必须同时满足：

1. 每条正例通过强表、卖家表和原始公钥表三方一致性核验；
2. 公共文本中身份串、联系方式、公钥和跨卖家完全相同文本的残留均为 0；
3. 控制者跨折重叠、重复配对、反向重复和标签冲突均为 0；
4. 至少 25 条正例、20 个独立正关系组，且每个账号至少 2 条非空记录；
5. 纯结构代理（商品数量、文本长度、标题/描述比例）在身份冲突分量隔离的折外评估中不得形成明显标签捷径；
6. 类别重合和词项重合不再伪装成纯结构量，必须作为商品主题/词汇诊断逐项公开报告，但由语义对照、风格视图、英文标签置乱和最终中文迁移增量共同判断是否造成错误归因；
7. 逐项报告正负分布和标准化均值差。若硬门失败，数据不得进入训练。

字符或词语模型从清洗文本中识别作者习惯属于本实验希望学习的信号，不能简单要求其处于随机水平；但后续必须用类别/语义对照、英文标签置乱和中文初始化对照区分作者规律与商品语义。

## 6. 发布物与后续实验

V3 发布目录为 `reports/step7_v5_english_source_dataset/v3_20260903/`，包含两个公共商品视图、公共配对、只含配对编号和二元标签的单独标签文件、质量审计和文件散列清单。控制者散列、证据类别和商品/词项计数只存在于内存审计，不写入训练数据包。公共文件不得出现原始账号名、公钥指纹、类别名或控制者编号。

V1 的三次预构建均未签发且失败产物已删除：小负例池 5:1 的结构/词汇探针曲线下面积约 0.87、最大标准化差约 1.67；扩大同市场公钥池后约为 0.78/1.22；改为 2:1 后约为 0.774/1.088。主要残差始终来自词项和类别重合，说明把词汇诊断当纯结构硬门会迫使构建器针对同一统计量反复优化。一次“强制同类别视图”预构建还在一个折中出现 0 个合格负例，同样未留下产物。

V2 曾生成 28 条正例、56 条负例和每视图 3,350 条商品，纯结构折外曲线下面积为 `0.500638`；但构建器与身份残留审计共用了带词边界的同一账号名正则，独立紧凑字符重放在 5 个入选账号文本中发现自身名称变体，例如空格、连字符或与前缀连写的变体。因此 V2 的“身份残留为 0”是假阴性，不能训练。其标签文件还保留了与标签一一对应且训练不需要的证据类别，增加了误用风险；身份冲突闭包又只覆盖文本合格账号，会遗漏文本不足账号形成的传递桥；同一强证据账号的多个公钥别名也只读取了第一行。V2 清单为 6 个文件、2,574,156 字节，清单 SHA-256 为 `62a713f28f14637248d9ca826471392ae722910dd9093e59c5ae84e4fe0c7116`，构建器 SHA-256 为 `ca859aa4101d331d6e44c1899a05c464b44701dce75d3fa1da35250934adcd6f`；结果在训练前作废并删除，不得恢复或使用。V3 只做对应的最小修复：使用完全不读标签的账号自身及公钥别名变体清洗和独立紧凑字符残留审计；从标签文件删除证据类别；在文本过滤前闭合完整身份冲突图；保留全部强证据指纹和公钥别名冲突边。V3 是明确的新科学合同，不追溯改判 V1 或 V2。

V3 已正式构建并通过全部冻结硬门：28 条正例、56 条负例、24 个独立正关系组、82 个发布账号和每视图 3,458 条商品。完整身份图先闭合 2,840 个节点和 2,808 个分量，其中 103 个节点只作桥、不进入训练。身份别名／公钥残留、跨账号完全相同文本和分量跨折均为 0。纯结构折外双向曲线下面积为 `0.550383`，平均精确率为 `0.338266`（正例率 `0.333333`），提升 `0.004933`，最大绝对标准化均值差为 `0.155187`。主题／词汇诊断仍为曲线下面积 `0.769452`、平均精确率 `0.684380`，所以 V3 只取得“受控英文源监督训练资格”，不取得“身份信号已与商品主题分离”的结论。清单 SHA-256 为 `a26e996e1d23d82fa87576d21580bb544618ac950e5f062c801972ca202f4007`，构建器 SHA-256 为 `589137b8d1fc878958e18221b1f551608c9be6672a58b7b705163c52075a3b63`。10 项目标测试全部通过，其中独立产物测试还覆盖原始公钥表全部合法 40 位指纹及其 16／8 位尾部；唯一未关联卖家编号的合法指纹也未出现在公开文本。网页端 GPT-5.6 Sol Xhigh 未发现新的训练阻断，本地逐项核验后只接受这一窄结论。

数据通过后，使用完全相同的多语言基座和中文训练预算比较：通用初始化、英文 V5 监督后的初始化、英文标签置乱初始化，以及各自相同的中文训练。只有“英文监督初始化相对通用初始化在未参与开发的中文数据上稳定提高”，并通过置乱和消融，才支持“英文马甲识别能力迁移到中文”。最终报告必须同时包含平均精确率、梯形积分的精确率—召回率曲线下面积、受试者工作特征曲线下面积、精确率、召回率、F1、平衡精确率、倒数排名均值、平均准确率均值、前 1/3/5/10 召回率和前 1/3/5/10 归一化折损累计增益。

本批数据规模预计只有约 30 条正对、约 26 个独立正关系组。它比旧 401 对更干净，但统计功效有限；英文域内结果只能作为源监督可学性证据，最终迁移结论仍由冻结的中文盲测边界决定。
