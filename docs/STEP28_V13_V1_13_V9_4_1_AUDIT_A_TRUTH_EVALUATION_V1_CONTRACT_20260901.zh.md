# Step28-v13 V9.4.1 审核甲真值评价 V1 合同

## 科研目的

本阶段只回答一个问题：在审核甲的 500 个从未参与训练或开发的合成世界中，冻结的 M2 身份迁移模块是否仍显著优于五个 M1 错配身份对照，并保持开发阶段预设的门槛。它不重新训练模型，不选择阈值，也不接触审核乙。

本阶段若通过，只能证明迁移增量在独立中文合成世界中成立；不能证明真实中文地下市场上的外部有效性，也不能把 M2 表述为精度最高模型。M3-joint 仍作为直接中文联合训练上限单独比较。

## 冻结输入

- 审核甲盲预测清单规范自哈希：`2f4b39899f27eb1dec6ff57ab2b9ce3f7c7dffb3f50d3424c51c3f322367cc4f`；
- 训练与开发 V2 清单规范自哈希：`7cab52a64081bc3871081a0f8a5bfd308813c2d80b9d433a7cbe277e9cb35364`；审核阈值必须与其中冻结的开发阈值逐模型相等；
- 预测规模：10 个模型，每个模型 189,000 个双精度概率；
- 行键：500 个世界，每世界 378 个卖家对；
- 阈值：完全复用训练与开发 V2 冻结的开发阈值；
- 重抽样：审核甲固定种子生成 `9999×500` 世界索引，字节摘要为 `617be9200ad55b45eda8b1800989d7e0b50579bb53ecee675713f8ba2cd4c3e4`；
- 私有输入仅允许 `audit_a/pair_labels.csv` 和 `audit_a/qrels.jsonl`。控制者、成员关系、生成审计、身份计划及全部审核乙文件均不在允许列表中。

## 读取和评价纪律

正式运行先核验盲预测、阈值、行键和重抽样索引，再分别语义读取审核甲标签和检索真值一次。两者必须逐行一致。评价直接调用冻结的第三版确认评价器，不接受预先计算的指标或重抽样序列。

每个模型必须报告平均精确率、梯形精确率—召回率曲线面积、接收者操作特征曲线面积、布里尔分数、对数损失、误报率百分之一时召回率、精确率、召回率、F1、特异度、平衡准确率、马修斯相关系数、原始及世界等权混淆矩阵，以及平均准确率均值、平均倒数排名、前 1／3／5／10 召回率和前 1／3／5／10 归一化折损累计增益。所有区间和模型差异使用 9,999 次按世界配对重抽样。

## 预设确认门

主比较是 M2 平均精确率减去五个 M1 各自平均精确率的均值，不允许先平均五组概率。审核甲同时置信下界必须严格大于 `0.03`，且 M2 相对每个 M1 的同时下界都必须严格大于零；M1 相对 M0 的等价区间仍须位于 `(-0.01, 0.01)` 内。

通过结果只表示可以另行申请冻结审核乙盲预测，不能由本结果自动授权审核乙。失败时审核乙不得用于挽救结论。
