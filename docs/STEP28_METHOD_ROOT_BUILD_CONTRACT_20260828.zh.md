# Step28-v13 v1.13 V9.4 方法资格数据根构建合同

> 2026-08-28 状态更新：方法资格根已成功构建，状态仍为 `BUILT_NOT_TRAINING_QUALIFIED`。第一次构建后质量审计因只执行一个文本探针而属于 `AUDITOR_DESIGN_INCOMPLETE_NO_DATASET_CONCLUSION`；不得引用其“通过”状态。后继必须在新尝试和新结果路径完整执行质量审计 C 修订件冻结的七视图、十四模型、346 个单特征和 9,999 次世界重抽样。

## 1. 科研目的与边界

本版本只构建用于方法资格审查的中文合成数据根，不训练或比较 M0、M1、M2、M3，不打开审核集甲、乙真值，也不产生真实中文地下市场外部有效性结论。数据根只有通过构建后质量审计，才可取得训练资格。

V9.4 预构建门禁尝试三已经通过。其唯一结论是：训练集和开发集的商品数量、标题缺失、描述缺失及四个时间桶比例所形成的十四项模型可见无关变量，未超过冻结捷径阈值。本次构建必须逐字节重放该十四维投影，不得重新选择数据计划。

## 2. 固定规模与标签

- 训练集 500 个世界，开发集 500 个世界，审核集甲 2 个世界，审核集乙 2 个世界，共 1,004 个世界；
- 每世界 28 个卖家、12 个控制者、378 个无序卖家对；
- 每世界四个三卖家控制者和八个双卖家控制者，故固定 20 个正例、358 个负例；
- 标签仅由“两个卖家是否属于同一私有控制者”定义；
- 训练集和开发集真值可见；审核集甲、乙的控制者、标签和检索相关性只写入忽略版本控制的私有保管区，并在盲预测冻结前保持未读。

## 3. 可见数据生成

商品数量、标题/描述缺失掩码和时间桶必须精确继承 V9.4 已登记计划。商品主题只由与控制者无关的噪声槽和私有文本随机权威决定。可见文本不得包含世界、拆分、卖家、控制者、机制、候选、行序等内部标记，也不得出现旧版本 `Q[A-P]{10}` 人工商品编号。

作者风格是有意身份信号：同一控制者共享基础用词、标点、换行和繁简偏好，每个卖家再作固定两项扰动；每个基础风格同时分配给三个不同控制者，避免“一个样式等于一个控制者”。标题和描述分别生成，身份值仅写入描述，M0 使用的去身份文本必须由同一商品的身份值删除后得到。

身份历史覆盖 Telegram、电子邮箱、BAT、QQ、微信、电话号码、0x 钱包和外部网址，并实现合同冻结的稳定复用、多类型复用、跨市场复用、单跳轮换、双证据两跳轮换、稀疏历史、同控制者无直接共享、零可见历史八类机制。三十三维身份历史只允许由冻结的 Step3 解析器对实际可见文本重放后计算，禁止由控制者或标签直接填写。

## 4. 随机权威与一次性执行

正式构建使用与 V9.4 预构建尝试三同一枚已消耗时间键，保证时间桶逐字节一致；文本、身份值、作者风格、审核计划和标识分别使用新建且相互独立的 32 字节私有权威。正式授权必须绑定实现提交、策略文件哈希、V9.4 通过结果哈希和全部随机权威承诺。输出目录与临时目录均已存在时拒绝运行；失败后先记录最小终止信息，再删除大型失败产物和临时目录。

## 5. 构建后硬门

数据根至少通过以下检查后才可签发训练资格：

1. 规模、20/358 真值、拆分隔离、标识唯一性和清单哈希完全闭合；
2. 训练/开发实际公开商品精确重放已登记十四维投影；
3. Step3 解析结果与私有身份计划逐项一致，三十三维特征只由解析结果生成；
4. 可见文本无人工编号、内部标记、精确跨拆分文档碰撞或真实源文本复制；
5. 已登记无关变量审计、控制者盲作者风格置乱文本审计和逐行人工可读性审计均通过；
6. 身份资产共享、八类机制覆盖、三十三维特征非退化及作者风格正向对照成立；
7. 审核集甲、乙真值读取计数保持为零。

任何一项失败都只得到失败记录，不得训练模型、不得改写同一路径后重试。修复必须使用新版本、新授权和新输出路径。
