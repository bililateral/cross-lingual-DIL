### 指标和持续学习端点定义

记 `Rij` 为学完第 i 阶段后，在第 j 个到达域的同一批确认群上的 MAP；实际 A／B／C 域随顺序映射。

- **最终三域 MAP**：`(R31 + R32 + R33) / 3`。
- **旧域初学 A_acq**：`(R11 + R22) / 2`，指前两个域各自刚学完的水平，不是相对未训练模型的增益。
- **旧域最终 O**：`(R31 + R32) / 2`。
- **平均遗忘 F**：`A_acq − O`，MAP 上越低越好；负值表示后续平均提升，不表示每个域、每条轨迹都没有遗忘。
- **新域学习 N**：`(R22 + R33) / 2`，后两阶段各自刚学完新域的水平。
- **末域 Z**：`R33`；**首域遗忘 F_first**：`R11 − R31`。

排序指标用 raw 分数。Brier、Log loss 及固定概率 0.5 阈值的分类指标使用 **stage-cal**，即各阶段训练侧校准映射；AP、梯形 PR-AUC、ROC-AUC、Recall@FPR1% 的排序／曲线结果在原单调校准下保持不变，此表采用 raw。first-cal（沿用首阶段校准）及其余端点的完整结果保留在原表，本文不混用不同校准口径。

AP、梯形 PR-AUC 在群内无向账号对上评价；MAP、MRR、Recall@k、NDCG@k 在账号查询的候选列表上评价，先平均群内 query，再按群、域及九条固定轨迹的既定权重汇总。AP、PR-AUC 与 MAP 不能互换，分类 Recall 也不同于检索 Recall@k。主表“最终三域”部分对最终三个域等权、九条轨迹等权；顺序行平均三个种子，种子行平均三个顺序，逐轨迹行不再跨顺序或种子平均。

### 结果解释及必须保留的例外

1. **SEQ 明确呈现旧域退化。** 确认集Ⅰ的 SEQ 平均 F 为 0.043722096，九条轨迹均为正。其额外阶段前评分记录支持在 18 个阶段转换中，新域学习增益均为正，15 个转换同时出现适应和旧域下降；这是固定轨迹的描述，不是 18 个独立显著性试验。
2. **ER 与 LOGIT 的保持—适应差异应同时展示。** 确认集Ⅰ ER0.1 相对 SEQ 的 O 增加约 0.007392、F 减少约 0.011368，但 N／Z 分别下降约 0.008558／0.009165，原探索性区间均支持这些方向。LOGIT0.1 相对 ER0.1 的 O 增加约 0.026523、F 减少约 0.026966；N／Z 差的区间跨零，不能据此宣称已证明新域无损。H 对这三种基线的 O／F／N／Z 原探索性区间方向均有利，仍不升格为事后共同主要验收。
3. **三种新增基线的原主要判据通过。** H 对 L²R 的旧域最终 MAP 差为 0.049658810，遗忘量差为 −0.039391078；对 ER+GCR 分别为 0.070397871、−0.023604714；对 FOREVER 分别为 0.051289815、−0.028793115。最终旧域优势同时可能包含初学水平差和后续保持差，不能全部归因于某个抗遗忘组件。
4. **平均达标不等于逐条达标。** 对 L²R，九条配对的 O／F 均有利于 H，但 BCA seed 4、6 的新域 N 较低；对 ER+GCR，O／N／Z 九条均有利于 H，但 ABC seed 6 的 H 遗忘量略多 0.000831417。对 FOREVER，九条配对的 O／F／N／Z／最终三域 MAP 方向均有利于 H。这些计数仅描述既定九条轨迹，不是总体胜率。
5. **H 在 ABC 顺序仍有遗忘。** 确认集Ⅱ平均 F 为 0.015008 左右，确认集Ⅲ为 0.010968832；整体负 F 包含其他顺序的后续提升抵消。较高 MAP 不保证每个辅助指标都更高，例如确认集Ⅱ新域 N 的 Recall@10，H 为 0.780332341，L²R 为 0.785044643。
6. **Precision／MCC 的 N/A 保留原含义。** 三批均有群的分母为零，原协议将其记为未定义，并向上保留 N/A；不填零，也不剔除这些群后重新平均。确认集Ⅲ最终三域 stage-cal 的有效群次数，H 为 1062／1080，FOREVER 为 727／1080；这是重复评价覆盖率，不是独立样本数或准确率。
7. **概率与分类不能只挑有利指标。** Specificity 更高可能伴随更低分类 Recall；每群正对比例仅 20／378。Brier／Log loss 越低越好，但它们是概率预测损失，不单独等于纯校准误差。表中 F 专指 MAP 下降量，不能把同方向解释直接套用到损失指标。
8. **比较范围有限。** H 有既往开发和选参经历，SEQ／ER／LOGIT 沿用各自有历史开发依据的冻结配置，L²R／ER+GCR／FOREVER 则没有新增项目 HPO；各方法开发机会并不相同，监督覆盖、回放量、历史状态和计算成本也不同。结果支持这些固定配置在本任务中的比较，不能否定基线方法家族，不能据此证明单模块因果贡献或真实市场上的普遍优势。

## 二、VendorLink：论文方法应用实验

### 实验范围与方法身份

本批于 2026-11-04 完成，研究的是方法在**英文真实商品文本上的观察账号视图排序任务**中的应用。A = AlphaBay，B = Dream，C = Agora；顺序为 ABC、BCA、CAB，seed 4、5、6。四方法共 36 条完整训练，每市场 40 轮，每条 10280 次更新，共 370080 次更新、108 个阶段端点。

四方法从同一份冻结 `bert-base-cased` 权重开始。`VendorLink_SEQ` 按当前市场账号做分类训练，进入新市场时重建分类头，评价使用最后四层求和、带 mask 的 token 均值及广告相似度聚合。`H_SEQ` 使用英文 BERT、标题／正文双通道和记录匹配头，执行当前自然／重组监督；`H_ER` 增加全局 6 群 Memory 的历史监督（权重 0.1）；`H_full` 再增加旧评分保持（权重 0.5，教师不刷新）。本批 H 的表示仍为最后层 CLS，训练参数继承既有中文选择；它不是后续英文表示／训练适配的结果，也不是中文 BGE 版本的同一个模型。

评价使用 456 个市场内观察账号的 912 个文本视图，共 57 群：AlphaBay 22 群、Dream 8 群、Agora 27 群。每个 query 的唯一正例是同一观察账号的另一份商品文本视图；候选为同群其他视图，54 群各有 15 个候选，另三群分别有 17、21、7 个候选。**这是固定小候选群内排序，不能直接解释为全市场检索或真实跨账号别名识别成功率。**

市场内按 query 等权，最终三个市场等权，九条轨迹等权；不是先对大小不同的群等权。每 query 只有一个正例，因此 MAP = MRR，Recall@1 = NDCG@1，这些相等项不是额外独立证据。该批正式协议只有 10 项排序指标；未纳入 Precision、MCC、F1、ROC-AUC、PR-AUC、Brier、Log loss 等分类／概率评价，不补零或写成“已计算后的 N/A”。

### MAP 分项定义

`Rij` 仍指学完第 i 阶段后对第 j 个到达市场的评价。**旧市场初学 Q** = `(R11 + R22) / 2`；**旧市场最终 O** = `(R31 + R32) / 2`；**遗忘 F** = `Q − O`；**末市场学习 N** = `R33`；**最终三市场 MAP** = `(2O + N) / 3`。

特别注意：本批 `N = R33`，对应中文表的 **Z**；它与中文 `N = (R22 + R33) / 2` 不是同一个量。英文 Q 与中文 A_acq 的公式相同，但数据和方法配置不同，不能直接比较绝对值。

### 人工构造规则

1. 每批使用一个固定插值系数 `p = (目标 MAP − 原实测 MAP) / (1 − 原实测 MAP)`。计算使用原保存字段的完整精度，表格统一显示九位小数。
2. 只改变最终阶段的统计量。最终阶段的 AP、曲线指标、排序指标及已定义的分类指标，统一按 `x* = (1 − p) × x + p` 向理想参考值 1 插值；Brier、Log loss 按 `x* = (1 − p) × x` 向理想参考值 0 插值。0 是损失的理想极限参考点，不表示本次得到过零损失模型。Precision、MCC 原汇总为 N/A，仍记 N/A，不由其他指标猜补。
3. 第一、二阶段的所有统计量保持原值。对 MAP，最终阶段各格统一满足 `R3j* = (1 − p) × R3j + p`；由此计算 `O*`、`Z*`，再用原定义得到 `F* = A_acq − O*`、`N* = N + (Z* − Z)/2`、`F_first* = F_first − p × (1 − R31)`。因此示例里的遗忘改善是额外假设的代数结果，不是模型验证结论。
4. 同一批的九条轨迹使用相同 p，按原权重平均得到顺序、种子和总体示例。沿用 N/A 传播规则；不生成新的置信区间、显著性、胜率或通过标志。
