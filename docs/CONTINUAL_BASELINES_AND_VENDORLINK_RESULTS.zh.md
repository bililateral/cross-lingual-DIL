## 一、持续学习对比基线：L²R／ER+GCR／FOREVER

### 实验范围和两批确认集

这三种方法都是**持续学习对比基线的固定任务适配**。输入为中文商品标题和描述，使用既定中文 BGE 起点，评价未参与训练的账号身份之间的群内关联排序。A、B、C 是合成表达域；训练只覆盖 ABC、BCA、CAB 三种循环顺序，每种顺序使用 seed 4、5、6，每方法九条轨迹，并未跑全部六种排列。每域 48 个 fit 群、12 个训练侧校准群，每阶段六轮、288 次当前更新；每条三个阶段共 864 次当前更新，额外回放更新随方法而异。

- **确认集Ⅰ（L²R／ER+GCR）**：`continual_comparison_confirmation_20261024`，生成种子 `2026102401`。2026-11-01 完成整批确认与分析。两种新基线共新增 18 条训练、54 个阶段端点；表中的 H 复用原 `H_pos_tuned` 九条训练、27 个阶段端点，并在本批新确认群上评价。
- **确认集Ⅱ（FOREVER）**：`forever_confirmation_20261030`，生成种子 `2026103001`。2026-11-03 完成整批确认与分析。FOREVER 新增九条训练、27 个阶段端点；H 复用同一组原 `H_pos_tuned` 模型，在这一批新确认群上重新评价。

两批分别包含 A／B／C 各 40 群，共 120 群、3360 个账号。每群 28 账号、378 个无向账号对，其中 20 正对、358 负对；每个 query 排除自身，在 27 个候选中检索 1 或 2 个正例。**两批 H 权重相同，确认样本不同，因此必须分别保留 H（Ⅰ）和 H（Ⅱ）。** 合并表便于查阅，不把 L²R／ER+GCR 与 FOREVER 的绝对分数直接排成同一确认集上的名次，也不把两批 H 当作两次独立重训。

方法名称对应：H = `H_pos_tuned`；L²R = `L2R_text_fixed`；ER+GCR = `ER_GCR_group_fixed`；FOREVER = `FOREVER_group_fixed`。H 使用标题／正文表示、记录匹配与账号聚合、自然／重组监督、历史监督及旧评分保持；历史监督系数 0.1、旧评分保持系数 0.5，固定全局 6 群 Memory。三种基线采用已审的查询／负例重放、梯度选群及加权重放、参数位移时钟驱动回放等各自适配。它们是完整系统比较，不是单模块消融，也不宣称逐项复现原论文的原始基准。

### 指标和持续学习端点定义

记 `Rij` 为学完第 i 阶段后，在第 j 个到达域的同一批确认群上的 MAP；实际 A／B／C 域随顺序映射。

- **最终三域 MAP**：`(R31 + R32 + R33) / 3`。
- **旧域初学 A_acq**：`(R11 + R22) / 2`，指前两个域各自刚学完的水平，不是相对未训练模型的增益。
- **旧域最终 O**：`(R31 + R32) / 2`。
- **平均遗忘 F**：`A_acq − O`，MAP 上越低越好；负值表示后续平均提升，不表示每个域、每条轨迹都没有遗忘。
- **新域学习 N**：`(R22 + R33) / 2`，后两阶段各自刚学完新域的水平。
- **末域 Z**：`R33`；**首域遗忘 F_first**：`R11 − R31`。

排序指标用 raw 分数。Brier、Log loss 及固定概率 0.5 阈值的分类指标使用 **stage-cal**，即各阶段训练侧校准映射；AP、梯形 PR-AUC、ROC-AUC、Recall@FPR1% 的排序／曲线结果在原单调校准下保持不变，此表采用 raw。first-cal（沿用首阶段校准）及其余端点的完整结果保留在原表，本文不混用不同校准口径。

AP、梯形 PR-AUC 在群内无向账号对上评价；MAP、MRR、Recall@k、NDCG@k 在账号查询的候选列表上评价，先平均群内 query，再按群、域及九条固定轨迹的既定权重汇总。AP、PR-AUC 与 MAP 不能互换，分类 Recall 也不同于检索 Recall@k。主表“最终三域”部分对最终三个域等权、九条轨迹等权；顺序行平均三个种子，种子行平均三个顺序，逐轨迹行不再跨顺序或种子平均。

### 结果解释及必须保留的例外

1. **三种基线比较均支持本轮固定系统的平均旧域排序与保持优势。** H 对 L²R 的旧域最终 MAP 差为 0.049658810，遗忘量差为 −0.039391078；对 ER+GCR 分别为 0.070397871、−0.023604714；对 FOREVER 分别为 0.051289815、−0.028793115。最终旧域优势同时可能包含初学水平差和后续保持差，不能全部归因于某个抗遗忘组件。
2. **平均达标不等于逐条达标。** 对 L²R，九条配对的 O／F 均有利于 H，但 BCA seed 4、6 的新域 N 较低；对 ER+GCR，O／N／Z 九条均有利于 H，但 ABC seed 6 的 H 遗忘量略多 0.000831417。对 FOREVER，九条配对的 O／F／N／Z／最终三域 MAP 方向均有利于 H。这些计数仅描述既定九条轨迹，不是总体胜率。
3. **H 在 ABC 顺序仍有遗忘。** 确认集Ⅰ平均 F 为 0.015008 左右，确认集Ⅱ为 0.010968832；整体负 F 包含其他顺序的后续提升抵消。较高 MAP 不保证每个辅助指标都更高，例如确认集Ⅰ新域 N 的 Recall@10，H 为 0.780332341，L²R 为 0.785044643。
4. **Precision／MCC 的 N/A 保留原含义。** 两批均有群的分母为零，原协议将其记为未定义，并向上保留 N/A；不填零，也不剔除这些群后重新平均。确认集Ⅱ最终三域 stage-cal 的有效群次数，H 为 1062／1080，FOREVER 为 727／1080；这是重复评价覆盖率，不是独立样本数或准确率。
5. **概率与分类不能只挑有利指标。** Specificity 更高可能伴随更低分类 Recall；每群正对比例仅 20／378。Brier／Log loss 越低越好，但它们是概率预测损失，不单独等于纯校准误差。表中 F 专指 MAP 下降量，不能把同方向解释直接套用到损失指标。
6. **比较范围有限。** H 有既往开发和选参经历，三种新基线没有相同的项目调参机会；监督覆盖、回放量、历史状态和计算成本也不同。结果支持这些固定适配在本任务中的比较，不能否定基线方法家族，不能据此证明单模块因果贡献或真实市场上的普遍优势。

## 二、VendorLink：论文方法应用实验

### 实验范围与方法身份

本批于 2026-11-04 完成，研究的是方法在**英文真实商品文本上的观察账号视图排序任务**中的应用。A = AlphaBay，B = Dream，C = Agora；顺序为 ABC、BCA、CAB，seed 4、5、6。四方法共 36 条完整训练，每市场 40 轮，每条 10280 次更新，共 370080 次更新、108 个阶段端点。

四方法从同一份冻结 `bert-base-cased` 权重开始。`VendorLink_SEQ` 按当前市场账号做分类训练，进入新市场时重建分类头，评价使用最后四层求和、带 mask 的 token 均值及广告相似度聚合。`H_SEQ` 使用英文 BERT、标题／正文双通道和记录匹配头，执行当前自然／重组监督；`H_ER` 增加全局 6 群 Memory 的历史监督（权重 0.1）；`H_full` 再增加旧评分保持（权重 0.5，教师不刷新）。本批 H 的表示仍为最后层 CLS，训练参数继承既有中文选择；它不是后续英文表示／训练适配的结果，也不是中文 BGE 版本的同一个模型。

评价使用 456 个市场内观察账号的 912 个文本视图，共 57 群：AlphaBay 22 群、Dream 8 群、Agora 27 群。每个 query 的唯一正例是同一观察账号的另一份商品文本视图；候选为同群其他视图，54 群各有 15 个候选，另三群分别有 17、21、7 个候选。**这是固定小候选群内排序，不能直接解释为全市场检索或真实跨账号别名识别成功率。**

市场内按 query 等权，最终三个市场等权，九条轨迹等权；不是先对大小不同的群等权。每 query 只有一个正例，因此 MAP = MRR，Recall@1 = NDCG@1，这些相等项不是额外独立证据。该批正式协议只有 10 项排序指标；未纳入 Precision、MCC、F1、ROC-AUC、PR-AUC、Brier、Log loss 等分类／概率评价，不补零或写成“已计算后的 N/A”。

### MAP 分项定义

`Rij` 仍指学完第 i 阶段后对第 j 个到达市场的评价。**旧市场初学 Q** = `(R11 + R22) / 2`；**旧市场最终 O** = `(R31 + R32) / 2`；**遗忘 F** = `Q − O`；**末市场学习 N** = `R33`；**最终三市场 MAP** = `(2O + N) / 3`。

特别注意：本批 `N = R33`，对应中文表的 **Z**；它与中文 `N = (R22 + R33) / 2` 不是同一个量。英文 Q 与中文 A_acq 的公式相同，但数据和方法配置不同，不能直接比较绝对值。

### 原结论与解释边界

**当前 H_full 未达到优于 VendorLink 的预期效果。** 最终三市场 MAP：VendorLink_SEQ = 0.897071877，H_ER = 0.891883684，H_SEQ = 0.881144571，H_full = 0.876405194。H_full − VendorLink 为 −0.020666683，即低约 2.066668 个百分点，九个顺序×种子配对的最终均值全部为负；这不等于每个单独市场或每个组成端点都落后。

H_ER − H_SEQ 的最终 MAP 均值为 +0.010739113，九条配对七正二负；H_full − H_ER 为 −0.015478490，九条配对二正七负。本批描述支持历史样本监督的平均收益，但当前旧评分保持配置没有带来平均整体收益。它未隔离约束强度、教师质量、Memory 覆盖或语言因素，不能把这些候选原因写成已经证实的结论。

四方法的整体平均 F 都为负，表示旧市场平均表现后续提升，但并非所有顺序／市场都无遗忘。H_full 的 F 比 VendorLink 更低，同时其初学 Q、最终旧市场 O 和末市场 N 都更低，不能仅凭较小 F 宣称抗遗忘获胜。表内逐顺序和逐轨迹结果保留这一差异；本批三顺序整体结论也不等于后续固定 ABC 开发的结论。

VendorLink 并非所有辅助指标都最高：H_ER 的 Recall@3／5 更高，NDCG@3 也略高；H_SEQ 的 Recall@10 最高。H_full 仅在 Recall@10 略高于 VendorLink，这不改变其 MAP 与首位排序落后的结果。

本批原状态为 `DESCRIPTIVE_FIXED_DATA_ONLY`，`passed = null`，整体置信区间均为 null。它没有设置统计优势验收，不能把 null 写成统计失败或缺失计算。57 群按候选共享及跨市场同名关联只有 10 个连通分量，最大分量含 48 群及全部 Dream 群，不能把群数、重复 query 数或九条轨迹当作独立样本另造显著性结论。

账号名遮蔽和精确重复剔除已实施，但原记录明确 `near_duplicate_exclusion=False`、`latent_owner_disjointness_verified=False`。近重复未完全排除，真实控制人身份独立性未验证；跨市场同名共用划分不保证不同账号名背后的真实控制人不跨划分。此处保留未知范围，既不声称已完全排除泄漏，也不把未知直接判为已证实泄漏。Dream 的 7 候选单群中 Recall@10 按定义为 1，不能视为困难的前十检索证据。英文约 0.90 的 MAP 与中文约 0.50 的 MAP 所处任务、候选和正例定义不同，不能跨实验直接排名。
