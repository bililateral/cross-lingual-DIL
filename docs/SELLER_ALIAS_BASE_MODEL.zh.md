## 已确认的问题与已有证据

研究对象仍为当前表达变化合成中文卖家数据中的同控制者账号关系；继续使用屏蔽身份信息的标题与描述。先建立有意义的基础识别能力，再研究如何在持续学习中保留该能力。此前有效遗忘和缓解结果保留，不因为基础能力需要加强而改写为无效实验。

当前LaBSE＋均值账号表示＋对称分类头从通用预训练编码器和随机分类头开始。第一域训练后再续训后两域，因此已有实验并非直接从未训练分类器测遗忘。但原可学性门主要是相对初始化的AP增量与联合／单域的相对差，没有冻结与应用目标对应的绝对识别能力门。

用户明确采纳首轮开发能力门：固定校准阈值下，valid三个域各自的异控对误报率FPR≤0.1%，同时同控对Recall≥50%；全部三域逐域及合并计数、Precision及区间同时报告，不能用总体数字掩盖某域失败。每域valid有7160异控对和400同控对，等价于FP最多7、TP至少200。它是开发筛选点值标准，不是实际部署保证或事后追认的旧实验门。

阈值算法：每域校准集有4296异控对，允许最多4个误报；异控logit降序第5个值的float64向正无穷相邻数作为该域下界，三域取最大，得到一个全局阈值。预测严格执行float64(logit)≥float64(threshold)，并列边界一律排除；全拒绝也如实报告，不放宽FPR换取召回。此算法不使用校准正例成绩优化阈值，也不看valid标签。5000次、种子20260918的域内群bootstrap给出条件95%区间，模型间用相同抽样；区间条件于固定模型和校准阈值，不涵盖重新训练／校准的不确定性。零观测误报的bootstrap区间可能为[0,0]，不构成人群误报率上界。

按当前正负比例20∶358计算，在Recall恰为50%时，FPR为0.1%对应Precision约96.54%；FPR为1%时约73.64%。这是固定比例下的算术说明，不是模型实测或真实市场保证。点值达到但区间宽时仍需如实披露；现有valid反复用于开发，本轮不作独立测试确认。不因某个AP高或仅超过LaBSE就宣布自动识别达标。
