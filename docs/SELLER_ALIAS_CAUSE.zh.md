# 普通继续训练未出现域均值下降的原因诊断

日期：2026-09-10。状态：首项 Linux 推理与一次 Windows valid 评价已完成，结果全量回传、独立核验通过；网页结果审查及本地处置已完成，未确认使结果失效的问题。见[实际结果](SELLER_ALIAS_CAUSE_RESULT.zh.md)。本阶段 valid 解析已消费，训练原因尚未完全确定；下文为冻结方案及其边界。

## 用户目标与边界

用户要求先查明前次模型为何未呈现预期遗忘，作为继续科研的前提，并明确“如果现有结果无法确定，那就做实验来确定”。本阶段只调查原因，暂不开发防遗忘方法。原[三轮同域/换域诊断](SELLER_ALIAS_DIAGNOSTIC.zh.md)仍保留为草稿，不自动运行。允许原因由多个因素共同构成；不能把相关性、局部下降或未显著当作唯一因果证明。

首先针对最近的新群体实验 20260909_162607；旧文本实验的表示、数据和评价不同，不合并作因果对照。原数据、结果、主端点与有效负结果保持不变，test、owners 和历史封存真值继续不读。

## 现有证据已经查明什么

见 [逐群/执行审计](../reports/seller_alias_continual/20260910/cause_audit/evidence.json)、[模型分数与可见表达特征](../reports/seller_alias_continual/20260910/cause_audit/style_association.json)及[独立复核](../reports/seller_alias_continual/20260910/cause_audit/verification.json)。前期证据审计未解析任何监督标签、加载模型或训练；后续正式探针与一次 valid 评价另见结果。

1. “完全没有遗忘”不是原结果支持的表述。六个最终旧域均值提高，但 120 个顺序×旧群观测中，40 个 AP 下降、80 个提高。正变化对总平均贡献 +0.036585378，负变化贡献 −0.012773664，净值 +0.023811714。MAP 有 47 个观测下降。这里复用了 60 群，不能视为 120 独立样本；局部下降尚未得到重复训练或因果对照支持。
2. 普通继续训练六段都只读当前域 60 群，每群呈现三次，历史样本呈现为零。三条轨迹的共享/第二/第三阶段模型状态摘要不同；每次相邻阶段全部 22,680 个 valid logit 改变。现有代码与运行记录不支持“实际没有更新”或“普通臂混入旧样本重放”的解释。真实初步检查分别验证过编码器和头梯度/更新；正式日志没有逐步模块位移，不能夸称每一步都单独审计过。
3. 新卖家不是新分类输出。模型始终判断两个不同账号是否同控，使用同一个纯文本编码器与二分类头。三域共享商品词表、标题模板、描述模板、服务话术和相同的马甲继承机制；只改变经营内容的混合比例。
4. 从全部 6,120 条公开 valid 商品原文可精确还原 1,680 账号的三轴表达特征，账号内保持一致。九个阶段点中，“两账号一致的表达轴数”与 logit 的群内 Spearman 相关均值为 0.843—0.919，每点的 60 群相关都为正。独立的完整模板重建和不依赖 scipy 的平均秩复算一致，最大差 4.44e-16。这比仅阅读合成器更接近实际模型行为，但仍可能混合商品相似性等关联，不能据此宣布因果已确定。
5. 原日志只有跨训练中不同模型/样本的阶段平均 BCE，没有固定训练集在每个检查点的完整误差或逐轮曲线。不能用阶段 BCE 从约 0.20 到 0.16 宣称已收敛，也不能用 AP 约 0.34 宣称训练不足。常数先验概率的理论 BCE 为 0.206996168，只是参照。

目前优先假设是：模型使用了跨域保持有效的模板/服务话术一致性，新域数据继续提供这类监督，部分改善抵消了局部退化。尚未确定这一机制的贡献，也未排除商品偏好共享、训练成熟度与模型容量的作用。

## 第一项实验：固定已训练模型，干预表达关系

先验证实际模型依赖，不追加训练或更改生成机制。使用原三顺序各自的首域后冻结模型与最终 sequential 模型，共六个现有推理权重；三个 frozen 权重正是相应共享首阶段模型，无需重训恢复。只处理同一批 60 个 valid 群、固定账号/商品顺序及原二值关系。首域学完到最终的保持比较，按 ABC 的 A、BCA 的 B、CAB 的 C 各 20 群配对；第二个旧域的中间权重没有长期留存，不将最终模型或其他臂冒充它。

对应的原文首域 AP 变化应为 +0.032807483897219374，60 群中 15 降、45 升；MAP 变化为 +0.032556119122103294。它与前述两旧域合计 120 观测的 +0.023811714 是不同范围，不可混用。

每个模型评价三种预先固定的输入视图：

- original：原文原样。全部分数必须与原保存结果逐元素一致，否则停止解释新干预。
- renamed：三个表达轴分别全局循环重命名一次，即标题/描述模板索引加一模三、服务话术族索引加一模四。所有账号间轴相等关系保持不变，但具体表达改变。它是表面改写敏感性的对照，不保证模型天然不受影响。
- reassigned：在 renamed 基础上，群内按固定公开账号顺序做非零循环移位，把完整三轴表达组合分配给另一账号。偏移由固定种子 20260910 和群 ID 确定，不读取标签或控制者信息，不试多个置换选结果。保持群内账号级表达组合的多重集合，破坏原账号与表达之间的对应关系；原有相等关系可能偶然保留，须报告实际改变比例。

两种改写都完整解析并重新渲染已存在记录，保留商品、限定语、intro/detail/packaging/delivery 原字符串、商品数量/ID、账号及二值关系。服务话术保留原族内位置，仅替换族；这是模板与服务话术的联合干预，不称纯标点或纯语言风格干预。每账号所有记录使用同一新组合。只生成诊断视图，不替换原数据。必须验证原文精确重建、商品内容不变、全局改写的相等关系保持、群内重分配的组合计数保持；账号商品数不同使逐商品模板频数不必严格相同，记录该限制。

采用相同改写输入比较六模型，不能按模型分别选置换。原文给保持事实；renamed 区分表面表达改变的影响；reassigned 进一步检验原有表达对应关系对评分/识别的影响。固定模型使干预效应不混入重新训练随机性。

## 评价与可解释范围

Linux 只读 public valid 原文与既有六模型，输出六模型×三视图的完整 60×378 float32 分数和核验回执，不读任何监督。完整回传及原分数重放门通过后，Windows 对本阶段独立解析一次新 valid 二值 CSV，对原文与两种视图使用完全相同的标签/候选对，计算原 22 项指标。train、test、owners 一律不解析；原阶段已消费的权限不复用。

在这同一次 valid 解析内，利用内存中的标签，按群/视图保存正边与负边各自的八种三轴相等模式计数及三轴一致率。模式顺序为标题、描述、服务，000 至 111；每群正边总计 20、负边 358。必须区分“轴关系发生改变”与“表达—同控关联实际削弱”：固定置换可能保留标签图结构。原文与全局改名的标签条件计数应完全一致；群内重分配前后的全体边模式边际计数也应一致。关联是否削弱需据实际计数判断；若没有削弱，报告操纵不足，不重抽置换。

AP 为本诊断主要排序尺度，MAP 为预先指定的检索核对；同时保留 MRR、Recall/NDCG@1/3/5/10、梯形 PR-AUC、固定 logit=0 分类及概率指标，不调阈值。报告每视图的首域/最终绝对表现、最终减首域变化，以及 renamed−original、reassigned−renamed 在两检查点的效应及其差中之差。对每域 20 群进行配对 bootstrap，5,000 次，固定种子 20260910，所有视图/检查点共享抽样。区间仅条件于既有模型及单次指定改写；本 valid 已见，不作为新的独立确认集。

预先区分以下结果：

1. 若仅全局改名就严重损害结果，说明模型对具体表达敏感。不能将 reassigned 的全部损害归因于马甲一致关系被打散；优先报告此不辨识问题。
2. 若 renamed 保留较多能力，标签条件计数确认重分配确实削弱了原表达—同控关联，而 reassigned 明显削弱两阶段能力，则有固定模型利用原表达对应关系的干预证据；这比相关性强，但仍不等于证明其独自造成净保持。估计的是该联合重分配的总效应，包含表达与商品内容配合、服务语义和记录聚合的影响，不是某一轴相等谓词的独立效应。
3. 若两模型对干预的效应不同，结合保持差中之差判断该类线索对观察到的阶段差有何贡献。必须同时查看绝对表现，防止被打散视图已接近低值而产生“更少遗忘”的地板效应。不把差中之差机械解释为训练过程中被该线索中介的比例。
4. 若表达干预效应小、全局改名对照失败或保持差没有可解释变化，不认定优先假设成立；再针对商品偏好或训练成熟度提出最小后续对照。训练成熟度若需实验，使用预先固定的同域/换域对照，不反复扩大轮数或学习率直到出现遗忘。

这项实验能识别固定模型对一组可见线索的依赖及其阶段差，不能保证一次实验唯一识别此前无域级遗忘的全部原因。原因未查清前，不恢复防遗忘方法开发。

要进一步确认“后续域中的共享表达监督促成了保持”，必须干预训练信息通路：从相同首阶段模型及非空 Adam 出发，保持后两个阶段的账号、商品内容、标签、更新数和日程不变，一支保留原表达对应，另一支按固定规则重分配表达；最终均在同一原文旧域 valid 上评价。预先预测是“保留关联训练的旧域变化 − 打散关联训练的旧域变化 > 0”，不要求后一支一定绝对遗忘。原首域推理权重没有 Adam，忠实起点需要重建；仅做一次转换不能解释原两阶段末态。用户随后以“采用这套配置”确认了[训练侧对照](SELLER_ALIAS_CAUSE_TRAIN.zh.md)的具体预算和新监督合同，Windows 实现、本地核验及实际网页外审已完成，最小缺陷已关闭；新 Linux 阶段仍须单独汇报暂停，不包含在原 45 分钟纯推理范围，也不自动恢复旧草稿。
