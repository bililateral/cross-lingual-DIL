主问题：**中文暗网卖家数据分批加入、历史训练记忆受限时，保存哪些已有的账号关系用于后续训练，才能兼顾旧分布上的马甲识别能力与新数据学习？**

每个阶段得到一批完整中文世界的公开输入和合成二值训练标签；训练器使用当前批数据与有限的历史记忆更新同一个判别模型。记忆里的关系必须包括重新训练所需的公开特征和同控／异控标签，按方法需要附带端点标识或旧输出，不能只存一个关系名称却通过磁盘无限回查旧记录。

模型始终判断两个账号是否同控，并为候选账号排序。卖家增加不意味着把每个卖家当作一个分类类别；这里先研究固定二分类输出的样本／分布增量，不照搬不断扩充身份分类头的类增量设定。评价主体是与训练身份隔离的开发账号，不能用记住缓存中的训练关系代替泛化能力。

首轮保持整个世界同批到达，因此验证的是留出身份上的分布泛化保持，尚不模拟同一卖家隔一段时间又新开一个马甲、再跨批连接该账号的发现过程。后者会改变世界完整性及特征依赖，不由当前结果自动支持。

三个研究问题按顺序回答：

| 问题 | 具体检验 | 对应结论 |
| --- | --- | --- |
| RQ1：顺序更新会损失哪些旧能力？ | 在固定开发账号及候选库上，比较每次更新前后的旧分布表现，同时记录新分布学习增益。 | 先区分真实更新干扰、同分布随机波动、模型根本没学会和候选库变化。 |
| RQ2：少量随机历史记忆能解决多少问题？ | 相同输入和模型下比较冻结、继续训练、随机 reservoir 重放与累计重训。 | 建立记忆带来的实际收益与更新成本，判断是否需要复杂选择器。 |
| RQ3：保留相互关联的账号对，能否优于独立样本选择？ | 在同一字节预算下，检验共同账号的正／负关系联合入选，并加入正负比例、难度和重复次数匹配的独立边参照及直接强基线。 | 有增量才提出具体关系选择贡献；无增量保留负证据，不用任务名称代替创新。 |

潜在方法问题是**有限记忆中保存哪些相互关联的账号对**。普通随机重放、困难样本重放、梯度多样性和旧输出蒸馏均有成熟近邻，不能把“给中文数据加 replay”称为新算法。第一步只建立可解释的遗忘与重放参照；看到具体失效后，才决定是否值得做关系选择器。

这比重新设计跨语言来源、弱监督或多模态机制更集中，但目前没有依据承诺顶刊顶会录用，也未证明这是很大的空白。方向价值取决于是否存在合理的更新困难、简单方法是否不足，以及后续关系选择是否提供可重复的增量。

“共享第一阶段”明确指每个到达顺序内部：相同首批、预处理、初始化、训练次序与第一阶段仅当前样本损失，得到一份共同权重及优化器状态；继续训练与 ER 均按同一口径继承 Adam 状态。各顺序首批不同时分别训练，不能搬用另一个顺序的第一阶段模型。新样本排序、记忆选择与重放采样使用独立随机流，防止某方法额外抽样改变共同的新样本序列。冻结臂固定全部评分状态；累计重训仍按每阶段共享原始初始化重置头与优化器，另行明确累计历史训练日程并报告成本。

方法阶段预定重点比较关系选择与正负分层随机 ER，并同时报告普通 ER、MIR、DER++。主比较对象、配额／难度匹配和阶段汇总方式在运行该比较前明确，不事后选择最弱基线作为主对手。若仅总体 AP 提高而旧能力更差，应报告总体改善及其代价，不能改写成“减少遗忘”。

## 发现问题时怎样纠偏

| 实际发现 | 最小处理 | 结论边界 |
| --- | --- | --- |
| 旧特征依赖未来批次或完整世界被拆开 | 保持世界完整；受影响统计只使用到达范围重算并保存为新实验派生输入，核验与原特征的区别。 | 修复新的到达协议，不重写旧批量实验结果，也不等于重新合成数据。 |
| 公开分组不同，模型实际输入却没有实质差异 | 保留同分布顺序更新参照；取消没有支持的跨分布解释。 | 不看标签或遗忘结果再挑一个“更有利”的划分。 |
| 小头没有学到基础识别能力 | 先核对预处理、标签对齐、损失和真实更新；若确属容量限制，记录证据后统一调整所有比较臂。 | 不把一个学不会的模型的稳定性当作抗遗忘，也不重启旧固定容量专门训练结论。 |
| 学会了，但更新几乎不遗忘，或 ER 已解决问题 | 保留有效结果，停止为当前固定表示设定堆叠选择器；再判断本主线是否需要一个有依据的表示／到达条件变化。 | 小头结果不否定所有持续识别问题；没有新机制依据就不强行升级实验。 |
| 成组记忆优势来自正负比例、难度或额外训练 | 补齐直接匹配对照，或收窄为整个策略效果。 | 不把配额、困难样本或额外计算包装成共同锚点贡献。 |
| 发现实现或复现缺陷 | 先记下受影响结论，做最小修复和针对性验证，只重跑受影响的比较。 | 区分无效执行与有效负结果；前者按纪律清理，后者保留必要证据。 |

每次实质纠偏在当前计划／结果回执记录“发现—依据—受影响结论—调整—是否已看过相关结果”。不新增审批状态机；新科研边界或训练语义变化才做对应外审和最小实际核验。实现正确的负结果不按失败垃圾删除；不可恢复无效运行则先留必要小记录，再清理载荷和临时文件。

具体补充：低开发 AP 本身不是容量不足的证据；容量／日程调整应由训练侧拟合或正确性证据支撑。若已经查看方法排名后改变顺序、预算、学习率或主要对照，就作为新的探索变体记录，保留原结果，不能覆盖成原预定比较或独立确认。公开依赖修复也须形成在一个到达顺序内固定的派生输入：同一开发边的特征及预处理在所有阶段保持不变。若确需随阶段刷新开发表示，则是另一个涉及输入变化的问题，不能只归因于打分头遗忘。

## 现有数据能支持什么

现有合格中文训练／开发各 500 世界、14,000 账号、49,500 商品、189,000 账号对；每世界账号对结构固定。完整合成二值监督继续使用，真实中文样本少，不能把合成实验写成真实经营时间线或真实市场验证。Audit A/B 真值与既有盲预测保持原边界。

首先区分两种可做的实验：

1. **随机分批到达参照。**保持世界完整、原身份隔离和全部原始账号对，将 500 个训练世界按已冻结的三种顺序分为五批，每批 100 世界；全部 500 开发世界始终固定，不再任意配成新／旧域。只报告固定开发总体的阶段轨迹，不把五批同源随机样本称为五个不同域。
2. **可能的受控分布变化。**先仅盘点公开记录中是否存在有样本量支撑、可解释的商品类别或文本形式差异；若存在，才按一个预先说明的公开规则组织不同阶段，并在开发侧保留相应身份隔离的评价分布。规则不得利用标签、私有控制者、合成角色或未来结果选择“最容易遗忘”的顺序。若需基于全训练公开特征设计分组，要明确这是离线构建的受控基准，不能宣称整个设计过程也从未见过未来输入。没有合适差异就如实记录，不改造样本或增加失真学习率来制造结果。

两者不可混合报告。随机到达可以作参照，但若想研究跨分布保持，必须先证明阶段划分对应可观察的分布差异。暂不拆开一个世界内的账号或商品模拟逐条到达；旧公共频率／图特征可能依赖同一世界的其他账号，拆开后必须另行重算和核验，不能直接复制完整世界特征。

公开商品类别不同仍不保证模型所见的 57 项成对特征或判别条件不同，后续盘点应核对实际输入。固定表示只检查打分头的更新干扰：小头不遗忘不能排除编码器遗忘，出现退化也不能证明完整中文系统会同样退化。

数字是便于讨论的起点，尚非确认性合同。只选一种有依据的变化规则，不展开大量机制、顺序与预算矩阵。当前固定特征全量规模并不大，因此“小记忆库”是受控研究条件，不是假称本项目实际上已经无法存下历史数据。

## 最小实现草案

第一轮复用合格公开特征提取方式，固定表示，只训练一个小型共享账号对打分头，例如一层隐藏层的 MLP，输入 57 个公开成对特征，输出一个同控 logit。各阶段沿用同一模型参数及预先规定的优化器状态；不增加新卖家专属类别，不读取控制者 ID，也不把旧 M3 的完整训练结果当第一阶段初始化。

这是可行性参照，不是宣布 57 项特征足以支撑最终论文。旧 M3 的规则外能力弱且强公开规则占很大比例，可能使总体指标掩盖问题，必须保留全体与既有公开强规则外分层。不能只报告缓存里会背的正例，也不能据旧负结果再次启动已经停止的专门训练或迁移实验。

预处理遵守到达边界：新中位数／缩放参数从第一批可见训练数据拟合后固定，缺失列回退规则预定。旧 `step28_specialist.py` 的全训练中位数对原批量实验合法，但不能直接当作严格前瞻第一批统计量。本轮查阅 `step28_prepare_public_projection.py` 的 `reconstruct_frozen_english_reference` 和 `legacy18_row`，确认旧 legacy18 的 IDF／百分位来自冻结英文公开参照，不能误报为未来中文统计泄漏；如复用，应作为事先固定外部参照明示，而非重启英文监督迁移主张。identity33 的完整世界依赖和实际载入边界仍需使用前核验。

| 比较臂 | 作用 |
| --- | --- |
| 第一批后冻结 | 说明“不忘但也不学”的代价，避免仅靠少更新获得虚假优势。 |
| 普通继续训练 | 测实际遗忘、新知识获得及顺序敏感性。 |
| 随机 reservoir 重放（ER） | 核心简单参照，不先假定随机保留不够用。 |
| 正负分层随机重放 | 排除所谓关系选择增益只是缓存正例更多；各类配额须预定。 |
| DER++ 二分类适配 | 强重放参照，区分保留历史标签与保留旧输出的作用。 |
| 累计全历史重训 | 使用相同固定输入与模型容量的效果／成本参考，单列实际计算；不称数学上界。 |

首个小型可行性比较可先用冻结、继续训练、ER、累计重训四臂。在比较新选择器前再补正负分层 ER、DER++ 和最直接的 MIR；如果创新依赖梯度多样性，也应纳入 GSS，而非一次实现全部文献。

DER++ 适配预定为 `BCE_current + alpha * MSE(logit_memory, saved_logit) + beta * BCE_memory`。两项旧样本项分别抽样并计入重放总量；`saved_logit` 是对应原样本首次到达、当前参数更新前算得的固定标量目标，保存后不再反传或刷新。相同旧 batch 的变体若另行使用必须单独注明，不能声称逐项复现原算法。单标量保持不承载原多类别 logits 的类别间知识解释。超参数从可见训练内数据确定，方法间调参机会对称，不要求不同损失的系数相等。

首轮记忆预算为 512 KiB，包含必要特征、二值标签及采样元数据的未压缩序列化字节；模型／优化器及预处理另报。当前 ER 不存端点，不推断独立账号覆盖数；未来方法需要端点或旧 logits 时须计入。离线基准包装可以对齐全训练监督，训练供数只返回当前批，累计臂单独获得已到达前缀。增量训练不得通过全量特征、旧标签、历史检查点或无限增长索引绕过预算；当前批可多轮访问，工作集和暂存开销另报，不称单遍在线算法。开发集及科研归档不参与后续训练。

增量训练臂共用新样本序列、初始头及约定更新次数；新／旧配比只在有重放的对应臂之间比较，不套在冻结或无重放臂上。记录实际新／旧样本处理数、两次 DER++ 抽样、MIR 虚拟更新和候选筛选的额外计算与耗时。同更新次数只表示训练日程配对，不足以宣称等计算；若主张等计算优势，须另按共同计量口径比较。冻结臂固定全部评分状态，包括预处理和阈值。

累计重训定义为每阶段从同一个初始头和新优化器状态重新训练，仅可访问截至该阶段的全部历史，预处理仍与其他臂一致；它是允许超出增量预算的效果／成本参照，报告真实代价。若改为沿用上期参数，应另称累计历史微调。本草案不同时增设两种累计参照。

每条唯一账号对只在首次到达时触发一次 reservoir 入库机会，阶段内额外训练轮数不视为再次到达。组中重叠边以唯一 pair key 存一次，组索引占用也计入字节；重放重复次数与各边权重必须显式记录。后续成组候选首版只改变联合入选，缓存边统一按独立边重放；若另研究成组 batch，作为独立调度消融，不能和入库策略混为同一增量。

## 后续可能的方法增量

若有稳定遗忘且普通 ER 尚有明显不足，再试一个局部假设：**同一旧账号的“应当相连”正关系与“容易混淆但不应相连”负关系，成组保留是否比独立保存账号对更有效？**

例如已有完整训练标签支持 `(甲,乙)` 同控、`(甲,丙)` 异控时，缓存共同锚点的两条边，使更新同时看到该账号的正确关联与混淆边界。只用当时可见的训练端点和二值标签；不读取私有控制者表，不让账号 ID 进入预测头。首版维持同一二分类损失，只改变记忆选择，防止把损失、权重和采样一起修改后无法归因。

候选组只能由当前阶段的合法训练数据与仍在预算内的历史边构成；已删除旧边缺少正／负伙伴时，不能到历史文件补齐该账号的邻接关系或标签。组的必要索引与候选历史状态也须计入预算，不允许用无限增长的账号关系目录绕过记忆限制。

这目前只是候选，三元组／对比关系和困难负例本身均不是创新，旧 Step15 也已有成对排序训练。必须对照相同正负比例的随机独立边、随机成组边和 MIR，检验增量是否来自关系组合而非正例配额、重复更新或额外计算。当前每个世界是完整账号对图，端点度数相同，不能凭空假定存在严重热门账号采样偏置；若选择器没有可解释且可重复的增益，就不把它包装成方法贡献。

本地独立推导还限制了“成组”的含义：对于逐对 BCE，若缓存边集合和各边权重相同，完整重放目标 `sum_e w_e BCE(h(x_e), y_e)` 不会因把边称为一组而改变。分组只能先影响选中了哪些边、batch 内协方差或更新顺序，不能声称模型因此读到了额外关系信息。首版已统一独立边重放，不再重复运行同一边集合的等价副本；只有后续另引入成组 batch 调度，才需要同一边集合的独立调度对照来区分选择与调度作用。这不要求新增网络或损失，也不是否决一切记忆选择方法。

外审还提出一个有效归因补充：取消共同锚点要求的独立边参照，应匹配正负比例、负例难度和重放重复次数，并保持相同字节／计算口径。若这些不能有效匹配，结果最多归因于整个选择策略，不能单独归因为共同锚点。此要求只约束未来方法主张，不阻断当前四臂可行性研究。

## 评价与继续条件

逐阶段保存模型在固定开发账号对／候选库上的完整分数，形成 `R[t,j]`：第 t 次更新后在第 j 个预定开发分组上的世界等权 AP。同时给出阶段内学习前后改善、旧分组变化、最终整体性能和处理成本。开发对象不与训练身份重叠，不把记忆样本训练精度当成主要评价。

每个到达种子 r 保存“阶段—训练组—开发组”映射。存在有意义的分布组时，`R^(r)[t,j]` 的 j 是该顺序第 j 个到达组及其对应开发组的位次；域组换序后开发列同步映射，不能仍用固定原组号套对角线。补存尚未优化头的 `R^(r)[0,j]`，用于第一阶段更新前后比较。仅随机分批时开发随机子集没有天然的新／旧域对应，主要报告固定全开发集的阶段轨迹；不能把随意配对的对角线增量叫作新分布学习。

分布组不等大时，最终总体逐世界 AP 为 `sum_j n_j * R[T,j] / sum_j n_j`，n_j 是相应开发世界数；下述 BWT／F 则是组等权汇总，分开命名和解释。方法间在每一顺序使用相同映射、相同分母和固定候选库。一个预定比较的所有阶段分数及必要重载检查完成后，由独立评价器读取开发二值标签构造指标；训练器不根据中途开发轨迹调整方法或日程。检索相关关系可从已对齐的开发二值账号对构造，不为本计划读取私有控制者或启封 Audit 资产。

若 j 对应有效的不同分布，报告 `BWT = mean_j(R[T,j] - R[j,j])`（j<T）及 `F = mean_j(max_{j<=t<T} R[t,j] - R[T,j])`，保留符号并解释正反向迁移；如果只是同分布随机组，则按受控开发子集轨迹解释，不用公式名字制造“任务切换”事实。少忘必须与新数据学习共同展示，不能仅挑 F 最小者。

AP 与梯形 PR-AUC 分开，补齐 MRR、MAP、Recall@1/3/5/10、NDCG@1/3/5/10 及原合同其余分类／阈值指标。成对头以 logit 排序、sigmoid 概率评价；旧迁移原始余弦合同不变。首轮所有臂／阶段统一使用未拟合的 logit≥0（概率≥0.5），不读取开发真值选择阈值。经验 FPR≤1% recall 另列为曲线诊断。候选库始终固定，新增竞争者造成的排名下降不算作遗忘。

不以任意百分比许诺继续：先判断基础头是否学到识别能力，继续训练是否有超过随机波动的旧分布退化，以及 ER 是否以合理成本改善旧／新折中；新采样器再与强参照比较。世界作为配对重采样单元，区间条件于已经训练的模型和预定顺序，不能涵盖全部训练随机性；到达顺序逐一报告，三个顺序不足以声称覆盖任意实际顺序，不因此扩充无根据的种子矩阵。当前开发集已被反复分析，新结果先作为探索性证据；后续确认性评价须另行明确冻结边界，不能自动启封 Audit A/B。
