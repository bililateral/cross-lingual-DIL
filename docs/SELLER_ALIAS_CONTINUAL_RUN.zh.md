## 数据可见范围与历史记忆

原 V9.4.1 训练／开发各 500 个完整 K28 世界，固定 57 维公开特征，种子 11／23／37 各自使用已经保存的随机 5×100 世界到达顺序。公开哈希和阶段 1 的行键／完整世界证据沿用；本轮不重新运行解析器、编码器或合成器。

**离线基准包装与方法可见输入分开解释。**正式运行开始时，基准包装读取一次已授权的训练 `pair_labels.csv`，与训练公开行键逐行核对，要求各世界仍为 20 正／358 负；形成临时、按原行序保存的 uint8 标签数组。包装器可以处理全部训练监督，它不拟合模型、选到达顺序或调整规则。不能将整个离线包装过程声称为从未读取未来训练标签。

随后供数器只返回当前阶段世界的特征／标签；累计重训臂单独请求截至当期的前缀。每次按世界选行后即关闭 mmap，供数对象不保留完整特征或标签矩阵；每阶段用完当前工作集即释放。已到达前缀的数据只传给累计臂的拟合调用，不传给继续训练／ER。记录实际世界序列、行数和访问用途，独立评价前重新核对。原始数据及离线临时数组是基准数据源，不是算法可任意回查的历史缓存；这里依靠明确代码与合同检查，不另建进程／文件系统隔离机制。

ER 每条唯一新边在本阶段所有 epoch 结束后只获得一次入库机会；当前批训练时只从此前缓存重放，选择与抽样随机流保持独立。容量为 2,284 条，每条为 57 个 float32＋1 个 uint8 标签；实际未压缩 NPY、两个 RNG 的 JSON 状态与元数据之和必须不超过 512 KiB。模型、Adam、首批预处理、当前临时工作集和整个进程峰值另报。ER 不保存端点 ID，因此本轮不推断缓存覆盖的独立账号数；后续关系选择若需要端点，必须纳入对应预算。

临时训练标签文件在运行退出时删除；ER 的含标签状态只在临时目录做磁盘与下一次抽样核验，随即删除，不放进公开结果目录。公开归档保留模型／优化器、无标签分数、必要训练统计、缓存大小和散列。归档不参与后续增量训练，也不在比较中通过历史检查点读取已丢弃样本。开发标签、qrels、Audit A/B 从不传给训练器；评价只在最终成功清单与全部分数／检查点完整性核对后读取开发二值标签，检索相关性直接由其构造，不读取 qrels。

## 首轮日程与成本

三种到达顺序分别拟合自身的首批中位数、均值和总体标准差，之后固定。头为 57→32→1、ReLU，初始化种子 20260907；Adam 学习率 0.001、betas=(0.9,0.999)、epsilon=1e-8，无权重衰减，关闭 foreach。

| 臂 | 每阶段实际输入与更新 | 状态继承 |
| --- | --- | --- |
| 冻结 | 共享首阶段后不再拟合，始终引用同一个开发分数和检查点。 | 所有评分状态固定。 |
| 继续训练 | 当前 100 世界，5 遍，batch 256，保留尾批。 | 共用首阶段权重及完整 Adam 状态。 |
| ER | 与继续训练相同当前批顺序；每次另抽至多 256 历史边，缓存内无放回。当前 BCE 均值＋历史 BCE 均值，权重各 1。 | 共用首阶段权重／Adam；缓存只在阶段结束更新一次。 |
| 累计重训 | 截至当期的全部世界重新训练 5 遍，batch 256，保留尾批；固定首批预处理。 | 每阶段从相同原始初始化和空 Adam 状态重新开始。 |

每个顺序首阶段只物理拟合一次，四臂都计入该共同成本；此后冻结臂计零。阶段当前批 37,800 对，继续训练和 ER 每阶段各 740 次更新、189,000 次当前呈现；ER 从第二阶段起另有 189,440 次历史呈现。尾批仍维持两个 BCE 均值各权重 1，不能误解释为拼接后的均值。

累计臂每阶段分别为 740／1,480／2,215／2,955／3,695 次更新，单列新到达与旧到达的呈现次数。三顺序共享首阶段避免重复计算后，正式比较实际总计 51,015 次优化器更新。另记录训练前／后当前批或累计前缀的 AP、BCE 诊断与额外前向呈现次数；这些只是训练侧拟合检查，不用于早停、调参或选择结果。拟合耗时包含这些诊断，整体运行耗时还包含供数、保存、重载和开发无标签评分。更新次数相同不等于计算相同，累计臂不是数学上界。

阶段 0 保存首批预处理已经拟合、头尚未优化时的开发分数。每顺序实际保存 14 份独立模型／分数：阶段 0、共享阶段 1，以及三种更新臂的阶段 2–5；冻结阶段共用阶段 1 记录，总共 42 份，不重复保存等价载荷。

## 评价定义

只评价固定的全部 500 开发世界。随机训练批次没有天然的新／旧开发域对应，故不另分开发子集，不构造域级 BWT／F，也不将阶段编号当作真实时间。报告每个顺序、每阶段完整轨迹，预定 0→1、1→5、0→5 和各相邻阶段的固定开发集变化。

主要总体量是最终世界等权 AP，主要四臂参照为 ER−继续训练；另预定继续训练−冻结、累计重训−继续训练和 ER−累计重训。正负方向直接按名称相减，不从结果选择最弱对手。AP 与梯形 PR-AUC 分开；还报告 ROC-AUC、Brier、裁剪概率 log loss、经验 FPR≤1% recall、原始混淆矩阵、precision／recall／F1／specificity／balanced accuracy／MCC，以及 MAP、MRR、Recall@1/3/5/10、NDCG@1/3/5/10。

排序一律使用原始 logit，同分分类曲线按整组处理；检索在原固定 K28 候选库上，按分数降序、候选公开 ID 的 UTF-8 升序解同分。概率由 sigmoid 取得，只用于概率指标。**首轮不拟合阈值，所有臂／阶段包括阶段 0 统一使用 logit≥0（概率≥0.5）。**这是在项目标签读取前补清的固定规则；不会根据开发集选择阈值。经验 FPR≤1% recall 仅为有标签样本的诊断曲线，不是提前冻结的可部署阈值。

同时保留 pooled 指标、逐世界指标及其等权均值。阈值另报告“世界内归一混淆再聚合”的指标，区分它与逐世界 F1 等指标的均值。规则外分层沿用原公开定义：identity33 的第 0 列直接线索和第 19 列强旋转线索均不大于零；分层只用于分类诊断，不调整训练输入或检索候选库。

预定 bootstrap 种子 20260907、2,000 次，三个固定到达顺序逐一报告。合并区间先对同一世界的三个顺序差值取均值，再同步重采样 500 个世界；不能把三个顺序×500 世界当作 1,500 个独立样本。95% 配对区间只计算总体 AP 和规则外 AP，其余指标完整描述性报告，不声称全部指标均做了区间推断。区间只覆盖给定模型与顺序下的评价抽样变化，不覆盖所有训练随机性。开发集已多次消费，全部结论为探索性合成域证据，不替代独立确认或真实市场效果。
