## 2. 失败结果

审计结论为 `DATASET_INVALIDATED`，失败阶段为 `text_counterfactual_probe`，原因码为 `DATASET_GATE_OR_ROW_CONTRACT_FAILED`。元数据捷径审计与文本反事实审计均未通过。

- 元数据单特征最大值为 `absdiff__seller_uid_digest_02`，对称受试者工作特征曲线下面积为 `0.5220111731843576`，超过冻结上限 `0.52`。这足以按事前合同判废 v7 数据，但单独不能证明编号生成器存在确定性标签耦合：质量门对完整特征家族取最大值，50 个开发世界下的有限样本和多重比较也可能产生该数值。不能通过删除该审计特征、事后挑选编号排列或放宽阈值解决。
- 文本审计中最大的单特征为 `fs_full::ascii_whitespace_count_absdiff__slot_description_mean`，对称曲线下面积为 `0.5198248863636363`，没有单独超过 `0.52`。文本审计整体仍失败，但 v7 最小失败回执只保留完整文本结果的规范哈希 `8bc59d631b24b75ffd7ed0393532f6c0ae4d11e1f4113869a7e66b7efe7ce324`，没有保留十四模型点估计、平均精确率提升和两个 95% 自举上界的诊断标量。因此不能事后声称空白字符单特征就是文本失败的充分根因；具体是哪一道文本硬门失败在 v7 证据边界内不可恢复。

本轮结果只能证明该 104 世界设计数据不合格，不证明当前生成机制的任意后继版本必然失败，也不构成正式中文数据、模型效果或真实地下市场泛化结论。

## 4. 后继修复边界

后继版本必须使用新版本、新输出根和新的事前冻结随机权威，且不得枚举多个随机盐后挑选通过者。允许修复的是生成机制和失败证据的诊断充分性：

1. 先用与实际特征数、正负结构、训练／开发分工、十四模型及重抽样门同构的零信号校准器，事前选择能把误拒率压到冻结上限以内的设计世界数。不得用多个真实数据盐试跑后选择世界数或结果。
2. 独立审查编号生成调用链。当前卖家编号来自 `id_key`，控制者分组来自不同的 `structure_key`；在没有进一步因果反例前，不得追着 `seller_uid_digest_02` 事后重编号。编号捷径探针必须保留。
3. 将描述空白字符信号作为待验证线索，而不是既定根因。只有用生成器级反例证明排版变量与控制者关系存在非任务所需耦合后，才允许解耦；不能以统一清洗全部空白的方式制造不自然文本或抹去任务信息。
4. 失败回执必须保留每个预注册硬门的少量诊断标量、最大项名称和规范哈希，使失败可解释，同时继续禁止保存完整预测、标签或大载荷。
5. 冻结的质量阈值、七视图、十四探针、审核盲边界和 9,999 次按世界重抽样不得因本次失败而放宽。世界数属于运行前设计功效参数，可在零信号校准后随新版本事前增加。新设计数据必须先通过完整回归和新的科研复审，才可运行一次新的设计级质量审计。

## 5. 事后方法诊断（不构成 v8 预注册）

为判断 `0.522011` 更像确定性耦合还是小样本多重比较，清理完成后运行了不读取 v7 数据的纯内存简化零信号模拟。每个世界只复现 28 个卖家、4 个三卖家控制者、8 个二卖家控制者和完整 378 对；64 个代理特征均独立于控制者标签。50 个世界下 300 次模拟的最大单特征对称曲线下面积中位数为 `0.521694`，95% 分位数为 `0.530085`，`66.3%` 超过 `0.52`。200 个世界下 200 次模拟中没有一次超过 `0.52`，最大观测为 `0.517605`。

这项模拟证明原 50 世界“全家族最大值不超过 0.52”门可能具有很高的零信号误拒率，但它只用了 64 个独立代理，没有复现真实 67 项元数据的相关结构、十四模型拟合和 9,999 次重抽样，不能直接认证 200 世界或改变阈值。v8 必须把完全同构的校准器、随机种子、候选世界数、重复次数和允许误拒率先写入新合同，再决定设计规模。

在新的设计级数据通过全部门以前，正式 500×4 生成和 M0/M1/M2/M3 训练继续禁止。
