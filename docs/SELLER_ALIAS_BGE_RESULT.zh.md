## 3 训练和评价的对象

本轮训练对象是**中文合成卖家账号的同控候选排序模型**。输入只有屏蔽标题与描述，编码器为中文 BGE，使用标题／描述分通道均值与总体标准差及对称关系头。每个群28账号、378个无向账号对；每查询在其余27账号中排序，有1或2个同控候选。不同域的新卖家群体依次到达，评价旧域留出卖家的保持能力，不追踪同一控制者跨阶段新开账号。

每域48拟合群、12当前域校准群和20 valid群。三种顺序为 ABC、BCA、CAB，仅一个训练种子s0；每个顺序从原始中文预训练模型和相同种子随机头开始，**没有把已联合学过三域的历史模型当首域初态**。首域实际模型／Adam／RNG共享后分支。

| 路径 | 后续两个阶段的操作 |
|---|---|
| frozen | 首域训练后固定模型及首映射；用于显示不继续学习的表现 |
| SEQ | 只用当前域监督继续训练 |
| ER | 当前群监督加一个随机历史群监督；保留最多6个完整拟合群 |
| LOGIT | 在ER相同成员、相同抽取序列上，加0.5×历史378个raw logit的平均平方差 |

各阶段6轮、288次Adam更新。当前／历史目标均为 BCE＋查询排序损失＋0.5×困难负例损失，各群单独归约后累积梯度，只clip一次并更新一次。ER／LOGIT有额外历史前后向，所以与SEQ不是相同计算量；ER与LOGIT的监督群及更新数配对。编码器阶段局部29步warmup后线性降至0，头学习率0.001，Adam计数连续。实际21点都记录了原生模型／Adam／RNG保存恢复核对。

每个实际点只用当前域12群拟合正斜率仿射校准：`p = sigmoid(a × raw_logit + b)`，`a > 0`。原始分数用于排序和AP/AUC；主概率指标用当阶段校准；固定首映射只作诊断，不能根据结果选择有利角色。正斜率保证保留原来的排序，本次独立检查了全部2520个群级校准顺序及并列关系。

## 4 判据与统计单位

记 `R(t,j)` 为学完第t阶段后在第j个到达域上的群宏指标：

- **O，最终旧域**：`(R(3,1)+R(3,2))/2`。
- **N，新域刚学完**：`(R(2,2)+R(3,3))/2`。
- **Z，最终最新域**：`R(3,3)`，单独保护，不能被N平均掩盖。
- 首域遗忘：`R(1,1)-R(3,1)`；新域学习增益G：`[(R(2,2)-R(1,2))+(R(3,3)-R(2,3))]/2`。
- 最终全域：`(2O+Z)/3`。Brier／log_loss的遗忘和学习增益符号按合同反转，使遗忘正值表示变差。

以上再对三个顺序平均。三顺序复用同60个valid群，不能当180个独立群；5000次抽样按实际A/B/C各20群配对，PCG64种子20260930。区间条件于这一种子、模型、映射、开发数据及三个顺序，不包括重新训练不确定性，也不是总体非劣效保证。

正式比较只有ER−SEQ与LOGIT−ER。各23项条件保护O／N／Z的MAP、Recall@5、AP、AUC、Brier、log_loss及相对原始参考的概率损失，详见 [冻结合同第7—8节](SELLER_ALIAS_BGE_CONTINUAL.zh.md)。下文LOGIT−SEQ只用于清楚解释绝对表现，不新增事后正式验收或改写原判据。首轮没有沿用旧基础改进的“MAP至少+0.01”线。

## 7 结果透露的机制线索

### 7.1 历史记忆很少，而且可能失去整个旧域的样本

第三阶段开始时，ER／LOGIT相同6群的域构成为：ABC是A4＋B2；BCA是B2＋C4；CAB是A6、C0。对应288次历史呈现分别为A191/B97、B95/C193、A288/C0。这里是模型无关Algorithm R的既定随机结果，不是事后筛选；CAB确有首域样本被全部淘汰，但不能仅凭这一项解释所有退化——ABC、BCA也存在ER退化。

每阶段当前48群各出现6次，历史6群平均各出现48次；本次实际单历史群出现34—63次。ER最后一轮的历史组合损失仅约0.397—0.579，而当前组合损失约1.724—2.873。**少量缓存重复训练后对缓存拟合很好、对旧域留出卖家保持不好，是与缓存过拟合相容的证据；尚不能单独确定因果。** 对历史样本代表性、重复强度、当前与历史目标的作用需要后续受控比较。

LOGIT限制历史输出变化，改善了ER的旧域和新域表现；但它也可能约束当前学习。相对SEQ的新域损失表明，后续研究必须把“记住旧域”和“仍学得动新域”一起解决，不能只加强保持项并预言必然改进。

### 7.2 校准有效，固定0.5阈值仍不是可用的自动判定工作点

例如O端点：SEQ原始log_loss 0.225775，经当前域校准为0.184187；ER 0.275197→0.192677；LOGIT 0.235852→0.182699。固定首映射分别为0.220800、0.228706、0.199285，说明旧映射在后续模型上不能当然保持良好校准。这些都是已存结果诊断，没有新增拟合。

最终全域的固定0.5阈值群宏召回：SEQ 0.064444、ER 0、LOGIT 0.030278。ER最终校准分数全部低于0，确实没有正预测，不能省略这一现象或用高specificity掩盖。候选排序的Recall@5分别为0.562004、0.497619、0.545040，与二分类固定阈值召回是不同任务。校准按未加权NLL拟合，而非优化0.5召回；这些结果不授权调整阈值、重拟合或改验收。

### 7.3 外审补充：梯度裁剪频率

外审独立训练账参考从保存更新数组统计：6048次更新中6030次总范数超过冻结阈值1.0；后两阶段5184次全部超过。主执行者已核对原第13列、clip调用、参考实现及实际日志和汇总。该结果支持进一步研究当前／历史／MSE的组合优化，但总范数不能给出分量方向或Adam实际更新，不能据此认定梯度冲突、唯一因果或调大clip必然有效。它不改变本轮验收。
