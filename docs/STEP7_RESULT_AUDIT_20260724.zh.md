# Step 7-v4 正式结果与数值修复审计

更新时间：2026-07-24

## 0. M0 角色解释

当前 Step 7 → Step 28 的 M0 是只用真实英文马甲标签训练和选择、随后冻结的完整英文来源分类流水线。编码器是否相对无编码器对照提供显著增量，是单独的归因消融，不是 M0 资格条件。本文正式结果字节不变；凡出现“编码器型 M0”或将编码器增量写成 M0 门槛的旧表述，均按 `docs/STEP7_STEP28_M0_ROLE_DEFINITION_20260724.zh.md` 纠正解释。

## 1. 数值故障及修复

Linux GPU 编码已经完整结束；失败发生在复用冻结特征的 CPU 逻辑回归选择阶段。报错中的 `24.700000000000006` 只是十进制 `24.7` 的正常二进制浮点显示，不是 L2 被截断或网格漂移。真正原因是：参数已接近最优点时，候选 Newton 步造成的目标函数变化小于 float64 可分辨尺度，Armijo 比较无法再区分下降，但旧求解器仍要求归一化梯度严格不大于 `1e-9`，于是把 `1.026485e-9` 的近边界状态错误耗尽为“不收敛”。

修复只替换数值求解器，不修改数据、特征、标签、候选、L2 网格、阈值或选择指标，也不重新编码 GPU 特征。目标函数变化落入明确计算的 float64 分辨尺度时，只有完整 Newton 步能使重新计算的解析梯度严格下降，才允许跨过 Armijo 的舍入平台；真实不收敛仍然立即失败。

正式复跑共执行 `32,423` 次逻辑回归拟合：

- 全部拟合均以原定 `normalized_gradient <= 1e-9` 通过；
- 最大最终归一化梯度为 `9.998840729744745e-10`；
- `70` 次拟合各使用一次上述 float64 分辨率 Newton 步；
- 放宽式“数值驻点兜底”使用次数为 `0`；
- 最大迭代数为 `22`。

因此，本轮结果不是把失败阈值改松后制造的“成功”。

## 2. 正式输入与编码结果

- train：`401 = 116 正 + 285 负`；旧 valid：`151 = 42 正 + 109 负`。
- 有效原始商品 `109,756` 条，形成 `33,434` 个唯一清洗文本。
- 共享分块共 `41,808` 块；`4,226` 个文本需要分块，最多 `23` 块。
- 四个模型接收完全相同的块；所有文本逐字符可重建，四个 tokenizer 的超预算块均为 `0`。
- PCM、mStyleDistance、E5、LaBSE 均在同一 RTX 5090、PyTorch `2.9.1+cu130`、cuDNN `9.13` 确定性配置下完成冻结编码。

## 3. 选择结果

训练集预注册主口径第一名是 `fusion__legacy_e5_stylometry`，即 `legacy18 + E5 六项聚合 + stylometry22`。其重复嵌套 OOF 指标为：

| 口径 | ROC-AUC | AP | F1 | Precision | Recall | Balanced Accuracy |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| pair 等权 | 0.8201 | 0.7093 | 0.6263 | 0.7561 | 0.5345 | 0.7322 |
| 连通分量等权 | 0.9562 | 0.8643 | 0.8236 | 0.7538 | 0.9075 | 0.9134 |

但它没有通过完整流水线稳定性门槛：

- 次优项是仅含 `legacy18` 的对照；主 AP 差仅 `+0.000939`，分量 bootstrap 95% 区间为 `[-0.042559, 0.040733]`。
- 同时超过全部 21 个对手的 bootstrap 概率仅 `0.395`，要求为 `0.95`。
- 五个外层种子的赢家依次为：E5 融合、legacy18、E5 融合、E5 融合、LaBSE 融合；总体第一名胜率恰为 `0.60`。
- 去掉任一方存在完全相同清洗标题或描述的 pair 后，只剩 `286 = 27 正 + 259 负`。原赢家降至第 `9`，五个种子胜率为 `0`；相对全部候选的最小差为 `-0.076027`，95% 区间 `[-0.245964, -0.004058]`。

因此，总体第一名依赖当前克隆丰富的数据结构，不能冻结为 M0。这里的直接原因是完整流水线排序不稳定，不是编码器增量未显著超过对照。

## 4. 编码器与作者风格结论

严格匹配的“编码器六项 + 同一 stylometry22”比较中，E5 暂列第一，但同时超过 PCM、mStyleDistance、LaBSE 的概率只有 `0.78`，低于 `0.95`，95% 最小差区间跨 0。预注册作者风格候选 `PCM + mStyleDistance + stylometry22` 相对仅 stylometry 的 AP 增量为 `+0.04835`，95% 区间跨 0；它相对最佳纯语义对照 E5 反而为 `-0.08232`，95% 区间 `[-0.16057, -0.00879]`。本轮既没有证明唯一最强编码器，也没有证明 Step24 风格编码器提供稳定增量。这只限制编码器/风格贡献表述，不会单独取消一套完整流水线的 M0 候选资格。

旧 valid 只作锁后诊断，不能参与选择。总体第一名在其上的 pair 等权 ROC-AUC/AP 为 `0.6077/0.5103`，低于 `legacy18` 的 `0.6442/0.6272`，再次显示排序不稳定。历史 test 标签未读取。

## 5. 根因与科研结论

train 中一个连通分量独占 `93` 条 pair（`66 正 + 27 负`），其余四折各约 `77` 条、`56–58` 个分量。分量隔离本身没有泄漏，但这个超大分量在每个种子中都只能整体留出；重复种子无法创造新的独立正向身份分量。去克隆后更严重：一个分量含 `40` 条（`20 正 + 20 负`），其他四折分别只有 `1–2` 个正例。pair 等权与分量等权指标的大幅分歧正是该不均衡结构的表现，不能挑较高口径宣称成功。

正式结论固定为：

> `no_stable_unique_provisional_m0`

继续在同一 `401` 条 train 和已反复查看的旧 valid 上改候选或调参，只会增加选择偏差。若仍需正式 M0，下一步必须补充新的真实英文确认数据，重点增加互不连通、无完整文本克隆的正向身份关系，并在数据收集前冻结完整流水线候选和评价合同。确认集选择的是完整英文来源模型；编码器增量另作消融。
