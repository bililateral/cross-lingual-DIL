权重含义为`当前BCE + α×历史BCE + β×历史logit MSE`，当前项始终为1。9月15日原基线为(1,.5)；(.5,.5)是9月16日预先批准、此次完成的敏感性配置，没有在该批准配置上再次改权重。(.5,.5)仅在已测三个配置中具有最高首域AP点估计，(1,.25)的新域差值较好；没有预定的综合效用或自动赢家，不能宣布(.5,.5)综合最优。
