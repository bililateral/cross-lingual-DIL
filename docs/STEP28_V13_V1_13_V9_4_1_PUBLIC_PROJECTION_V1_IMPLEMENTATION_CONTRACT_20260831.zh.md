## 3. 基础侧三段式隔离

基础投影必须拆成三个阶段：

1. 公开侧中央处理器预处理：验证正式根，按世界和卖家对固定顺序写出行键与
   legacy18；从去身份商品标题和描述建立无标签文本工作量；
2. 隔离 Linux 图形处理器编码：工作区只含不透明文本编号与文本、不透明卖家
   编号、不透明卖家对编号、冻结分块代码和四个模型载荷。工作区不得包含拆分名、
   规范世界／卖家／商品编号、卖家资料、legacy18、identity33、标签、控制者、
   成员关系、检索相关性或任何审核真值；
3. 公开侧中央处理器回收：只按预先冻结的行序接收六项 LaBSE 数值，验证返回包和
   行数后，与 legacy18 合并为 base24，再调用冻结 M0、C0 输出无标签概率。

图形处理器工作区只使用一份独立的最小机器政策：它只登记不透明分片
编号、公开文本字段、计数、特征算法、运行环境、模型载荷和返回格式。包含
训练／开发／审核拆分名和正式数据路径的完整公开投影政策，以及该政策的
解析器，均不得复制到图形处理器工作区。一次性授权必须同时钉死完整政策与
最小机器政策，中央处理器转运清单必须交叉登记两者的规范摘要。

图形处理器返回包不得携带文本、块向量或模型参数副本；长期只保留六项聚合分数
及其清单。分块和块向量是临时产物，成功或失败均删除。任一拆分失败时，不发布
半成品；记录具名失败边界后删除本次临时工作区和未完成输出。

## 4. 固定特征语义

legacy18 必须使用冻结英文 401 对训练侧卖家重建的文档频率和八项数值参考，
中文训练或开发数据不得重估参考。卖家资料字段、拆分、归一化、去重和排序规则
逐字沿用模型实验 V1 与共享 base24 V2 实现。

LaBSE 六项只从去身份商品标题和描述构造。完整文本由 Step7-v4 四分词器共同
约束分块：包括前缀和特殊词元在内最多 256 词元、零重叠、不设块数上限、不抽样、
不丢弃。每块编码后归一化；同一去重文本的块向量等权平均再归一化；卖家内去重
文本等权；标题和描述分别计算质心余弦和双向最高三项均值，再计算字段等权值。
六项先按十二位小数序列化，再解析为小端双精度；缺失值为规范 NaN，正负无穷
禁止。M0 与 M3-base 必须复用同一份填补前 base24，禁止分别重算。
