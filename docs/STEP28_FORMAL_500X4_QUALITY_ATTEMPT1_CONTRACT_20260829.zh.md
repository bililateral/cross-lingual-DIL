## 1. 目的与权限边界

本合同只规定已成功构建的 V9.4.1 正式中文合成数据根如何取得训练资格。它不授权读取审核甲、审核乙的标签、控制者关系或检索相关性，也不授权计算 M0 输入或训练、调参、评估 M0、五个 M1、M2、M3-base、M3-joint。

当前只允许实现、测试、只读预检和独立审查。完整质量审计必须在实现提交、推送并取得一次性审计授权后运行一次。

## 3. 无真值阶段

在读取训练或开发监督以前，必须完成：

1. 用正式调度密钥重建四组各 500 世界，核对四组调度承诺；进入文本特征链前立即丢弃控制者分组，只保留分割名、世界序号、卖家标识和噪声槽；
2. 逐行核验四组全部公开行的精确字段顺序、数量、世界／卖家／商品／卖家对连接、完整图卖家对键集、三十三维身份行键集及有限数值；公开商品的标题、描述以及卖家档案中五个模型可见字符串字段都必须进入可读性、非法字符、未展开模板、真实来源逐字复制和内部标识泄漏扫描；
3. 由隔离扫描器检查训练、开发、审核甲、审核乙四组全部非监督私有身份计划、生成审计和匿名解析记录，只返回计数、真假值和摘要；逐世界验证八类身份齐全、六个登记负例完整，并通过解析器匿名世界摘要把身份计划的值摘要集合与实际解析结果逐世界闭合。三十三维身份是否激活必须直接从模型可见的实际三十三维行重算，再与生成审计计数核对，不能只信私有摘要。公开世界、卖家、商品和卖家对的完整注册表都必须进入内部标识精确扫描，不能只登记身份商品或六个负对照。该阶段禁止打开成员关系、卖家对标签和检索相关性，不返回任何私有值、关系或命中行；
4. 对四组全部 2,000 世界重放十四维公开结构投影；
5. 只为训练和开发构造并只读冻结七个原始文本视图、七个作者风格错排反事实视图以及两张三十三维身份矩阵；原始公开商品必须重新走一次生产解析器、身份历史构造器和三十三维身份构造器，并与持久化结果闭合；反事实商品再独立走同一完整链并保持三十三维身份不变；整条链必须再独立重放一次。卖家档案路径必须由独立于档案聚合器的贡献血缘重建器，从商品来源集合重新计算每个候选片段的支持商品、首次位置、跨卖家文档频率及其卖家集合，并与档案输出逐项核对。

作者风格错排必须是卖家全集到自身的严格双射、无固定点、定义域和值域都与本世界 28 个卖家完全相同。每名卖家的风格必须以已登记原型为底座，恰好声明两个不同字段发生变化；实际变化字段必须与声明完全相同，且变化值必须是冻结取值域中的下一项。

## 4. 监督阶段和硬门

矩阵冻结后，训练和开发的成员关系、卖家对标签、检索相关性各只读一次，并与正式调度独立重建结果逐行、逐序核对。审核甲乙语义读取必须保持为零。

文本捷径门沿用质量审计 C 修订件：七个视图各使用固定二范数逻辑回归和深度二浅树，共十四个模型；另检查三百四十六个单特征和 9,999 次按开发世界重抽样的家族最大值。门限固定为：单特征对称曲线下面积不高于 0.52；十四模型最大值不高于 0.53；平均精确率提升不高于 0.01；重抽样九十五分位上界分别不高于 0.53 和 0.015。三十三维身份正对照须达到曲线下面积至少 0.65、平均精确率至少 0.15。

同时必须通过根与载荷闭合、全部可见行质量、封存字面零泄漏、真实来源零逐字复制、正式公开投影精确重放、作者风格干预有效、路径和行序等价、八类身份齐全、每世界六个登记负例及身份特征非退化等机械门。

## 5. 终态与失败纪律

全部硬门通过时，唯一允许的状态为 `PASSED_FORMAL_500X4_ROOT_QUALITY_TRAINING_QUALIFIED`：`training_qualified=true`，但 `m0_m1_m2_m3_training_authorized=false`，模型训练仍需后继独立合同和授权。

完整证据证明任一硬门失败时，正式根失效；先记录失败门、关键摘要和声明边界，再删除失效数据载荷及本次专用代码。早期公开结构、可读性、密封泄漏、真实来源复制或公开重放门一旦完整返回失败，必须立即固定失败门和回执摘要并停止后续矩阵或模型计算，后继机械异常不得把它洗成“无数据结论”。已经通过根清单校验、但其内部字段、连接、重放或监督核对违反冻结数据合同时，必须记为具名数据硬门失败，不能伪装成执行器故障；只有被明确标成“持久化输入证据”的验证器异常才可直接转成数据硬门，普通数值错误或审计器异常不得自动改判数据失败。完整硬门结果已经形成后即使结果发布再发生异常，也必须用结果规范摘要和失败门列表保留数据失效结论，不能降级为无数据结论。执行器自身在完整证据形成前机械失败时，状态只能是 `AUDITOR_EXECUTION_FAILED_NO_DATASET_CONCLUSION`；删除临时矩阵和失败输出中的无价值载荷，保留正式输入根，使用新版本与新授权修复，不得重用本次尝试。无论成功或失败，临时矩阵的实际删除必须先于科研终态发布；若临时矩阵或失败输出根的删除本身失败，只能生成 `CLEANUP_PENDING_NO_SCIENTIFIC_TERMINAL` 非终态回执，回执必须分别绑定原始异常和实际清理异常；若原始异常已经是具名早期数据硬门失败，还必须显式保存失败门和该门的证据摘要；若完整失败结果已经形成，还必须保存其结果摘要、状态和失败门列表，禁止生成成功或失效终态。结果文件成功落盘后，控制台输出失败不得删除或改变已经发布的科研结果。
