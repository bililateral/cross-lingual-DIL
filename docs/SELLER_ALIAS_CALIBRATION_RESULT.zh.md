## 2. 怎么校准，为什么这样校准

原模型为每一对账号输出一个分数`z`，原概率为`sigmoid(z)`。本轮在模型后面接一个小映射：

`p_cal = 1 / (1 + exp(-(a*z+b)))`，其中`a>0`。

`a`调节分数尺度，`b`调节整体偏移；这两个值由数据拟合，而非手工挑出。以固定送测s0的C为例，实际得到`a=0.8478783321`、`b=0.5312823708`。同一模型的所有群、账号对共同使用这一组参数，没有按查询或类别分别拟合。

具体流程：

1. 固定原A/C第6轮、三个预定种子及其保存分数，共六个模型。36个训练内校准群此前未参加编码器梯度更新，但用过阈值诊断，因此不能称全新独立数据。
2. 每个模型使用同样13,608对的合成二值同控标签拟合。保留720正对和12,888负对的原比例；不把正负样本重加权为一比一。144个原编码器拟合群不用于本次优化。
3. 从`a=1,b=0`开始，以float64的L-BFGS-B优化平均二元负对数似然，即未截断BCE。只训练两个参数，既不反传编码器，也不更新评分头。Brier没有被直接优化，仍须另外检查。
4. 六组参数及分数全部保存、恢复并核对来源后，才统一读取valid评价；valid没有参与拟合参数或选模型。train／valid标签各只解析一次，test未读。
5. C与同样校准后的A公平比较，同时保护相对原始A的概率损失。这样不会仅因加工C或把对照变差而宣称成功。

这样设计有三个具体原因。首先，上轮C已有排序收益，而Brier／log_loss退化，值得检验分数到概率的映射能否修复这一部分；现有结果不能证明原退化全部来自某一种机制。其次，正斜率使`z1>z2`时仍有`a*z1+b>a*z2+b`，因此保留相对先后；实际实现还核对浮点顺序与并列，并以logit排序，避免极端概率饱和造成新并列。最后，两参数分别允许调整尺度和零点；只改分类阈值无法降低Brier／log_loss，只调正温度不能平移零点。

这并不保证任意新数据上都能改善概率。本轮通过说明此简单映射在当前valid上有效；推广性仍需独立test。它也不带来C自身新的排序增益，或构成持续学习方法创新。
